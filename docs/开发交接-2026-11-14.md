## 1. 快速开始

```bash
git clone https://github.com/GGbond-god5/kaoyan-atlas-pages.git
cd kaoyan-atlas-pages
git pull --rebase origin master
```

本地运行（Node 18+）：

```bash
npx wrangler pages dev . --d1=DB --r2=LIBRARY_FILES \
  --binding SESSION_SECRET=local-dev-secret \
  --binding SMS_DEV_CODE=1
```

打开 `http://127.0.0.1:8788`。本地 D1/R2 状态在 `.wrangler/`，不会污染线上。

发布：改完后提交并推送 `master`，Cloudflare Pages 自动构建（命令 `node scripts/build-pages.mjs`，输出 `dist/`）。

## 3. 架构

- 前端：原生 HTML/CSS/JS，无框架、无打包步骤
- 后端：Cloudflare Pages Functions（`functions/`）
- 数据：D1；文件：R2；短信：阿里云号码认证服务（PNVS）
- 站点全站要求登录：`functions/_middleware.js`
  - 未登录页面请求 302 到 `/login?next=原始地址`
  - 未登录静态资源/评卷接口返回 401
  - 放行：登录/注册页、`assets/auth.*`、`assets/config.js`、`assets/remotion/`、`/api/auth/*`、`/api/sms/send`、`/api/health`

主要 D1 表：

- 账号：`users`、`sms_send`、`codes`、`login_fail`
- 档案：`user_profiles`
- 个人笔记：`user_notes`
- 学习平台：`platform_files`、`platform_drafts`、`platform_extractions`、`platform_questions`、`platform_state`、`platform_attempts`、`platform_results`、`platform_coach`

## 4. 功能清单

### 账号与门禁

- 手机号 + 阿里云短信验证码注册/登录，也支持密码登录
- PBKDF2 密码哈希、HMAC 会话 Cookie、60 秒重发、每日限额、错误锁定
- 登录后回到 `?next=` 指定页面

### 个人档案与个性化首页

- `/api/profile`：目标院校、专业代码/名称、初试日期、科目、数学/英语变体、自定义专业课、每日时长、作息
- 首页由档案驱动：
  - 根节点显示院校、专业、科目组合、倒计时
  - 首屏标题「我的备考图谱，以真题为纲」
  - 统计数字按所选科目重算
  - 页面标题、倒计时日期同步
  - 不考数学可取消数学；专业课可取消内置 807，自由添加（显示占位章节，引导去资料库）
- 共享院校目录：`functions/_lib/programs.js`，`GET /api/programs?q=`，档案弹窗可搜索并一键填入

### 笔记库

- 内置 255 篇 Obsidian 笔记（`lazy-src/数一`、`lazy-src/英一`）
- 转换脚本：`scripts/build-lazy-notes.mjs`
  - 输出 `assets/lazy-index.js`、`assets/lazy/<章节>.json`、`assets/lazy-figs/`
  - 支持 `$...$` / `$$...$$`（含 `$$$` 相邻符号）、callout、引用、列表、表格、图片、双链
- 首页每个章节有「笔记 N」入口；顶栏「笔记库」打开全库
- 阅读器支持章节搜索、双链跳转、KaTeX、图片、PDF 预览
- 个人笔记：`user_notes` + `/api/notes` CRUD + 编辑器（Markdown 预览、插入图片、导入文件）
- 附件：`POST /api/notes/upload` 存 R2，`GET /api/notes/file/:file` 校验归属后读取；图片/PDF 在正文内渲染
- 删除：页面内确认框；列表悬停 `×`；内置笔记只读

### 题库与刷题

- 题库约 4662 题，`assets/questions.js`
- 按知识点 / 套卷 / 诊断三种模式
- 套卷交卷后自动逐题评分，2 路并发；结果页有「AI 正在评分 N / 总数」进度、完成后绿色 ✓「评卷完成」
- 能力图：≥3 个维度有数据画雷达面积，不足画扇形面积
- 分值规则 `functions/_lib/scoring.js`：
  - 卷面 `maxScore` 优先
  - 数学选填 5、大题 10–12；807 每题 15–25；英语/政治按现行结构
  - 套卷配平：数学/807 150，英语/政治 100
  - 客观题按参考答案直接记分

### AI 评分与问答

- `functions/_lib/prompts.js`：英语小作文 10 分、大作文 20 分公开标准 rubric
- 作文评分返回：维度分、`grammar[]`（原句/修正/原因）、`upgrades[]`（原句/升级/说明）、`revised`
- `/api/coach` 从个人题库取最多 3 条关键词相关资料注入上下文，回复末尾标注「参考：…」
- 提示词声明用户内容不可信；未复制第三方仓库代码或提示词

### 动效与视觉

- 首页粒子：`assets/particles.js`，鼠标排斥 + 连线，默认尊重 `prefers-reduced-motion`，`?motion=1` 可强制
- Remotion 工程：`remotion/`，组合 `AtlasField`（1600×900、6 秒循环）
- 渲染产物：`assets/remotion/atlas-field.mp4`，作为登录页环境背景
- 顶栏精简、按钮右对齐，窄屏隐藏工具链接；首屏文案全部档案化

## 6. 常用维护任务

### 加一篇内置笔记

1. 把 Markdown 放进 `lazy-src/数一/...` 或 `lazy-src/英一/`
2. 在 `scripts/build-lazy-notes.mjs` 的 `FILE_MAP` 里映射到章节（英语文件）
3. `node scripts/build-lazy-notes.mjs`
4. 提交源文件与生成的 `assets/lazy*`

### 加一所院校/专业

编辑 `functions/_lib/programs.js`，按现有结构加条目：

```js
{
  id: "school-code",
  school: "学校名", college: "学院", majorCode: "代码", majorName: "专业",
  degreeType: "专业学位", studyMode: "全日制", year: 2027,
  subjects: [
    { kind: "math", variant: "math1", name: "数学一", code: "301", fullScore: 150 },
    { kind: "english", variant: "english1", name: "英语一", code: "201", fullScore: 100 },
    { kind: "politics", name: "思想政治理论", code: "101", fullScore: 100 },
    { kind: "professional", name: "807 材料力学", code: "807", fullScore: 150, builtin: "mechanics" },
  ],
}
```

不确定的专业课不要编造，留空让用户补。

### 改作文评分标准

编辑 `functions/_lib/prompts.js` 的 `ESSAY_RUBRIC`，保持输出字段不变：`score/level/comments/missing/suggestions/revised/dimensions/grammar/upgrades`。

### 重新渲染登录页粒子视频

```bash
cd remotion
npx remotion render AtlasField ../assets/remotion/atlas-field.mp4 --codec=h264
```

改完 `Composition.tsx` 一定要重新渲染并提交视频；Pages 构建不会自动跑 Remotion。

### 更新内容/题库

```bash
py -3 src/build/build_web.py
py -3 src/build/make_index.py
py -3 src/build/build_questions.py
py -3 src/build/classify_papers.py
py -3 src/build/build_papers.py
node src/build/katex_check.js
```

生成物要一起提交；Pages 构建只复制文件，不跑 Python。
