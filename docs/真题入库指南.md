## 三、数据格式（imported-*.json）

`build_questions.py` 会自动合并 `src/bank/imported-*.json`，无需改构建脚本。

```json
{
  "items": [
    {
      "id": "math-2024-5",
      "subject": "math",
      "chapter": "math-2024",
      "chapterTitle": "数一 2024 真题",
      "kp": "",
      "kpName": "第5题（选择题）",
      "kind": "选择题",
      "difficulty": "中",
      "year": "2024",
      "source": "2024 全国硕士研究生招生考试 数学一",
      "isReal": true,
      "text": "题干，公式用 \\( ... \\)",
      "answer": "C",
      "steps": ["第 1 步……", "第 2 步……"],
      "figures": ["q2024-5.png"],
      "pageImage": "content/math-pages/2024-lite-p1.png",
      "sourcePdf": "bank/.../2024考研数学一真题.pdf",
      "sourcePage": 1
    }
  ]
}
```

约定：

- `kpName` 必须写成 `第N题（题型）`，套卷模式靠它排序；缺了会排到 9999。
- `figures` 只放 `assets/figs/` 下的文件名（字符串）。放对象会导致刷题页渲染中断（本次已修，但新数据仍按字符串写）。
- `pageImage` 是整页扫描图；`#pbig`「原题整页」按钮由它控制显示。
- `kp` 留空时，「去读对应考点」链接会自动隐藏（真题卷没有对应大观章节）。
- `isReal: true` + `year` 才会被「真题」筛选命中。

## 四、操作步骤

### 1. 找源文件

```bash
find bank -iname "*2024*" | grep -iE "数学|数一"
```

优先用带文字层的解析 PDF：

```bash
py -3 - <<'PY'
import fitz
p = "你的.pdf"
d = fitz.open(p)
print(len(d), sum(len(pg.get_text()) for pg in d))
PY
```

- 文字层 > 0：可直接抽题干/答案，最快。
- 文字层 = 0：扫描件，只能渲染题页后逐题转录。

### 2. 渲染可读题页

用现有 lite 图（`content/math-pages/<year>-lite-pN.png`），转录前压到 1500px 宽，别直接读 4000px 原图——上下文会被图片撑爆。

```bash
py -3 - <<'PY'
from PIL import Image
im = Image.open("content/math-pages/2024-lite-p1.png").convert("L")
w, h = im.size
im = im.resize((1500, round(h * 1500 / w)), Image.LANCZOS)
im.save("content/_read/2024-p1.jpg", quality=82)
PY
```

### 3. 转录与写解答

每套 22 题，按 `一、选择 1–10`、`二、填空 11–16`、`三、解答 17–22` 组织。每题至少给：

- 完整题干（选项逐行写，用 `\n` 分隔）
- 最终答案
- 4–8 个步骤：先写切入点，再写公式/代入/数值/单位，最后写结论
- 证明题写清定理条件和取点方式

公式统一用 `\( ... \)`；中文不要直接写进公式环境，`cases` 里的“其他”要写成 `\text{其他}`，否则 KaTeX 报警告。

### 4. 裁题图（只有需要时才裁）

```bash
py -3 - <<'PY'
from PIL import Image
im = Image.open("content/math-pages/2024-lite-p1.png")
w, h = im.size
im.crop((int(w*.43), int(h*.705), int(w*.645), int(h*.795))).save("assets/figs/q2024-5.png")
PY
```

裁完必须打开看一眼，确认没有把上方矩阵文字或下方选项带进去。

### 5. 构建题库

```bash
py -3 src/build/build_questions.py
```

预期输出：

```

merged imported-math-2025.json 22
total 449 Counter({'math': 195, ...})
```

## 六、踩过的坑

1. **`python` 命令退出码 49**：本机 `python` 指向 Windows Store 别名，执行即失败；一律用 `py -3`。
2. **文字层公式乱序**：2024 解析 PDF 的公式被拆成单字符行，只能当答案校对用，题干以题页图为准。
3. **一次读 17 页高清图导致上下文爆掉**：这是上一个会话失败的原因。每题只读一次 1500px 题页，解析自己写，别把整本解析图塞进上下文。
4. **`figures` 写成对象**：`practice.js` 原先只接受字符串，会直接抛错导致题目渲染中断；构建脚本现已兼容两种格式，但优先写字符串。
5. **套卷被随机打乱**：`start()` 只在知识点模式 shuffle；套卷模式额外按 `kpName` 的「第N题」排序，保证原卷顺序。
6. **公网/平板访问**：`serve.py` 的 `ATLAS_PUBLIC=1` 会屏蔽 `/content/`，而整页原题图就在 `content/` 下。Tailscale 直连（默认非 PUBLIC）不受影响；若以后开 PUBLIC，需要把 `pageImage` 移到 `assets/` 或放行 `/content/`。
