# 功能说明（使用者手册）

考研科目大观（KAOYAN ATLAS · 2027）：按目标院校专业组织的考研学习站。账号为手机号（密码登录 + 短信验证码登录），全部进度绑账号，换设备登录不丢失。未登录只能访问登录/注册页。

## 账号与档案
- 注册/登录：手机号 + 密码日常登录零成本；短信验证码用于注册与找回。
- 个人档案（首页右上角「档案」）：搜索全国院校专业目录选定目标（学校、专业代码、学位类型），考试科目与初试倒计时自动对齐；可调整数学/英语版本（数一/二/三、英一/二），增删专业课。
- 院校专业目录：数据来自研招网当年硕士专业目录逐条核查，持续分批扩充；目录里没有的专业课可在档案中自建。
- 自建科目：档案里添加的专业课会自动成为「我的科目」，可在资料库选用、抽题、刷题，与内置科目体验一致。

## 首页图谱
- 按 科目 → 章节 → 考点 组织内容与真题，点考点直达题库对应题目；支持科目切换、搜索（快捷键 /）、目录。
- 视觉：全站统一「纸墨」设计系统（`assets/theme.css`），统一页眉、按钮、卡片与动效，跨页不跳版。

## 新手引导与 AI 向导
- 新手引导：新账号首次进入首页强制走 7 步功能引导（定档案 → 图谱 → 刷题批改 → 套卷分析 → 资料库 → 单词进度）；每一步都可点「我是老手，跳过教程」跳过；完成状态按账号记录，不重复打扰；顶栏「功能引导」可随时重看。
- AI 向导「小观」（首页右下角）：可对话询问站内功能用法（按站内地图给出具体步骤），也可直接解题——打字或上传题目照片，AI 先转述识别到的题干供核对，再按考点分步骤讲解并自检；问「给个提示」时只给提示不给全解。

## 刷题与 AI 批改
- 三种模式：按知识点练、整套卷、诊断测。套卷模式限单科目、需选定试卷。
- 主观题可拍照上传：AI 先转写手写内容，再按学科评分标准逐步给分——数学按步骤分，材料力学按平衡/协调/计算/量纲四维，政治按采分点，英语作文按分档 rubric 输出语法问题与升格句；批改含得分点、丢分点、修改建议与分步得分明细。
- 客观题以参考答案复核 AI 判定；已批改结果缓存，重复打开一致。

## 套卷分析
- 汇总历次套卷：整体得分率、得分率走势、薄弱知识点榜（未满分率/题量/零分次数，可直达题库补练）、题型得分率、每套错题号与知识点明细。
- 规则化提升建议（优先攻克、反复错、章节集中失分、最弱题型、走势对比），并可让 AI 教练结合数据再总结。

## 资料库（个人题库）
- 上传 PDF/图片/文本/Markdown/JSON（≤20 MiB），浏览器端提取文字、扫描页转图片识别，按页抽题生成草稿，审阅编辑并勾选「我已核对」后导入个人题库。
- 上传可填自定义「分类」（如真题/讲义/笔记/模拟卷），列表可按分类筛选；科目可选内置科目或自建科目。
- 个人题会进入刷题与题库检索，AI 教练回答时也会引用相关个人题作为参考。

## 题库
- 内置 5,554 题：数学一/二、英语一/二、807 材料力学、政治（含肖1000）与各科章节题，含真题年份与来源标注；按科目/章节/考点检索，考点可从图谱深链直达。
- 题目均带参考答案与解析。2026-11-15 完成一次全量校核补缺：807 全卷独立重解（44 处实质勘误）、数学二勘误 2 处并补齐 42 条解析、英语一改正 135 处错误答案并重写约 750 条解析且补齐主观题参考译文/范文、英语二补齐 2010–2016 年共 311 题、政治肖1000 补全 241 题并清理重复编号；全库占位答案/解析已清零，逐科记录见 `docs/audit/`。仅剩政治 1 题因题面截断、设问缺失未给定答案（已附答题要点）。

## 单词与笔记
- 单词：按遗忘曲线复习，进度绑账号。
- 笔记库：内置 Obsidian 笔记（含政治笔记，CC BY-SA 4.0 署名保留）与个人笔记（可上传图片/PDF 附件），按章节挂载。

## 其他
- 时间线：备考阶段与里程碑视图。
- 数据：进度、错题、词汇、个人题与笔记均按账号隔离保存；AI 批改与教练共用同一 AI 通道，服务异常时页面会给出明确报错。

## 账号与个人中心（2026-11-15 下午）
- 头像即账号入口：所有页面右上角显示账号头像（与账号绑定，可在档案里上传更换），点开是个人中心面板——名片（头像、昵称、格言、目标院校、距初试天数）、编辑档案、我的社区分享、管理控制台（仅管理员）、账号设置（改密码、导出我的数据、注销账号）与退出登录。档案与设置已合并到头像入口，不再有单独的档案/设置按钮。
- 个人档案升级：支持头像（自动裁成方形）、一句格言（会显示在社区分享里）、按累计刷题量授予称号；目标院校专业可从「院校专业目录」搜索选择（见下）。
- 内测地基：AI 功能按账号每日限额（批改/教练/抽题，管理员不限）、全站安全响应头、邀请码注册开关（管理台可生成邀请码、封禁账号、发全站公告，公告显示在首页）。

## 学习留存
- 错题艾宾浩斯回流：做错的题按 1/2/4/7/15/30 天间隔自动回到刷题页的「今日错题复习」，答对逐步晋级，毕业移出；历史错题自动纳入。
- 首页今日任务卡：汇总今日到期错题、到期单词与最近一次套卷进度，当天可关闭。
- 套卷分析新增「目标差距」卡：各科最近一次套卷折算分数与自设目标分对比（目标为自设值，非官方复试线）。
- PWA：可添加到手机主屏幕，题库等静态资源缓存后可离线打开复习。

## 社区共享
- 广场支持按标题/说明/分享者搜索、按科目筛选；分享与取消分享改为站内弹窗（标题+一句话说明）。
- 交流：每条分享可点赞、评论（自己的评论可删），分享卡展示分享者头像与格言。
- 页面设有 GitHub 交流区入口（仓库主页 / Discussions / Issues），功能建议与题库勘误可去仓库讨论；站内交流用点赞评论即可，无需 GitHub 账号。
- 资料管理：资料库可删除整份资料（连带其题目、草稿）、单道个人题、单条草稿；导入改为逐条导入并明确报告成功/跳过数量与原因，不再整页失败。

## 院校专业目录（接入中）
- 档案的院校选择接入研招网 2027 全国硕士目录：输学校名 → 选专业 → 按学院与学习方式选定一套考试科目，自动填入档案并映射科目（政治/英语一二/数学一二三/管理类联考等；自命题数学与非英语外语会注明暂代关系）。目录数据按学校分片静态加载，抓取完成后上线；此前回退站内精选目录。

## AI 文案风格
- 全部 AI 输出（批改评语、套卷教练总结、首页向导「小观」）统一为纯文本自然段落：不出现加粗、标题、分隔线、列表符号等 Markdown 字符，分点用中文衔接词；显示层另有清洗兜底，历史生成内容打开时也会自动净化。

## 性能
- 题库分片加载：题库由整包（约 14 MB）改为按科目分片（单科 0.4–2.9 MB），刷题页先加载当前科目，其余科目空闲时后台补齐或切换时按需加载，手机首开明显变快；分片在部署构建时自动生成。

## 学习计划生成器
- 首页新增「学习计划」卡：按个人档案（初试日期、每日学习时长、报考科目）与最近一次套卷得分率自动生成 7 天滚动计划，弱科自动多分时间；按距初试天数划分阶段（强化推进/真题强化/套卷冲刺/考前复盘），阶段越靠后套卷日越密。
- 今日任务逐项可勾选完成（进度按账号保存），每项都直达对应练习：错题复习、单词复习、各科新题推进与套卷日；卡片带明日预告与「重新生成本周计划」。计划与今日任务卡同列展示在首页左下角。
