# 会话纪要：给「考研科目大观」加短信验证码注册登录

记录时间：2026-11-12

## 一、最初的需求

网站 `E:\claude -run\kaoyan-atlas`（考研科目大观，纯静态站点）要加注册登录，手机号 + 阿里云短信验证码；用户已经买了阿里云服务器，想绑到已有网站上。

## 二、过程中改变了三次方向

第一次：用户选了 Node.js + Express，做完整可运行 Demo。于是写了 `server/` 一套 Express 服务，本地 mock 模式全流程跑通，33 项测试通过。

第二次：查资料时发现**学生个人实名认证账号申请不了国内短信签名**（个人资质无法完成运营商实名报备），必须改用「号码认证服务 · 短信认证」。于是短信通道改成双通道：`pnvs`（个人可用，赠送签名 + 模板）和 `dysms`（传统短信，企业认证后可用）。用户随后确认「有赠送服务」，方向正确。

第三次：用户补充「是在 Cloudflare 网页上使用的功能」，最后明确「不想折腾 ECS，用 Cloudflare 跑接口」。于是后端整体改写为 Cloudflare Pages Functions + D1，与网页同域，跨域、跨站 Cookie、备案三个问题一次性消失。

## 三、最终架构

网页（静态）+ 接口（Pages Functions）都在 Cloudflare Pages，通过 GitHub 自动构建；用户数据存在 D1；短信由阿里云「号码认证服务 · 短信认证」发送与核验。

选择 D1 而不是 KV 的原因：KV 是最终一致的，注册完立刻刷新可能读不到刚写入的用户，表现为「注册成功但顶栏还显示登录」。

## 四、交付物

静态页面：`login.html`（密码登录 / 验证码登录 / 已登录面板）、`register.html`、`assets/auth.css`、`assets/auth.js`、`assets/auth-nav.js`；`index.html` 顶栏加了账号入口。

Cloudflare 接口：`functions/_lib/{http,security,sms,db,verify}.js` 与 `functions/api/{health,sms/send,auth/register,auth/login,auth/logout,auth/me}.js`。

本地备用后端：`server/`（Express 版本，含 AI 评卷移植），留作离线开发，不需要 ECS 也能删掉。

配置与防护：`.assetsignore`（阻止 `server/`、`.env` 被上传到 Cloudflare）、`.gitignore` 补充 `.env` 与 `server/data/`。

文档：`docs/短信登录接入指南.md`（阿里云侧开通与 ECS 部署方案）、`docs/Cloudflare部署指南.md`（本次上线手册）。

## 五、安全设计

密码 PBKDF2-SHA256 加盐哈希，迭代次数可配，默认 20000（受 Pages 免费版 10ms CPU 限制）；验证码 5 分钟有效、错误 5 次作废；同号码 60 秒一条、每日 10 条，同 IP 每日 20 条；密码连错 5 次锁 10 分钟；会话为 HMAC 签名令牌，Cookie 为 HttpOnly + Secure + SameSite=Lax；AK 与 Secret 只放环境变量。

## 九、接手后补做的验证与修复（2026-11-12）

端到端测试中发现并已修复：

1. **密码连错锁定从未生效**：`login_fail.until = 0` 被当成「锁定期已过」清零，失败次数永远停在 1。已改为仅当 `until > 0` 且已过期才清零。
2. **未绑定 D1 时发码仍返回成功**：验证码写不进库，用户随后注册只会看到「验证码已过期」。现在发码前先检查 `env.DB`，缺失直接返回 503。
3. **站点 Basic Auth 与 Bearer 冲突**：前端同域也带 `Authorization: Bearer` 会覆盖浏览器自动附带的 Basic 认证，导致开启 `SITE_PASS` 的站点登录接口 401。现在同域只用 HttpOnly Cookie，跨域（`apiBase` 非空）才用 Bearer。
4. **本地 http 无法保存会话 Cookie**：Cookie 原先固定带 `Secure`。现在按请求协议决定，https 仍带 Secure，本地 http 可正常调试。
5. **「最近登录」显示 UTC 时间**：直接截取 ISO 字符串会差 8 小时，已改为本地时区格式化。
6. **健康检查漏报缺失配置**：`smsMode=pnvs` 但缺签名时 `smsMissing` 为空，现始终返回真实缺失项。
