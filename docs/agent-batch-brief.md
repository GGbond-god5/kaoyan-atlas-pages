# 单年数学一真题逐题录入 · 子代理执行规范

## 任务
把指定年份的数学一真题逐题转录：**2009–2020 为 23 题（8 选择 + 6 填空 + 9 解答）；2021 起为 22 题（10 选择 + 6 填空 + 6 解答）**，并写出完整分步解答，输出为一个 JSON 文件：

`src/bank/imported-math-<年份>.json`

只写这一个文件，不要改 `questions.js`、不要跑 `build_questions.py`、不要动其他年份。

## 输入
- 题页（4 页，按页序）：
  - `content/math-pages/<年份>-lite-p1.png`
  - `...-p2.png`、`...-p3.png`、`...-p4.png`
- 原卷 PDF（可选，用于确认题号/页码）：
  `bank/00.考研数学（一二三）09-25真题+解析+做题本/考研数学一历年真题做题本/考研数学一真题09-25/<年份>考研数学一真题.pdf`
- 解析 PDF（只用于核对答案，**不要整本读入**）：
  `bank/00.考研数学（一二三）09-25真题+解析+做题本/考研数学一历年真题做题本/考研数学一真题【解析】09-25/<年份>考研数学一真题【解析】.pdf`

## 读取方式（重要）
1. 用 Read 工具逐张看 4 张题页图；不要一次读高清原 PDF 的全部页面。
2. 每道题写完后在脑内核对：题干、选项、数据、页码。
3. 如答案不确定，用 `py -3` + PyMuPDF 只抽取解析 PDF 中对应的一两页文字（文字层可能是 OCR 乱序，只用来核对答案，不要照抄）。
4. 不要读整本解析 PDF，避免上下文溢出。

## JSON 格式
```json
{
  "items": [
    {
      "id": "math-2019-1",
      "subject": "math",
      "chapter": "math-2019",
      "chapterTitle": "数一 2019 真题",
      "kp": "",
      "kpName": "第1题（选择题）",
      "kind": "选择题",
      "difficulty": "中",
      "year": "2019",
      "source": "2019 全国硕士研究生招生考试 数学一",
      "isReal": true,
      "text": "题干……\nA. ……\nB. ……\nC. ……\nD. ……",
      "answer": "B",
      "steps": ["步骤1……", "步骤2……"],
      "figures": [],
      "pageImage": "content/math-pages/2019-lite-p1.png",
      "sourcePdf": "bank/00.考研数学（一二三）09-25真题+解析+做题本/考研数学一历年真题做题本/考研数学一真题09-25/2019考研数学一真题.pdf",
      "sourcePage": 1
    }
  ]
}
```

字段要求：
- `id`：`math-<年份>-<题号>`。
- `kind`：选择题 / 填空题 / 计算题 / 证明题。
- `kpName`：必须是 `第N题（题型）`，套卷排序依赖它。
- `year` 是字符串；`source` 按上面格式。
- `text`：完整题干，公式用 `\( ... \)`；选择题四个选项逐行写；填空题保留横线；解答题写全条件与两问。
- `answer`：选择题写字母，填空题写最终结果，解答题写最终结论（多问用（1）（2））。
- `steps`：**5–8 步**，每步 1–3 句，必须有公式/代入/结果，不能只写“思路”。证明题写清定理条件与取点。
- `figures`：一般留空 `[]`；不要伪造图片名。图形题靠 `pageImage` 看原页。
- `pageImage`：题目实际所在页，按 p1–p4 对应。
- `sourcePage`：题页页码 1–4。

## 数学与排版要求
- 所有公式用 LaTeX：`\frac`、`\lim`、`\int`、`\sum`、`\sqrt`、`\begin{cases}` 等。
- 中文不要直接写进公式；`cases` 里的“其他”写成 `\text{其他}`。
- 选择题必须四个选项齐全；如原卷选项跨页，继续从下一页补。
- 解答题的分步要能让读者照着算出来；关键积分/求导/行列式展开要写出中间结果。
- 不确定的题目不要编造；在 `steps` 里注明“原卷此处印刷不清，按……理解”，并给出两种可能。

## 写完自检
在项目根目录运行：

```bash
py -3 -c "import json; d=json.load(open('src/bank/imported-math-<年份>.json',encoding='utf-8')); print(len(d['items'])); print([i['kpName'] for i in d['items']])"
```

要求题号 1–N 连续（2009–2020 为 23 题，2021 起为 22 题），题型顺序按当年结构。

再运行（只关心 errors 为 0；总量会包含其他文件）：

```bash
node src/build/katex_check.js
```

若自己文件有错误，修到 0 再结束。
