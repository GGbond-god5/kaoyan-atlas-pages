# 题库公式渲染与评分规范核查（2026-11-15）

## 公式乱码排查与修复

站内所有公式渲染器（atlas/practice/lazy/katex-loader）只认 `\(` `\)`、`\[` `\]` 定界符。逐项审计结论：

| 问题 | 数量 | 修复 |
| --- | --- | --- |
| `$...$` / `$$...$$` 美式定界符（站内不渲染，直接显示源码） | 594 个字段（数二为主，含 1,160 个独立式、8,488 个行内式） | 全部转换为 `\[ \]` / `\( \)`；英语篇章中的美元金额 `$268 billion` 等不是公式，未动 |
| 公式交界损坏 `\[\)`、独立式开头丢失、续行 `\[` 嵌套 | 9 + 7 + 31 处 | 按段解析修复定界符配对 |
| `\quad` 后缺空格（`\quadP` 等未知命令） | 5 处 | 补空格 |
| 行距写法 `\\[2pt]`、`\2pt]` 等：本站 KaTeX 0.16.11 **不支持** `\\[dim]` | 50 余处 | 统一降为普通行断 `\\` |
| 行断反斜杠被吞残片（`\0`、`\2`、`\-`，仅限定位到的 7 题） | 7 题 | 逐题定点修复（此类模式与矩阵中合法的 `\\0`、`\\-` 仅差上下文，禁止全库正则替换） |
| 解析中混入导入过程的元注释/自辩文字（如「经核对……」「用户要求逐字转录」） | 7 题 | 整题重写干净解析并独立验算：math2-2012-22、2014-18、2015-2、2016-11、2017-23、2019-22、2021-17 |

修复后用仓库自带 KaTeX 全量复验：**66,463 条公式，0 失败**。审计脚本已入库：`scripts/katex-audit.mjs`（`npm run check:katex`），纳入 `npm run release`。

已知遗留（内容层，非渲染层）：个别英语解析存在 OCR 错字、个别数二长解析为整节教材摘录（单步过长），后续按科目分批清洗；数学二 2019-22 原解析曾给出错误记忆版本，已按题面重解并与答案核对。
