# 考研科目大观 · 制作过程

> 记录这个网站从内容整理、题库录入、前端交互到 GitHub + Cloudflare Pages 上线的完整做法，方便以后自己维护或复刻。

---

## 1. 项目定位

面向 2027 考研（华南理工 085500 机械）的个人备考站，把四门课拆成可点、可读、可刷的结构：

- **数学一**：20 个知识点章节 + 2009–2025 真题 + 2025/2026 模拟卷
- **英语一**：5529 大纲词、作文句式、2009–2025 全部 17 套真题
- **807 材料力学**：2004–2018、2020–2026 共 22 套真题
- **政治**：2017–2026 真题、肖1000、时间轴

访问入口：

| 页面 | 作用 |
|---|---|
| `index.html` | 四科思维导图，点章节在页内阅读 |
| `vocab.html` | 大纲词 / 专题词卡片与自测 |
| `timeline.html` | 1840–2026 政治时间轴 |
| `practice.html` | 套卷刷题 + 按知识点刷题 + AI 评核 |
| `bank.html` | 本地题库资料索引（不转载题目） |

## 3. 内容生产：章节与图谱

1. **章节源文件**：`src/chapters/<subject>/NN.json`，每章含 `title`、`kps[]`、每个考点下的 `exams[]`（题干、答案、分步解答、图片）。
2. **渲染阅读包**：`py -3 src/build/build_web.py` 生成 `web/<id>.js`，页面内懒加载，支持上下章与 `<details>` 展开解析。
3. **生成 PDF**：`py -3 src/build/build.py` 调用 Edge 打印，再用 PyMuPDF 加页眉页脚和返回目录。
4. **更新图谱数据**：`py -3 src/build/make_index.py` 汇总成 `assets/data.js`。
5. **公式校验**：`node src/build/katex_check.js`，要求 `errors: 0`。

## 4. 题库：从 PDF 到可刷题

所有题库数据最终都落到 `src/bank/imported-*.json`，再由 `py -3 src/build/build_questions.py` 合并成 `assets/questions.js`。

### 4.1 数学一真题 / 模拟卷

- 每套卷先按页渲染成 `content/math-pages/<年>-lite-pN.png`，逐题转录题干、选项、答案与 5–8 步解答。
- 字段约定：`id`、`subject`、`chapter`、`kpName`（必须是「第N题（题型）」）、`kind`、`year`、`isReal`、`text`、`answer`、`steps`、`pageImage`。
- 批量录入用子代理流水线：`docs/agent-batch-brief.md`、`render_papers.py`、`render_mock_set.py`、`validate_imported.py`。
- 知识点归类：`classify_topics.py` 给套卷题写 `topicChapter`（math-01～20）。

### 4.2 政治 2017–2026

- 源文件：`bank/pol-zhenti/` 的分类试题册 + 分类解析册 + 套卷版。
- 脚本 `import_politics.py`：
  - 从分类册抽题干和选项，从解析册抽答案与「正确答案为X」的解析正文；
  - 用两本书交叉核对，冲突以解析正文为准；
  - 生成 `imported-pol-<年>.json`，题页图放 `content/pol-pages/`。
- 源书本身缺题（时政题等）在 `docs/真题入库指南.md` 里列明，不补写。

### 4.3 英语一 2009–2025

分三类来源处理：

| 年份 | 题目来源 | 解析来源 |
|---|---|---|
| 2009–2018、2022 | PDF 文字层 + 手工补题 | 公开答案 + 解析册 OCR |
| 2019–2021、2023、2025 | 300 dpi OCR + 手工补题 | 解析册 OCR / 官方答案 |
| 2024 | PDF 文字层 | 库内答案表 |

关键脚本：

- `parse_eng_paper.py`：按题型切分文字层试卷（完形、阅读、Part B、翻译、写作）。
- `ocr_eng_import.py`：OCR 文本解析，阅读题按「题干流 + 选项四连组」重建，绕过 OCR 丢题号的问题。
- `build_eng_bank.py`、`build_ocr_2019/2020/2021/2023/2025.py`：各年生成与手工补题表（MANUAL）。
- `enrich_eng_solutions.py`：OCR 解析册，按题抽取「精准定位 / 解题思路 / 命题排除 / 技巧总结」，并用解析正文校正答案。

每套 52 题：完形 1–20、阅读 21–40、新题型 41–45、翻译 46–50、小作文 51、大作文 52。

### 4.4 807 材料力学

- 22 套 193 题，逐题录入 `imported-807-*.json`，题图在 `content/bank-pages/`。
- 官方答案勘误已写入数据：2004 选择 C→D、2005 三题、2013 稳定判据、2015 直径与切应力等，详见 `docs/807题库状态备案.md`。
- 2019 年缺源文件，未录入。

### 4.5 肖1000

- `import_xiao1000.py` 生成 `imported-pol-x1000.json`（1127 题），按章节 `pol-01～07` 归类，题页图在 `content/x1000-pages/`。

## 5. 知识点模式与套卷模式

`practice.js` 有两条互不干扰的筛选线：

- **按知识点刷**：按 `topicChapter` 聚合章节；章节题和套卷题混排。
- **按套卷刷**：按 `chapter`（如 `eng-2024`）取整套卷，按 `kpName` 里的「第N题」排序。

`classify_papers.py` 负责给套卷题写知识点：

- 英语按题型直接映射（完形→english-02、阅读→english-03……）；
- 政治按题干与解析关键词打分归入 pol-01～07；
- 807 按力学关键词归入 mech-01～14；
- 只处理 `chapter` 含四位年份的套卷文件，不动肖1000 等既有章节题。

章节标题统一由 `practice.js` 的 `TOPIC_NAMES` 映射，避免不同来源的标题混在一起。

## 6. 刷题页的交互设计

### 6.1 阅读与完形

- 完形原文里的空格数字渲染成**带下划线的空位**，序号标在横线上方。
- 阅读题在宽屏进入「左原文 / 右题目」双栏：原文粘性固定、独立滚动，题目侧单独滚动；窄屏自动上下堆叠。
- 原文默认展开，不再需要手动点开。

### 6.2 客观题作答

- 选择题、多选题、阅读、完形、新题型的选项是按钮，可直接点击。
- 单选点一下选中，再点取消；多选可反复勾选。
- **交卷前不判对错**，只记录选择；交卷时统一按 `answer` 判分，写入答题卡和结果页。
- 套卷模式右侧保留题号答题卡：显示已答数，可点题号跳转，交卷后显示对错状态。

### 6.3 结果与解析

- 点「显示解析」展开参考答案和分步解析。
- 解析来自库内解析册 OCR 的题，会显示定位、排除与结论；只有答案的题保留「原解析 ↗」链接。

## 7. AI 评核（阿里云百炼 / 千问）

### 7.1 两种运行方式

| 环境 | 入口 | 说明 |
|---|---|---|
| 本地 | `serve.py` 的 `/api/grade` | Python 代理，Key 放 `%USERPROFILE%\.claude\kaoyan-atlas-grading.key` |
| 线上 | `functions/api/grade.js` | Cloudflare Pages Function，Key 放 Pages 环境变量 |

前端统一请求 `/api/grade`，通过 `assets/config.js` 的 `gradeEndpoint` 配置。

### 7.2 支持的能力

- **纯文字**或**图片 + 文字**作答；
- 客观题：核对所选字母，解释正确项与干扰项，不改判参考答案；
- 小作文 / 大作文：按内容、结构、语言、语法评分，给修改建议和**润色稿**；
- 翻译：逐句对照参考译文，给改译；
- 政治分析题、计算/证明题：按采分点或步骤给分。

返回字段：`score / level / comments / missing / suggestions / revised`。

### 7.3 配置

- 模型：`qwen3-vl-plus`（可用 `DASHSCOPE_MODEL` 覆盖）。
- 线上密钥：Cloudflare Pages → Settings → Environment variables → `DASHSCOPE_API_KEY`。
- 访问控制：`functions/_middleware.js` 实现 Basic Auth，环境变量 `SITE_USER`、`SITE_PASS`；不设置 `SITE_PASS` 时自动关闭。

## 8. 发布与部署

### 8.1 本地预览

```bash
py -3 serve.py
```

默认 `http://127.0.0.1:8123`；`PORT` 环境变量可改端口。

### 8.2 GitHub

- 私有仓库：`https://github.com/GGbond-god5/kaoyan-atlas`
- `.gitignore` 只忽略根目录 `/bank/`、`/pdf/`、`/content/math-pages/`、`/content/x1000-pages/` 等大文件；
- 题库源数据 `src/bank/`、807/政治题页图都纳入版本管理，保证新机器能重建。

### 8.3 Cloudflare Pages

1. Pages → Connect to Git → 选择私有仓库；
2. 框架 None，构建命令留空，输出目录 `/`；
3. 环境变量加 `DASHSCOPE_API_KEY`、`SITE_USER`、`SITE_PASS`；
4. 直接部署命令：

```bash
npx wrangler pages deploy dist --project-name kaoyan-atlas --branch master --commit-dirty=true
```

`dist/` 是从仓库根目录生成的发布目录，排除了 `bank/`、`pdf/`、`_ocr/`、`content/math-pages`、`content/x1000-pages`。

### 8.4 线上地址

- 生产：`https://kaoyan-atlas.pages.dev/`
- 全站 Basic Auth：未登录返回 401；登录后页面与 AI 接口正常。
- 已知限制：数学真题页图、肖1000 页图、真题/解析 PDF 未上传，线上点这些链接会缺文件。


## 10. 踩坑记录

1. **本机 `python` 是 Store 别名**，执行退出码 49，一律用 `py -3`。
2. **`.gitignore` 的 `bank/` 会匹配任意层级**，误伤 `src/bank/`；应写 `/bank/`。
3. **OCR 会丢题号和选项字母**：用「题干流 + 每组四个选项」重建，别依赖识别出的数字。
4. **扫描版解析册双栏排版**：题号与正文会错位，抽取解析时只保留能可靠对应的题。
5. **GitHub push 偶发 `Connection was reset`**：重试，或加 `-c http.version=HTTP/1.1`。
6. **Cloudflare Pages 会把 `/practice.html` 308 重定向到 `/practice`**，属正常，跟随跳转即可。
7. **AI 代理必须放在服务端**，Key 不能进浏览器；线上用 Pages Function，本地用 `serve.py`。
8. **版权资料边界**：真题 PDF、解析册、肖1000 原图只留在本地 `bank/`，公开仓库和线上只保留自研内容与必要的题页图。
