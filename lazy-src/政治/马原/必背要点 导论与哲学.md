# 必背要点 · 导论与哲学

冲刺阶段按条背诵的最小集合：先记「标志类」表格，再按唯物论—辩证法—认识论—唯物史观四块过原理。每条都是一句可直接落到选项里的判断。

## 一、导论：构成、渊源与经典著作

- 马克思主义由**马克思主义哲学、马克思主义政治经济学、科学社会主义**三个部分构成，恩格斯在《反杜林论》中首次明确这一划分，《反杜林论》也是全面阐述马克思主义理论体系的著作。
- 直接思想渊源有三：**德国古典哲学、英国古典政治经济学、英法空想社会主义**。
- 马克思在哲学史上的两大贡献：**唯物史观和剩余价值学说**（合称两大发现）；其中马克思主义经济理论的基石是剩余价值理论。

| 著作 | 地位与标志 |
| --- | --- |
| 《共产党宣言》 | 第一个无产阶级政党**共产主义者同盟**的党纲；马克思主义公开问世、科学社会主义诞生、马克思主义诞生的共同标志 |
| 《德意志意识形态》 | 首次系统阐述唯物史观，标志马克思主义哲学的诞生 |
| 《资本论》 | 系统阐述剩余价值理论，标志马克思主义政治经济学的诞生 |
| 《关于费尔巴哈的提纲》 | 首次确立科学的实践观 |
| 《哲学的贫困》 | 马克思主义的第一次公开阐述 |
| 《神圣家族》 | 马克思与恩格斯第一次合著的作品 |
| 《德法年鉴》 | 标志「两个转变」：从唯心主义转向唯物主义、从革命民主主义转向共产主义 |

- 基本特征一句话：**科学性与革命性的统一**；人民性、实践性、发展性集中表现为革命性。
- **人民性是马克思主义的本质属性**，人民至上是其政治立场；**实践性是首要的基本观点**，也是区别于其他理论的根本特征。
- 世界的物质统一性原理是辩证唯物主义最基本的观点、马克思主义的基石。

## 二、辩证唯物论：物质与意识

- 物质的唯一特性是**客观实在性**；运动是物质的存在方式和根本属性，时空是运动着的物质的基本存在形式，运动的存在方式也是时空。
- 静止是运动的特殊状态，是**运动的衡量尺度**——没有静止就无法衡量运动。
- 意识是人脑的机能和属性，是**客观世界的主观映像**；劳动（社会实践）在意识的产生和发展中起决定性作用。
- 发挥主观能动性的前提是**尊重客观规律**，基础与基本途径都是实践。
- 人的实践活动是自然界与人类社会、客观世界与主观世界**分化与统一的关键**；实践是横跨物质与意识的唯一桥梁。
- 人有自然属性和社会属性，**社会属性是人的本质属性**。

## 三、唯物辩证法：联系、发展与矛盾

- **系统观念**是普遍联系观点的应有之义；区分新旧事物只看是否符合历史发展趋势和规律，**与时间先后无关**。
- **对立统一规律是唯物辩证法的实质和核心**：斗争性寓于同一性之中，共性寓于个性之中，必然寓于偶然之中。
- **具体问题具体分析是马克思主义的活的灵魂**，也是正确认识事物的基础和正确解决矛盾的关键。
- 主要矛盾是矛盾体系中处于支配地位、对事物发展起决定作用的矛盾——抓主要矛盾即「牵牛鼻子」。
- 可能性辨析：区分「可能与不可能」看**是否有现实依据**；区分「现实的可能与抽象的可能」看**现实依据是否充分**。

## 四、认识论：实践、认识与真理

- 实践的观点是马克思主义认识论**第一的和基本的**观点；实践是认识的基础，在认识活动中起决定性作用，首要的是**实践是认识的来源**。
- 实践的主体与客体之间有实践关系、认识关系、价值关系，**实践关系最根本**。
- 实践的三种基本类型：物质生产实践、社会政治实践、科学文化实践，其中**物质生产实践最基本**；虚拟实践是派生形式，具有相对独立性。
- 认识的第二次飞跃（从理性认识到实践）比第一次飞跃**更为重要**，认识的最终目的要回到实践中检验和发展。
- 真理与谬误在一定范围内对立是绝对的，超出范围会相互转化——真理都有条件和范围。
- 认识必然、争取自由是人类认识和改造世界的根本目标；历史表现为不断从**必然王国走向自由王国**的过程。

## 五、唯物史观：社会存在、社会基本矛盾与人民群众

- 社会历史观的基本问题是**社会存在与社会意识的关系问题**；二者何者决定何者，是唯物史观与唯心史观的根本分野。
- 生产力三要素中：**生产工具是生产力发展水平的客观尺度**、区分社会经济时代的客观依据；**劳动者是最活跃的因素**；科学技术是第一生产力，是先进生产力的集中体现和主要标志。
- 生产关系中**生产资料所有制关系最基本、最具决定性**，是判定社会经济结构性质的客观依据；「生产关系一定要适合生产力状况」是社会发展的第一规律（社会基本矛盾运动的第一对矛盾）。
- 上层建筑中**政治上层建筑居主导地位、国家政权是核心**；上层建筑反作用的性质归根到底取决于它是否有利于生产力发展。
- 社会基本矛盾是生产力与生产关系的矛盾、经济基础与上层建筑的矛盾。
- 世界历史的形成和发展以**生产方式的发展变革**为基础，**普遍交往**是世界历史的基本特征；人的发展最根本的是自由程度的提高。
- 「谁创造历史」是唯物史观与唯心史观的分水岭：**人民群众是历史的创造者**（特定时期可以包括剥削阶级），其创造活动受经济、政治、精神文化条件制约，**经济条件是根本制约条件**。
- **群众路线**是无产阶级政党的根本路线，也是党的根本领导方法和工作方法。
