# 选择题速查 · 政经与垄断

政经选择题的失分点集中在「划分方式」「形成原因」「计算」三处。这篇按速查表整理，与「必背要点 政经与科社」互补：那篇背条目，这篇对陷阱。

## 一、资本的三种划分方式（先看划分依据）

| 划分依据 | 结果 |
| --- | --- |
| 是否带来剩余价值（在剩余价值生产中的作用） | 不变资本 c / 可变资本 v |
| 在资本循环中的职能 | 货币资本 / 生产资本 / 商品资本 |
| 价值周转方式 | 固定资本 / 流动资本 |

- 资本构成三层：**技术构成**由技术水平决定，反映生产资料与劳动力的实物比例；**价值构成**是 c:v 的金额比例；**有机构成**是由技术构成决定并反映其变化的价值构成。关系链：技术变→价值变→有机构成变；技术不变而价值变（价格波动），有机构成不变。
- 有机构成提高是一般趋势，由资本本性决定；其普遍提高形成相对过剩人口。
- 金融资本形成的主要途径：金融联系、资本参与、人事参与。

## 二、周转、积累与再生产

- 影响资本周转快慢的两个关键因素：**资本周转时间**、**生产资本中固定资本与流动资本的构成**。
- 资本积累速查：剩余价值是资本积累的唯一源泉；资本积累是扩大再生产的源泉；积累导致两极分化，并通过有机构成提高产生失业（相对过剩人口）。
- 社会再生产的核心问题是社会总产品的实现问题（价值补偿 + 实物补偿）。
- 社会生产定位：生产力是生产的物质内容，生产关系是社会形式，二者构成生产方式；社会形态更替归根结底是社会基本矛盾运动的结果，生产力发展具有最终决定意义；社会历史发展的根本动力是社会基本矛盾。
- 经济危机具有周期性，根源在于资本主义基本矛盾运动的阶段性；危机可能性的最初来源是货币的流通手段与支付手段职能。

## 三、货币职能关键词辨析

做题先抓题干关键词：

- **价值尺度**——标价，只需观念中的货币
- **流通手段**——即时交易，一手交钱一手交货
- **贮藏手段**——贮存，必须是足值的货币
- **支付手段**——提前或延后交易，关键词：债务、赋税、工资、租金
- **世界货币**——货币职能在世界范围的扩展，关键词：汇率、国际结算

最基本职能是价值尺度与流通手段；货币的本质是固定充当一般等价物的商品。

## 四、价值规律作用的错误表述

价值规律在市场配置资源中的作用只有三项：自发调节生产资料和劳动力在各部门的分配比例、自发刺激社会生产力发展、自发调节社会收入分配（促进两极分化）。凡选项说它能「调节雇佣工人与资本家之间的利益再分配」「消除两极分化」的，都是错误表述——它恰恰加剧分化。

## 五、剩余价值三概念对照

| 概念 | 形成机制 | 竞争范围 |
| --- | --- | --- |
| 超额剩余价值 | 个别企业率先提高劳动生产率，个别价值低于社会价值 | 同一部门内部 |
| 相对剩余价值 | 全社会劳动生产率提高→生活资料价值下降→必要劳动时间缩短 | 整个社会 |
| 平均利润 | 资本在部门间转移，利润率平均化 | 不同部门之间 |

- 劳动生产率与价值量：单位时间内劳动量不变时，生产率提高→产品数量增多、单位商品价值量下降、**价值总量不变**。
- 工资辨析：资本主义工资是劳动力的价值或价格（表述为「劳动的价值或价格」是其假象）；劳动者实际所得远小于其劳动创造的价值，差额即剩余价值。
- 资本主义劳动过程的特点：工人在资本家监督下劳动、劳动隶属于资本家；劳动产品全部归资本家所有。劳动是否具有生产性，取决于能否为资本家带来剩余价值。

## 六、政经计算速查

基本量：预付资本 = c + v；有机构成 = c:v；剩余价值率 m′ = m/v = 剩余劳动时间/必要劳动时间；利润在量上等于剩余价值。

例：投资 100 万，c:v = 3:1，m′ = 200%。则 c = 75 万、v = 25 万，m = v × m′ = 50 万，利润 = 50 万。

绝对与相对剩余价值的计算对照（原工作日 8 小时、必要劳动 4 小时、剩余劳动 4 小时，m′ = 100%）：

- 绝对剩余价值：延长工作日 2 小时→总时长 10 小时，剩余劳动 6 小时，m′ = 6/4 = 150%
- 相对剩余价值：工作日不变，必要劳动缩短 2 小时→必要 2 小时、剩余 6 小时，m′ = 6/2 = 300%

口诀式记法：绝对是「加时」，相对是「减必要」；两者都靠延长剩余劳动时间，只是路径不同。

## 七、资本主义的新变化

**二战后**：

- 所有制：当今居主导地位的是**法人资本所有制**（资本占有主体多元化，所有权与控制权分离）；私人股份所有制下所有权与控制权也不再统一。
- 劳资与分配：职工参与决策、终身雇佣、职工持股、社会福利普及化与全民化。
- 阶层结构：有所有权的资本家一般不再直接经营企业，**高级职业经理人**成为大公司经营的实际控制者；知识型、服务型劳动者数量增加。

**当代**：最突出、最鲜明、最主要的特征是**国际金融资本的垄断**；金融垄断寡头化与国际化、经济虚拟化与产业空心化相伴；金融垄断资本形成壮大的重要制度条件是**金融自由化与金融创新**。

## 八、国际：战时共产主义、新经济政策与巴黎公社

| | 战时共产主义 | 新经济政策 |
| --- | --- | --- |
| 农业 | 余粮收集制 | 粮食税，余粮可自由出卖 |
| 商品货币 | 取消商品货币关系 | 恢复商品货币关系（主要特征：发展商品经济） |
| 工业 | 全面国有、国家配给 | 部分恢复私营中小企业；实行国家资本主义（租让制、租借制） |
| 分配与贸易 | 国家垄断贸易 | 按劳分配，允许自由贸易 |

- 巴黎公社（1871）是无产阶级夺取政权的第一次伟大尝试，是第一国际精神的产儿（注意：不是第一国际发动和领导的）。防「公仆变主人」的两项措施都与人有关：**全面选举制与撤换制**（职位）、**取消高薪制**，公职人员年薪不超过熟练工人工资（工资）。
- 辨析：苏维埃制度由俄国十月革命建立，不是巴黎公社；公社建立的是政权，不是政党。
