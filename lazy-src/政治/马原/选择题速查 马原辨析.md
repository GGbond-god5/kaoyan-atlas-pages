# 选择题速查 · 马原辨析

与「必背要点」分工：那篇按条背诵，这篇专攻选择题最爱设陷阱的辨析点——成组的「寓于」、两个「枢纽与基石」、著作的别称与定位，考前快速扫一遍即可。

## 一、六个「寓于」

选择题常把主宾顺序颠倒，记住方向：小者寓于大者、具体寓于一般。

- **价值寓于使用价值之中**（无使用价值则无价值）
- **必然寓于偶然之中**（偶然是必然的表现形式）
- **斗争性寓于同一性之中**（同一性以斗争性为前提）
- **绝对性寓于相对性之中**（真理的绝对性通过相对性表现）
- **普遍性寓于特殊性之中**，即**共性寓于个性之中**（二者是同一关系的不同表述，不要当两个考点重复选）

## 二、两个理论辨析（最易互串）

| 问法 | 答案 |
| --- | --- |
| 理解政治经济学的枢纽 | **劳动二重性理论** |
| 马克思经济学的核心内容和基石 | **剩余价值理论** |
| 社会主义由空想变为科学的两大基石 / 马克思一生的两个伟大发现 | **唯物史观和剩余价值学说** |
| 马克思主义理论区别于其他理论的根本特征 | **实践性** |
| 马克思主义的本质属性 | **人民性** |
| 马克思主义基本特征一句话 | **科学性与革命性的统一** |

## 三、上层建筑

- 政治上层建筑在上层建筑中居**主导地位**，其核心是**国家政权**。
- 观念上层建筑（意识形态）中居核心地位、起主导作用的是**政治法律思想**。
- 易错：问「上层建筑的核心」答国家政权；问「意识形态的核心」答政治法律思想，两问两答。

## 四、人的本质与物质世界的二重化

- 人的本质是一切**社会关系的总和**——不是自然属性，也不是抽象的类本质。
- 实践使世界发生二重分化：从自然界中分化出人类社会，从客观世界中分化出主观世界（现实世界与虚拟世界是其在信息时代的延伸表述）。

## 五、科学社会主义的核心命题与「自由」

- 科社核心命题是「两个必然」：**资本主义必然灭亡、社会主义必然胜利**。
- 与自由相关的四个定位：马克思主义追求的根本价值目标、共产主义社会的根本特征是**实现人的自由全面发展**；人类认识和改造世界的根本目标是**认识必然、争取自由**；人的发展最根本的是**自由程度的提高**；检验真理的唯一标准是实践，理由是实践具有**直接现实性**。
