# 必背要点 · 思想道德与法治

思修的条目分两半：前半是人生观、道德与核心价值观，后半是法治——法治部分「前提/关键/重点/基础」这类定位词最容易互相串位，单独成表背。

## 一、人生观与人生价值

- 处理人生问题的着眼点和出发点是**个人与社会的关系问题**；人的本质属性是社会属性，推动和实现人的全面发展是社会发展的根本目标。
- **人生目的是人生观的核心**，它是人们在人生实践中关于自身行为的根本指向和人生追求。
- 人生的**社会价值是自我价值的基础**；评价人生价值的根本尺度，是看实践活动是否符合社会发展客观规律、是否促进历史进步；具体标准是能否以劳动和才能为国家社会真诚奉献、为人民尽心服务。
- **社会实践是实现人生价值的必由之路**，艰苦奋斗是实现理想的重要条件。

## 二、中国精神与社会主义核心价值观

- 民族精神的核心是**爱国主义**，时代精神的核心是**改革创新**；创新创造是中华民族最深沉的民族禀赋，创新驱动最根本的是增强自主创新能力。
- 爱国主义的本质是**爱国和爱党、爱社会主义的高度统一**；新时代弘扬爱国主义要把维护祖国统一和民族团结作为重要着力点和落脚点。
- 社会主义核心价值体系四部分：马克思主义指导思想、中国特色社会主义共同理想、以爱国主义为核心的民族精神和以改革创新为核心的时代精神、社会主义荣辱观。
- 社会主义核心价值观是核心价值体系的**精神内核**与高度凝练，三个层面不要错位：

| 层面 | 内容 |
| --- | --- |
| 国家 | 富强、民主、文明、和谐 |
| 社会 | 自由、平等、公正、法治 |
| 公民 | 爱国、敬业、诚信、友善 |

- 核心价值观的地位：坚持和发展中国特色社会主义的价值遵循、提高国家文化软实力的迫切要求、增进社会团结奋进的最大公约数；其**根本特性是人民性**。

## 三、道德

- **劳动是道德起源的首要前提**；道德最基本的功能是认识功能、规范功能、调节功能。
- 社会主义道德的**核心是为人民服务，原则是集体主义**；集体主义的最高层次是无私奉献、一心为公。
- 对公民最基本的道德要求：顾全大局、遵纪守法、热爱祖国、诚实劳动。
- 分层定位：社会公德最基本最低的要求是**遵纪守法**；职业道德的最低要求是**爱岗敬业**，最高层次是**奉献社会**。

## 四、法治：定位词对照表

法治条目九成考定位词，按三组对照记：

**法治体系五部分**

| 组成部分 | 定位 |
| --- | --- |
| 完备的法律规范体系 | 前提 |
| 高效的法治实施体系 | 重点 |
| 严密的法治监督体系 | 宪法法律有效实施的重要保障 |
| 有力的法治保障体系 | 重要依托 |
| 完善的党内法规体系 | 本质要求和重要内容 |

**全面依法治国四环节**：科学立法是前提，严格执法是关键，公正司法是重点（也是难点所在），全民守法是基础。

**法治建设三位一体**：法治国家是目标，法治政府是重点（重点任务和主体工程），法治社会是基础（基础工程）。

- 根本遵循和行动指南是习近平法治思想；全面依法治国的**根本目的是依法保障人民权益**，目标是建设法治中国，总抓手是建设中国特色社会主义法治体系。
- 中国特色社会主义法治道路的核心要义：坚持党的领导、坚持中国特色社会主义制度、贯彻中国特色社会主义法治理论；五项原则为坚持党的领导、坚持人民主体地位、坚持法律面前人人平等、坚持依法治国和以德治国相结合、坚持从中国实际出发。
- **党的领导是中国特色社会主义最本质的特征**、社会主义法治最根本的保证，也是我国法治同西方资本主义国家法治的最大区别。
- 法律运行：法律制定是起始性和关键环节，原则是公正、公平、公开；**法律遵守是法律实施和实现的基本途径**。
- 公正是法治的生命线；**公正司法是维护社会公平正义的最后一道防线**。
- 全面依法治国的重要保障是法治人才；依法治国是国家治理体系和治理能力现代化的依托。

## 五、宪法与权利保障

- **宪法是国家的根本法**，是党和人民意志的集中体现，是国家各项制度和法律法规的总依据。
- 公平正义四方面：权利公平、机会公平、规则公平、救济公平。
- 权利保障四环节：**宪法保障是前提和基础，立法保障是重要条件，行政保护是关键环节，司法保障是最后防线**。
- 维护国家统一和民族团结是公民的**最高法律义务**；国家统一是公民实现法律权利与自由的前提。
