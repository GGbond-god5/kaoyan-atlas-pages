# 选择题速查 · 法治定位与辨析

法治部分的选择题几乎全是「定位词 + 表现形式」的对应题。这篇把定位关系做成速查表集中过，与「必背要点 思修与法治」的条目式背诵互补。

## 一、法律至上的三性

| 表现 | 含义 | 题干关键词 |
| --- | --- | --- |
| 普遍适用性 | 所有人、所有机构、所有组织都必须遵守法律 | 「都必须遵守」 |
| 优先适用性 | 多种规范发生矛盾时，优先适用法律规范 | 「优先考虑法律」 |
| 不可违反性 | 不论权力大小、职位高低，违法必受制裁 | 「违法必究」 |

## 二、法治体系五部分定位（再确认）

- 完备的法律规范体系——**前提**
- 高效的法治实施体系——**重点**
- 严密的法治监督体系——宪法法律有效实施的**重要保障**
- 有力的法治保障体系——**重要依托**
- 完善的党内法规体系——**本质要求**和重要内容

记忆抓手：规范是前提、实施是重点、监督是保障、保障体系是依托、党内法规见本质。

## 三、权利保障四环节

**宪法保障（前提和基础）→ 立法保障（重要条件）→ 行政保护（关键环节）→ 司法保障（最后防线）**。注意与法治体系定位的区别：这里问的是「权利保障」，四环节的定位词不要和五体系的互相挪用。

## 四、全面依法治国四环节定位

科学立法是**前提**，严格执法是**关键**，公正司法是**重点**，全民守法是**基础**。易错点：把「公正司法」换成「司法保障」或与严格执法的「关键」对调——司法是重点、执法是关键。

## 五、高频辨析组

- **法治国家 / 法治政府 / 法治社会**：目标 / 重点 / 基础，三者一体建设。
- **依法治国 / 依法执政 / 依法行政**：治国是党领导人民治理国家的基本方式；依法执政是新的历史条件下党执政的基本方式。
- **法律制定 / 法律遵守**：制定是法律运行的起始性和关键环节；遵守是法律实施和实现的基本途径。
- **公正的四方面**：权利公平、机会公平、规则公平、救济公平——缺一不可，选项里多一个「结果公平」或少一个「救济公平」都要警惕。
- **党的领导三定位**：中国特色社会主义最本质的特征、社会主义法治最根本的保证、我国法治同西方资本主义国家法治的最大区别。
