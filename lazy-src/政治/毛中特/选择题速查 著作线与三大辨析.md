# 选择题速查 · 毛泽东思想著作线与三大辨析

毛中特选择题最爱考「哪篇文章属于哪个阶段」。这篇把著作按形成阶段排成一条线，再附四组极易互串的「三大」辨析。

## 一、著作线：四个阶段

**萌芽（大革命时期）**——提出新民主主义革命的基本思想

- 《中国社会各阶级分析》：提出革命的首要问题是分清敌友；中国社会是「两头小中间大」——两小头是无产阶级和地主大资产阶级，一大头是农民、城市小资产阶级及其他中间阶级
- 《国民革命与农民运动》《湖南农民运动考察报告》：阐明农民问题的重要性

**初步形成（土地革命时期）**——农村包围城市、武装夺取政权道路理论

- 《中国的红色政权为什么能够存在？》《井冈山的斗争》：论证红色政权存在发展的主客观条件，提出**工农武装割据**思想
- 《星星之火，可以燎原》：回答「红旗到底打得多久」的疑问
- 《反对本本主义》：为反对教条主义而作；提出「没有调查，没有发言权」，是独立自主思想最初的明确表述

**成熟（遵义会议后至抗战时期）**——新民主主义理论系统阐明

- 《论反对日本帝国主义的策略》（瓦窑堡会议文件）：系统说明党的政治策略问题
- 《实践论》《矛盾论》：哲学奠基，「两论」
- 《论持久战》：分析中日双方四个基本特点，预言防御、相持、反攻三阶段（**相持阶段最关键**），驳斥速胜论与亡国论，提出「兵民是胜利之本」
- 《〈共产党人〉发刊词》：提出三大法宝
- 《中国革命和中国共产党》：第一次提出新民主主义革命的科学概念
- 《新民主主义论》：系统阐明新民主主义的政治、经济、文化纲领
- 《改造我们的学习》《论联合政府》：后者把新民主主义基本纲领具体化——经济纲领三项：没收封建地主土地归农民、没收官僚资本归新民主主义国家、保护民族工商业（第三项最具特色）

**继续发展（解放战争至建国后）**

- 《在晋绥干部会议上的讲话》：完整提出新民主主义革命总路线（完整之处在于革命对象增加了官僚资本主义）
- 《论人民民主专政》：总结出工人阶级（经过共产党）领导的、以工农联盟为基础的人民民主专政；它与七届二中全会决议共同构成《共同纲领》的基础
- 《论十大关系》：以苏为鉴，探索中国自己的社会主义建设道路；基本方针是调动一切积极因素为社会主义服务；第一大关系是重工业、轻工业和农业的关系；为八大召开作理论准备
- 《关于正确处理人民内部矛盾的问题》：形成系统的社会主义社会矛盾学说——社会主义基本矛盾「又相适应又相矛盾」；正确处理人民内部矛盾是社会主义国家政治生活的主题，根本着眼点是调动一切积极因素

命名节点：毛泽东思想在**中共七大**被确立为党的指导思想。

## 二、三大辨析（成套出现时逐项核对出处）

**三大优良作风**（七大《论联合政府》概括）：理论联系实际、密切联系群众、批评与自我批评。

**三大法宝**（《〈共产党人〉发刊词》提出）：统一战线、武装斗争、党的建设——党在中国革命中战胜敌人的三个主要法宝。

**工农武装割据**（井冈山斗争时期形成）：土地革命、武装斗争、农村革命根据地建设三者结合；走农村包围城市道路，根本在于处理好三者关系。

**活的灵魂**（十一届六中全会《决议》概括）：实事求是、群众路线、独立自主；其中**实事求是是基本点、是精髓**，也是党的思想路线的核心。

辨析要点：作风出自七大报告，法宝出自《发刊词》，活的灵魂出自十一届六中全会决议——出处年份是常见的设错点。

## 三、马克思主义中国化速查

- 党一开始就坚持了马克思主义中国化的正确方向；党领导的改革开放从一开始就具有明确的社会主义方向。
- 根本途径是「两个结合」：同中国具体实际相结合、同中华优秀传统文化相结合。
- 毛泽东的名言定位：用马克思主义之「矢」去射中国革命之「的」——讲的正是中国化的方法论。
