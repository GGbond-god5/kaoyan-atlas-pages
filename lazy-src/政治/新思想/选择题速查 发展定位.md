# 选择题速查 · 高质量发展与新发展格局定位组

新思想经济部分的选择题爱把「必由之路、主线、战略基点、最终目的」等定位词成组打乱。这篇集中列两组定位，与「必背要点 新思想」的分块背诵互补。

## 一、高质量发展五定位

| 问法 | 答案 |
| --- | --- |
| 必由之路 | 加快实现高水平科技自立自强 |
| 主线 | 深化供给侧结构性改革 |
| 必然要求 | 推进农业现代化 |
| 战略基点 | 加快构建新发展格局 |
| 最终目的 | 人民幸福安康 |

总定位先行：高质量发展是全面建设社会主义现代化国家的**首要任务**，是新时代经济社会发展的鲜明主题。

## 二、新发展格局定位组

- 基本立足点：**满足国内需求**
- 战略基点：**扩大内需**（注意与上表「构建新发展格局是高质量发展的战略基点」互为表里，两问两答不要混）
- 主线：深化供给侧结构性改革（与经济建设主线一致）
- 战略方向：坚持供给侧结构性改革
- 关键：**经济循环畅通无阻**
- 战略支撑：科技自立自强
- 最本质的特征：**实现高水平的自立自强**
- 格局本身：以国内大循环为主体、国内国际双循环相互促进

## 三、易混点提示

- 「主线」在三个语境里答案不同：经济建设的主线是供给侧结构性改革；全面深化改革开放的主线是制度建设；中国特色大国外交的主线是服务民族复兴、促进人类进步。看清问的是哪条线再选。
- 「战略基点」出现两次：高质量发展的战略基点是构建新发展格局；构建新发展格局的战略基点是扩大内需。
