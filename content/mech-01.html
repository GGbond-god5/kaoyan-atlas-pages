[[K-kp-01]]
01

任务与基本假设

基础中频

材料力学研究构件在强度、刚度、稳定性三方面的要求。四大基本假设是全部公式的前提：连续性、均匀性、各向同性、小变形。小变形假设使平衡方程可以按变形前尺寸建立，也让叠加原理成立；一旦题目出现大变形或柔性构件，这些前提要重新检查。

强度：构件不发生破坏对应 \(\sigma\le[\sigma]\)
刚度：变形在允许范围内对应位移、转角限值
稳定性：受压杆不突然失稳对应压杆稳定校核
同型 807 概念题

简答：为什么要引入小变形假设？它对平衡方程和叠加原理分别有什么影响？

要点 小变形下变形量与构件尺寸相比很小，可按变形前几何建立平衡方程；同时内力与变形近似线性，多个载荷的共同响应可叠加。
完整解答
  1. 定义：变形量远小于构件尺寸，通常小于 1/1000。
  2. 对平衡：按变形前几何列方程，忽略位移高阶项。
  3. 对叠加：线弹性 + 小变形使响应与外载成线性，可叠加。
  4. 结论：两条假设是材料力学全部公式的前提；大变形或柔性构件需另建模型。
易错
  • 把“均匀性”和“各向同性”混为一谈：前者指材料各处相同，后者指各方向相同。
  • 认为小变形假设只影响几何，不影响物理关系。
讲法
瞌睡哥概念题只背“四个假设 + 三个要求”，并用一句话解释每个假设的用途。

02

内力与截面法

核心必考

内力是构件内部相邻部分之间的相互作用力。求内力的唯一通用方法是截面法：假想截开、取一侧、用平衡方程求未知内力。截面可以取在任意位置，结果与取哪一侧无关；但截面必须垂直于杆轴或按题目要求取斜截面。后续轴力图、扭矩图、剪力图弯矩图都是截面法的重复使用。

\(\sum F=0,\quad \sum M=0\)（对截开后的隔离体）先画受力图，再列方程
\(F_N,\ F_S,\ T,\ M\)四种基本内力分量
同型 807 高频前置步骤

任意一道大题的第一步：取隔离体、画受力图、求支座反力与内力。

要点 截开后必须画出全部未知内力，方向先假设；解出负值说明实际方向与假设相反，不要直接改方程。
完整解答
  1. 取隔离体，画全部外力与约束反力，未知力先设正方向。
  2. 列整体或局部平衡方程。
  3. 截开求内力，画轴力/剪力/弯矩图。
  4. 负号表示实际方向与假设相反，保留负号继续算。
  5. 校核：整体与局部平衡一致。
易错
  • 截开后漏画内力或支座反力。
  • 把内力与外力混在一起列平衡。
讲法
瞌睡哥截面法三句话：截开、代力、平衡；每道题都从这三步开始。

03

应力与应变

核心必考

应力是内力在截面上的分布集度，正应力垂直于截面、切应力平行于截面；应变是变形的集度，线应变描述长度改变，切应变描述直角改变。应力 × 面积 = 内力，应变 × 长度 = 变形，这两组关系是连接“力”与“变形”的桥梁。

\(\sigma=\lim\limits_{\Delta A\to0}\dfrac{\Delta F_N}{\Delta A}\)正应力，拉为正
\(\tau=\lim\limits_{\Delta A\to0}\dfrac{\Delta F_S}{\Delta A}\)切应力，方向沿截面
\(\varepsilon=\dfrac{\Delta l}{l},\quad \gamma=\dfrac{\Delta s}{h}\)线应变与切应变，均为无量纲
同型 807 概念题

说明正应力与切应力的方向区别，并指出线应变与切应变分别对应哪种变形。

要点 正应力沿截面法线，引起长度改变（线应变）；切应力沿截面切线，引起直角改变（切应变）。
完整解答
  1. 正应力沿截面法线，对应线应变 \(\varepsilon=\Delta l/l\)。
  2. 切应力沿截面切线，对应切应变 \(\gamma\)（直角改变）。
  3. 正应力改变长度与体积，切应力改变形状。
  4. 结论：两者是应力状态的不同分量，组合时不能直接相加。
易错
  • 把应力单位写成 N（应为 Pa 或 MPa）。
  • 认为切应变有单位；弧度是无量纲的。
讲法
瞌睡哥用“正应力拉长、切应力错动”建立直觉，再记定义。

04

杆件的基本变形

基础中频

四种基本变形：轴向拉压、剪切、扭转、弯曲。组合变形是两种或多种基本变形的叠加。判断变形类型的关键看外力作用方式：沿轴线拉压、横向力剪切、力偶绕轴线扭转、横向力或力偶使轴线弯曲。807 的组合变形题，第一步就是拆成基本变形。

拉压：外力沿轴线轴力 \(F_N\)
扭转：外力偶绕轴线扭矩 \(T\)
弯曲：横向力或力偶使轴线弯曲剪力 \(F_S\)、弯矩 \(M\)
同型 807 题

给出几种构件受力图，要求判断属于哪种基本变形或哪几种变形的组合。

要点 先看外力是否通过轴线、是否产生扭矩、是否使轴线弯曲；偏心拉力 = 拉压 + 弯曲，横向力 + 扭矩 = 弯扭组合。
完整解答
  1. 看外力是否沿轴线：是→拉压。
  2. 看外力偶是否绕轴线：是→扭转。
  3. 看横向力或力偶是否使轴线弯曲：是→弯曲。
  4. 偏心或斜向力先向形心简化，再分解为基本变形组合。
  5. 结论：先分解，后判断。
易错
  • 看到斜杆就判为拉压，忽略横向分力产生的弯曲。
  • 把偏心压力只当压缩，漏掉附加弯矩。
讲法
瞌睡哥组合变形先拆后叠，拆的依据就是外力对轴线的位置与方向。

05

力学简图与支座简化

核心高频

力学简图是把实际结构抽象为杆、梁、板等元件，并把连接简化为支座与节点。常见支座：固定铰支座（两个反力分量）、可动铰支座（一个法向反力）、固定端（两个反力 + 一个反力偶）。简化的合理性决定计算模型是否可用；807 题目通常已给出简图，但要求考生正确识别约束类型与反力个数。

固定铰：F_x, F_y限制两个方向移动
可动铰：F_y只限制法向移动
固定端：F_x, F_y, M限制移动与转动
同型 807 题

给出含固定铰、可动铰、固定端的组合结构，要求判断超静定次数。

要点 先数未知反力，再数独立平衡方程（平面一般力系 3 个）；差值即超静定次数。固定端提供 3 个反力，是常见的“多余约束”来源。
完整解答
  1. 数未知反力：固定端 3 个，固定铰 2 个，可动铰 1 个。
  2. 数独立平衡方程：平面一般力系 3 个。
  3. 超静定次数 = 未知反力数 − 独立平衡方程数。
  4. 结论：固定端、多支座是常见的多余约束来源。
易错
  • 把固定铰当成固定端，多算一个反力偶。
  • 可动铰方向判断错误，导致反力方向错。
讲法
瞌睡哥画简图时先标约束、再标反力，最后检查未知力个数与方程个数。

06

外力分类与内力分量

基础中频

外力分为集中力、集中力偶、分布载荷；按时间分为静载与动载。空间受力杆件横截面上一般有六个内力分量：轴力、两个剪力、扭矩、两个弯矩。807 以平面问题为主，通常只出现轴力、剪力、弯矩、扭矩四个分量，但组合变形题要能说清每个分量的来源。

\(q(x)\)：分布载荷集度均布、线性分布常见
\(F_N,\ F_{Sy},\ F_{Sz},\ T,\ M_y,\ M_z\)空间一般情况下的六个内力分量
同型 807 概念题

说明集中力、分布载荷、集中力偶在剪力图与弯矩图上分别产生什么特征。

要点 集中力使剪力图突变、弯矩图折角；分布载荷使剪力斜变、弯矩抛物线；集中力偶使弯矩图突变、剪力图不变。
完整解答
  1. 集中力处：剪力图突变，突变值等于该力；弯矩图折角。
  2. 分布载荷段：剪力线性变化，弯矩抛物线。
  3. 集中力偶处：弯矩图突变，剪力图不变。
  4. 结论：用这些特征快速校核手画图形。
易错
  • 把分布载荷的合力位置取错（应作用在分布区域形心）。
  • 忘记集中力偶只影响弯矩、不影响剪力。
讲法
瞌睡哥外力与内力图的对应关系要背成表，画图前先标外力。
[[K-kp-07]]
07

叠加原理与适用条件

进阶中频

在线弹性、小变形条件下，多个载荷共同作用产生的内力、应力、变形等于各载荷单独作用时的代数和。叠加原理是组合变形、叠加法求挠度、超静定分解的共同基础。使用时必须保证同一坐标、同一符号规定，并且每个分载荷下的响应都在线弹性范围内。

\(\sigma=\sum_i \sigma_i,\quad \Delta=\sum_i \Delta_i\)线弹性、小变形下成立
\(\sigma\le\sigma_p\)适用条件：线弹性、小变形
同型 807 题

为什么组合变形可以拆成几个基本变形分别计算再叠加？

要点 因为材料在线弹性范围内、变形很小，内力与变形对外载荷是线性的；各基本变形在同一截面上产生的同种应力可直接代数相加。
完整解答
  1. 线弹性、小变形时，内力、应力、位移与外载成线性。
  2. 各基本变形在同一截面产生同种应力分量。
  3. 分别计算后在对应点代数相加。
  4. 结论：不同种应力（正/切）不能直接相加，需先求主应力。
易错
  • 在不同符号规定下直接相加。
  • 把叠加用于非线性（如稳定、塑性）问题。
讲法
瞌睡哥叠加前先统一正方向；组合变形章节会反复用到这一条。
[[T-topic-01]]
专题 01

受力图标准化画法：五步不出错

807 每道大题的第一步都是受力图。受力图画错，后面的平衡方程、内力图、强度校核全部作废；而受力图本身是可以在 30 秒内做到零失误的。

  1. 取隔离体：明确研究对象，把它从周围结构中“切”出来。
  2. 画主动力：集中力、分布载荷、力偶，按题目给定方向与位置画。
  3. 画约束反力：固定铰两个分量、可动铰一个法向、固定端两个分量 + 一个力偶。
  4. 检查未知力个数：与独立平衡方程数比较，判断是否超静定。
  5. 标正方向与符号：所有未知力先按正方向假设，解出负值再解释。
例

简支梁一端固定铰、一端可动铰，受均布载荷 q 和跨中集中力 F，画受力图并判断超静定次数。

解 固定铰画 F_Ax、F_Ay，可动铰画 F_By；未知力 3 个，平面一般力系独立方程 3 个，静定。均布载荷合力 ql 作用在跨中。

踩坑点 不要漏画固定端的反力偶；也不要把可动铰画成两个分量——这两处是超静定次数判断错误的主要来源。
