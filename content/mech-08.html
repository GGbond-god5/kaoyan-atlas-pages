组合变形的分类与叠加

核心必考

组合变形是两种或多种基本变形同时存在。处理原则：先分解、再分别计算、最后在同一危险点叠加。分解的依据是外力对轴线的位置与方向；叠加的前提是线弹性、小变形。常见组合：斜弯曲、拉弯、偏压、弯扭。

\(\sigma=\sigma_1+\sigma_2+\cdots\)同一点同方向的正应力代数相加
\(\tau=\tau_1+\tau_2+\cdots\)同一点同方向的切应力代数相加
同型 807 高频题型

给出几种受力构件，要求判断组合变形类型并说明分解方式。

要点 偏心拉力 = 轴向拉 + 弯曲；横向力 + 扭矩 = 弯曲 + 扭转；斜向力 = 两个方向的弯曲（斜弯曲）。
完整解答
  1. 偏心拉力：把力向形心简化，得轴力 \(F\) 与弯矩 \(M=Fe\)。
  2. 横向力 + 扭矩：分解为弯曲与扭转。
  3. 斜向力：分解为两个主平面内的分力，得到两个方向弯矩（斜弯曲）。
  4. 判断危险点：各基本变形产生的同种应力在同一点代数相加。
  5. 结论：先简化，再分解，最后叠加。
易错
  • 把不同点的应力直接相加。
  • 把不同方向的应力（正应力与切应力）直接代数相加。
讲法
瞌睡哥组合变形先画“分解图”：把外力拆成沿轴线、横向、扭转三组，再逐组算。

02

斜弯曲

核心高频

横向力不通过截面主惯性轴时，梁在两个主平面内同时弯曲，称为斜弯曲。任一点正应力为两个方向弯曲正应力的代数和：\(\sigma=M_z y/I_z+M_y z/I_y\)。中性轴不再水平，而是过形心的一条斜线；最大应力在离中性轴最远的角点。

\(\sigma=\dfrac{M_z y}{I_z}+\dfrac{M_y z}{I_y}\)两个方向弯矩的叠加
\(\tan\varphi=\dfrac{M_y I_z}{M_z I_y}\)中性轴方位
\(\sigma_{\max}=\dfrac{M_z}{W_z}+\dfrac{M_y}{W_y}\)矩形截面角点
同型 807 题

矩形截面悬臂梁受斜向集中力，求固定端最大正应力。

要点 把力分解为两个主平面内的分力，分别求固定端弯矩；两个方向的最大应力在同一个角点同号相加，取该角点计算。
完整解答
  1. 把斜向力分解为沿两个主惯性轴的分力 \(P_y,P_z\)。
  2. 固定端弯矩 \(M_z=P_y l\)、\(M_y=P_z l\)（按右手定则定正负）。
  3. 任一点应力 \(\sigma=M_y z/I_y+M_z y/I_z\)。
  4. 最大应力在四个角点之一，比较同号相加的角点。
  5. 中性轴满足 \(\sigma=0\)，为一条过形心的直线，据此判断拉压区。
易错
  • 把两个方向的弯矩直接求矢量和后除以一个 W。
  • 最大应力角点选错（应取两个方向应力同号的角点）。
讲法
瞌睡哥斜弯曲找“同号角点”：两个方向都产生拉应力的那个角，才是危险点。

03

拉（压）弯组合

核心必考

轴向力与横向力同时作用时，横截面上正应力为轴力引起的均匀应力与弯矩引起的线性应力之和。危险点在弯曲应力与轴力同号的一侧；若轴力为压，另一侧可能出现拉应力，脆性材料要分别校核。

\(\sigma=\dfrac{F_N}{A}\pm\dfrac{M}{W}\)拉弯或压弯组合
\(\sigma_{\max}=\dfrac{F_N}{A}+\dfrac{M}{W}\le[\sigma_t]\)受拉侧
\(\sigma_{\min}=\dfrac{F_N}{A}-\dfrac{M}{W}\ge-[\sigma_c]\)受压侧
同型 807 高频题型

矩形截面杆受偏心拉力，求最大拉应力与最大压应力。

要点 偏心拉力可分解为轴心拉力与弯矩；\(\sigma=F/A\pm Fe/W\)，一侧相加、一侧相减，分别与许用拉/压应力比较。
完整解答
  1. 偏心拉力向形心简化：轴力 \(F\) 与弯矩 \(M=Fe\)。
  2. 截面应力 \(\sigma=F/A\pm Fe/W\)。
  3. 靠近偏心一侧为拉应力叠加，另一侧为拉压相减。
  4. 分别求最大拉应力与最大压应力（或最小拉应力）。
  5. 与许用拉、压应力分别比较；脆性材料尤其注意压应力。
易错
  • 漏掉轴力项，只算弯曲。
  • 压弯构件只校核压应力，忽略另一侧可能出现的拉应力。
讲法
瞌睡哥拉弯组合先画应力分布图：一条水平线（轴力）加一条斜线（弯矩），叠加后一眼看出危险侧。

04

偏心压缩与截面核心

进阶高频

偏心压力可分解为轴心压力与两个方向弯矩。当偏心距较小时，整个截面仍受压；偏心距增大到某一临界值时，中性轴开始穿过截面，出现拉应力。截面核心是使中性轴不穿过截面的偏心压力作用区域；矩形截面的核心是菱形，对角线长度分别为 \(b/3\) 与 \(h/3\)。

\(\sigma=-\dfrac{F}{A}\pm\dfrac{F e_y y}{I_z}\pm\dfrac{F e_z z}{I_y}\)偏心压缩
\(\dfrac{e_y y_0}{i_z^2}+\dfrac{e_z z_0}{i_y^2}=1\)中性轴方程
\(e\le\dfrac{h}{6}\)矩形截面单向偏心时核心边界
同型 807 题

矩形截面短柱受偏心压力，问偏心距多大时截面开始出现拉应力。

要点 令最小应力为零：\(F/A-Fe/W=0\)，得 \(e=W/A=h/6\)；超过此值截面出现拉应力。
完整解答
  1. 令截面最小应力为零：\(\sigma_{\min}=F/A-Fe/W=0\)。
  2. 得 \(e=W/A\)。
  3. 矩形截面 \(W=bh^2/6,\ A=bh\)，故 \(e=h/6\)。
  4. \(e\le h/6\) 时全截面受压；超过则出现拉应力。
  5. 结论：这个范围称为截面核心。
易错
  • 把截面核心与形心混淆。
  • 双向偏心时只考虑一个方向的 \(e/W\)。
讲法
瞌睡哥矩形核心记“h/6、b/6”，圆形核心是直径的 1/4；这是常考结论。

05

弯曲与扭转的组合

核心必考

圆轴同时受弯矩与扭矩时，危险点同时有正应力与切应力，处于平面应力状态。按第三或第四强度理论折算：\(\sigma_{r3}=\sqrt{\sigma^2+4\tau^2}\)，\(\sigma_{r4}=\sqrt{\sigma^2+3\tau^2}\)。圆轴中 \(W_p=2W\)，可化为只含 \(M,T,W\) 的形式。

\(\sigma=\dfrac{M}{W},\quad \tau=\dfrac{T}{W_p}\)圆轴危险点
\(\sigma_{r3}=\dfrac{\sqrt{M^2+T^2}}{W}\)第三强度理论
\(\sigma_{r4}=\dfrac{\sqrt{M^2+0.75T^2}}{W}\)第四强度理论
真题 2025 · 807 计算（25 分）

实心圆轴受弯扭组合，表面测点应变已知，要求按第三强度理论校核。

要点 先由应变求正应力与切应力（或由 M、T 直接算），再代入 \(\sqrt{\sigma^2+4\tau^2}\le[\sigma]\)；注意 \(\tau=T/W_p\)，不是 \(T/W\)。
完整解答
  1. 由测点应变用广义胡克定律求 \(\sigma,\tau\)，或直接由 \(M,T\) 计算。
  2. 圆轴 \(\sigma=M/W\)，\(\tau=T/W_p=T/(2W)\)。
  3. 主应力 \(\sigma_{1,2}=\frac{\sigma}{2}\pm\sqrt{(\frac{\sigma}{2})^2+\tau^2}\)。
  4. 第三强度理论 \(\sigma_{r3}=\sqrt{\sigma^2+4\tau^2}\)。
  5. 与许用应力比较并给出结论。
易错
  • 切应力用 \(W\) 而不是 \(W_p\)。
  • 第三与第四强度理论的系数用反。
讲法
瞌睡哥圆轴弯扭组合是送分模板：先写 \(\sigma=M/W\)、\(\tau=T/(2W)\)，再套 \(\sqrt{\sigma^2+4\tau^2}\)。

组合变形强度计算流程

核心必考

固定五步：分解外力 → 画内力图（各基本变形分别画）→ 确定危险截面 → 确定危险点 → 按应力状态选择强度理论校核。每一步都要写清楚，807 的过程分主要在这里。

分解 → 内力图 → 危险截面 → 危险点 → 强度理论固定流程，按顺序写步骤
同型 807 高频题型

给出弯扭组合轴，要求完整写出强度校核过程。

要点 分解为弯曲与扭转；分别画 M 图、T 图；取 M、T 同时较大的截面；危险点在截面边缘；按第三强度理论写相当应力并比较。
完整解答
  1. 把载荷分解为弯曲与扭转，分别画 \(M\) 图、\(T\) 图。
  2. 选 \(M\)、\(T\) 同时较大的截面为危险截面。
  3. 危险点在圆截面边缘，正应力与切应力同时最大。
  4. 按第三或第四强度理论写相当应力。
  5. 与许用应力比较；若不合格，调整直径或材料。
易错
  • 危险截面只按 M 最大取，忽略 T 也较大的截面。
  • 危险点取在中性轴（切应力最大但正应力为零），没有按强度理论综合判断。
讲法
瞌睡哥组合变形的答案要像流程图一样写，阅卷老师能顺着步骤给分。

斜弯曲：空间弯矩的分解与叠加

进阶高频

斜向力不过主轴时，先向形心简化，分解为两个主平面内的分力，分别产生 \(M_z\)、\(M_y\)；任一点正应力为两项代数和，最大应力在角点。中性轴仍过形心，但不一定与主轴重合。

\(M_z=Pl\cos\theta,\quad M_y=Pl\sin\theta\)悬臂梁固定端
\(\sigma=\dfrac{M_z y}{I_z}+\dfrac{M_y z}{I_y}\)任一点，注意正负
\(\sigma_{\max}=\dfrac{M_z}{W_z}+\dfrac{M_y}{W_y}\)角点同号相加
\(\tan\beta=\dfrac{M_y I_z}{M_z I_y}\)中性轴斜率（按坐标约定取符号）
同型 807 题

矩形截面悬臂梁宽 \(b\)、高 \(h\)、长 \(l\)，自由端作用斜向力 \(P\)，与 \(y\) 轴夹角 \(\theta\)，求固定端最大正应力与中性轴位置。

要点 \(\sigma_{\max}=\dfrac{6Pl\cos\theta}{bh^2}+\dfrac{6Pl\sin\theta}{hb^2}\)，中性轴过形心，斜率由 \(\tan\beta=\dfrac{M_yI_z}{M_zI_y}\) 确定。
完整解答
  1. 把 \(P\) 分解为 \(P_y=P\cos\theta\)、\(P_z=P\sin\theta\)。
  2. 固定端弯矩 \(M_z=P_y l=Pl\cos\theta\)，\(M_y=P_z l=Pl\sin\theta\)。
  3. 截面系数 \(W_z=bh^2/6\)、\(W_y=hb^2/6\)；角点应力 \(M_z/W_z+M_y/W_y\)。
  4. 取两项同号的角点为危险点，得 \(\sigma_{\max}\)。
  5. 令 \(\sigma=0\) 得中性轴方程，过形心；据此判断拉压区并校核。
易错
  • 分别算出两个方向的最大应力后取较大者，而不是在同一点相加。
  • 把 \(I_y\) 与 \(I_z\)、\(W_y\) 与 \(W_z\) 对调，导致长边/短边方向错误。
讲法
瞌睡哥空间弯矩先分解到两个主平面，再找四个角点中同号叠加的那个。

专题 01

圆轴弯扭组合：从内力到相当应力

这是 807 出现频率最高的综合题型之一，2025 年以 25 分出现。公式少，但危险点、截面系数、强度理论三处都可能设坑。

  1. 把外力分解为产生弯矩与产生扭矩的两组。
  2. 分别画弯矩图与扭矩图，找 M、T 同时较大的截面。
  3. 在危险截面取边缘点：\(\sigma=M/W\)，\(\tau=T/W_p=T/(2W)\)。
  4. 按材料选第三或第四强度理论。
  5. 写相当应力并与许用应力比较，注明控制因素。
例

实心圆轴 d=60 mm，M=3 kN·m，T=4 kN·m，[σ]=160 MPa，按第三强度理论校核。

解 \(W=\pi d^3/32=2.12\times10^4\ \text{mm}^3\)，\(\sigma_{r3}=\sqrt{3^2+4^2}\times10^6/2.12\times10^4\approx235\ \text{MPa}>160\)，不安全。

踩坑点 弯矩单位 kN·m 换成 N·mm 要乘 10⁶，不是 10³；这一步错会导致结果差 1000 倍。
[[T-topic-02]]
专题 02

偏心压缩与截面核心

偏心压缩是“拉弯组合”的典型应用，截面核心是概念题与计算题的交汇点，砌体、混凝土柱设计常用。

  1. 把偏心压力平移到形心，得到轴力与两个弯矩。
  2. 写任一点应力表达式，注意拉压符号。
  3. 令最小应力为零，求中性轴恰好过截面边缘的偏心距。
  4. 单向偏心时核心边界为 \(e=h/6\)；双向偏心按中性轴方程求。
  5. 判断偏心距是否在核心内：在核心内全截面受压。
例

矩形截面柱 b×h，偏心压力作用在 h 方向，求截面不出现拉应力的最大偏心距。

解 \(\sigma_{\min}=-F/(bh)+Fe/(bh^2/6)=0\)，得 \(e=h/6\)；这就是矩形截面单向偏心的核心边界。

踩坑点 截面核心是“压力作用点”的区域，不是截面内的某个面积；不要把核心面积与截面面积混淆。
[[T-topic-03]]
专题 03

空间弯矩分解与斜弯曲

807 组合变形常把“斜向力/偏心”与“弯扭组合”放在一起。空间弯矩的难点不是公式，而是分解方向与正负号。

  1. 把力向截面形心简化，得到轴力、剪力、扭矩与两个弯矩。
  2. 选主惯性轴 \(y,z\)，把弯矩分解为 \(M_y\)、\(M_z\)。
  3. 分别写 \(\sigma=M_yz/I_y\) 与 \(\sigma=M_zy/I_z\)。
  4. 在四个角点中找两项同号的点，求最大应力。
  5. 令 \(\sigma=0\) 求中性轴，判断拉压区与危险点。
例

斜弯曲的中性轴为什么一定过形心？

解 应力表达式是 \(y,z\) 的齐次线性式，\(y=z=0\) 时 \(\sigma=0\)，故中性轴过形心；其方向由两向弯矩与惯性矩之比决定。

踩坑点 不要把“两个方向的最大应力”分别算完取大；最大应力发生在同一点两项同号相加处。
