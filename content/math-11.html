01

线性组合与线性表示

核心必考

向量 \(\beta\) 能由 \(\alpha_{1},\dots,\alpha_{s}\) 线性表示，等价于方程组 \(x_{1}\alpha_{1}+\cdots+x_{s}\alpha_{s}=\beta\) 有解，也等价于 \(r(\alpha_{1},\dots,\alpha_{s})=r(\alpha_{1},\dots,\alpha_{s},\beta)\)。把“表示”翻译成“方程组有解”，是所有向量题的起手式。

\(\beta=k_{1}\alpha_{1}+\cdots+k_{s}\alpha_{s}\)存在一组系数
\(r(A)=r(A\mid\beta)\Leftrightarrow\) 可表示判定核心
\(r(A)=r(A\mid\beta)=s\Leftrightarrow\) 表示唯一系数唯一
同型 数一

给出四个三维向量，问 \(\beta\) 能否由其余向量线性表示；若能，写出表达式。

要点 以向量为列构造 \(A\) 与 \((A\mid\beta)\)，同时行变换化为阶梯形：秩相等则可表示；再把自由未知量取零求一组特解作为系数。
完整解答
  1. 目标：判断 \(\beta\) 能否由 \(\alpha_i\) 线性表示。
  2. 以 \(\alpha_i\) 为列拼 \(A\)，再拼增广矩阵 \((A\mid\beta)\)。
  3. 对 \((A\mid\beta)\) 行变换化阶梯形，比较 \(r(A)\) 与 \(r(A\mid\beta)\)。
  4. 若秩相等，继续化行最简形，读出 \(\beta\) 的坐标 \(x\)。
  5. 写出 \(\beta=x_1\alpha_1+\dots+x_n\alpha_n\)，并代回验证。
易错
  • 只比较 \(r(A)\) 与 \(r(A\mid\beta)\) 的大小，不比较是否等于 \(s\)，无法判断唯一性。
  • 把行向量与列向量混着拼矩阵。
讲法
武忠祥向量表示题一律“列拼矩阵、行变换、看秩”，不要试图观察凑系数。

线性相关与线性无关

核心必考

线性相关等价于齐次方程组 \(Ax=0\) 有非零解，等价于 \(r(\alpha_{1},\dots,\alpha_{s})<s\)。向量个数大于维数必相关；部分相关则整体相关，整体无关则部分无关。这些结论是选择题的送分点，也是证明题的推理链。

\(\alpha_{1},\dots,\alpha_{s}\ \text{无关}\Leftrightarrow r(A)=s\)\(A\) 以它们为列
\(s>n\Rightarrow\) 必相关n 为向量维数
\(A\ \text{可逆}\Leftrightarrow A\ \text{的列向量组无关}\)方阵情形
同型 数一

设 \(\alpha_{1},\alpha_{2},\alpha_{3}\) 线性无关，判断 \(\alpha_{1}+\alpha_{2},\ \alpha_{2}+\alpha_{3},\ \alpha_{3}+\alpha_{1}\) 是否线性无关。

要点 设组合为零，整理得 \((k_{1}+k_{3})\alpha_{1}+(k_{1}+k_{2})\alpha_{2}+(k_{2}+k_{3})\alpha_{3}=0\)；由原组无关得齐次方程组，其系数行列式为 2，只有零解，故新组无关。
完整解答
  1. 目标：判断 \(\alpha_1+\alpha_2,\ \alpha_2+\alpha_3,\ \alpha_3+\alpha_1\) 是否线性无关。
  2. 设 \(k_1(\alpha_1+\alpha_2)+k_2(\alpha_2+\alpha_3)+k_3(\alpha_3+\alpha_1)=0\)。
  3. 整理得 \((k_1+k_3)\alpha_1+(k_1+k_2)\alpha_2+(k_2+k_3)\alpha_3=0\)。
  4. 因 \(\alpha_i\) 线性无关，系数全为零，得方程组；其系数行列式为 \(2\ne0\)。
  5. 故只有零解 \(k_1=k_2=k_3=0\)，三个和向量线性无关。
易错
  • 认为“相关”就是“有向量是零向量”。
  • 把 \(r(A)=s\) 与 \(r(A)=n\) 混淆。
讲法
张宇判断新向量组的相关性，先写“设组合为零”，再用原组无关拆方程；这是唯一稳妥的证明路径。

极大无关组与向量组的秩

核心高频

极大无关组是“能代表全组、且自身无关”的部分组；所含向量个数就是秩。求法：把向量按列拼成矩阵，行变换化阶梯形，主元所在列对应的原向量构成极大无关组。注意是原向量，不是阶梯形里的列。

\(r(\alpha_{1},\dots,\alpha_{s})=\dim\operatorname{span}\{\alpha_{i}\}\)秩即张成空间维数
\(r(A)=r(A^{T})\)行秩等于列秩
同型 数一

给出四个四维向量，求向量组的秩与一个极大无关组，并把其余向量用其表示。

要点 列拼矩阵化行最简形；主元列编号对应原向量即极大无关组；非主元列在行最简形中读出组合系数，直接写成用极大无关组表示。
完整解答
  1. 目标：求秩、极大无关组，并表示其余向量。
  2. 把四个向量按列拼成矩阵 \(A\)，行变换化行最简形。
  3. 主元所在的列编号对应原向量，构成一个极大无关组。
  4. 非主元列在行最简形中的系数，就是该向量用极大无关组表示的系数。
  5. 写出表达式并代回验证；秩等于主元个数。
易错
  • 把阶梯形矩阵中非零行的向量当作极大无关组。
  • 求组合系数时用了行变换后的向量而非原向量。
讲法
没咋了“主元列回原矩阵取向量”这句话要背下来，考场上能省五分钟。

向量空间：基、维数与坐标

进阶中频

数一独有考点。向量空间的基是极大无关组，维数是秩；同一向量在不同基下坐标不同，过渡矩阵把两组基连起来。考法集中在“求基、求维数、求坐标、写过渡矩阵”，难度不大但容易漏步骤。

\((\beta_{1},\dots,\beta_{n})=(\alpha_{1},\dots,\alpha_{n})C\)\(C\) 为过渡矩阵
\([x]_{\alpha}=C\,[x]_{\beta}\)坐标变换
\(\dim\operatorname{span}\{\alpha_{i}\}=r(\alpha_{1},\dots,\alpha_{s})\)维数即秩
同型 数一

已知两组基，求过渡矩阵，并求某向量在新基下的坐标。

要点 把两组基分别按列拼成矩阵 \(A,B\)，解 \(B=AC\) 得 \(C=A^{-1}B\)；坐标满足 \(x_{\alpha}=Cx_{\beta}\)，代入求解。
完整解答
  1. 目标：求过渡矩阵与新坐标。
  2. 两组基按列拼成 \(A,B\)，设 \(B=AC\)。
  3. 则过渡矩阵 \(C=A^{-1}B\)，用行变换解 \(AC=B\)。
  4. 若 \(\beta=Ax_A=Bx_B\)，则 \(x_B=C^{-1}x_A\)。
  5. 代回 \(\beta=Bx_B\) 验证。
易错
  • 过渡矩阵方向写反，\(C\) 与 \(C^{-1}\) 混用。
  • 把维数当成向量个数。
讲法
武忠祥过渡矩阵只记一个式子 \(B=AC\)，方向就不会错。

齐次方程组的基础解系

核心必考

\(Ax=0\) 的基础解系含 \(n-r(A)\) 个线性无关的解向量，通解是它们的任意线性组合。求法固定：行变换化行最简形，主元变量用自由变量表示，自由变量依次取单位向量，得到基础解系。

\(\dim N(A)=n-r(A)\)解空间维数
\(x=k_{1}\xi_{1}+\cdots+k_{n-r}\xi_{n-r}\)通解
\(Ax=0\ \text{有非零解}\Leftrightarrow r(A)<n\)方阵时即 \(|A|=0\)
同型 数一

求四元齐次方程组的基础解系并写出通解。

要点 系数矩阵化行最简形，确定主元列与自由变量；自由变量取 \((1,0),(0,1)\) 两组，回代求主元变量，得到两个解向量；通解为二者线性组合。
完整解答
  1. 目标：求齐次方程组的通解。
  2. 系数矩阵行变换化行最简形，确定主元列与自由变量。
  3. 自由变量依次取 \((1,0),(0,1)\)，回代求主元变量。
  4. 得到两个线性无关的解向量 \(\xi_1,\xi_2\)，即基础解系。
  5. 通解 \(x=c_1\xi_1+c_2\xi_2\)；维数 \(n-r(A)=2\)。
易错
  • 基础解系向量个数写成 \(r(A)\)。
  • 自由变量取值重复，导致解向量线性相关。
讲法
张宇基础解系必须“个数对、线性无关、都是解”三条同时满足，写完要自查。

非齐次方程组解的结构

核心必考

\(Ax=b\) 的通解 = 一个特解 + 对应齐次方程组的通解。几何上是一条不过原点的仿射子空间。求解顺序：先判有解（\(r(A)=r(A\mid b)\)），再求特解，最后叠加齐次通解。

\(x=\eta^{*}+k_{1}\xi_{1}+\cdots+k_{n-r}\xi_{n-r}\)\(\eta^{*}\) 为特解
\(r(A)=r(A\mid b)=n\Leftrightarrow\) 唯一解满秩
\(r(A)=r(A\mid b)<n\Leftrightarrow\) 无穷多解含自由变量
同型 数一

已知非齐次方程组有无穷多解，求参数并写出通解。

要点 对增广矩阵行变换，令 \(r(A)=r(A\mid b)<n\) 定参数；取自由变量为零求特解，再求齐次基础解系，最后相加。
完整解答
  1. 目标：由无穷多解定参数并写通解。
  2. 对增广矩阵行变换，令 \(r(A)=r(A\mid b)<n\)。
  3. 由秩条件解出参数，并确认最后一行为 \(0=0\)。
  4. 令自由变量为 0，回代得特解 \(\eta^*\)。
  5. 再解对应齐次组得基础解系，通解 \(x=\eta^*+c_1\xi_1+\dots\)。
易错
  • 忘记先判 \(r(A)\) 与 \(r(A\mid b)\) 是否相等。
  • 把两个特解相加当作通解。
讲法
没咋了非齐次题按“判解—特解—齐次通解—相加”四步走，顺序不能乱。

解的判定与含参数讨论

核心必考

含参数方程组是数一解答题的常客。标准流程：写增广矩阵、行变换、按参数取值分类讨论秩。参数出现在分母时，必须先讨论是否为零；参数在分子时，按 \(r(A)\) 与 \(n\) 的关系分类。

\(r(A)<r(A\mid b)\Leftrightarrow\) 无解出现 \(0=d,\ d\ne0\)
\(r(A)=r(A\mid b)=n\Leftrightarrow\) 唯一解
\(r(A)=r(A\mid b)<n\Leftrightarrow\) 无穷多解自由度为 \(n-r\)
同型 数一

含参数 \(a\) 的三元线性方程组，问 \(a\) 取何值时有唯一解、无解、无穷多解。

要点 对增广矩阵行变换，令主元表达式为零得到临界值；分别回代判断最后一行是 \(0=0\) 还是 \(0\ne0\)，再确定解的情况。
完整解答
  1. 目标：按参数讨论唯一解、无解、无穷多解。
  2. 对增广矩阵行变换，保留参数，化成阶梯形。
  3. 令主元表达式为零，得到临界参数值。
  4. 逐一回代：最后一行 \(0=d\ne0\) 无解；\(0=0\) 且秩小于未知量个数则无穷多解。
  5. 其余参数值主元非零，唯一解；分别写出结论。
易错
  • 直接把参数当非零约去，漏掉参数为零的分支。
  • 只算 \(|A|=0\) 的根，不回代判断是否有解。
讲法
武忠祥含参数题先问“能不能除”，不能除就分情况；讨论完必须逐个回代验证。

同解方程组与公共解

进阶中频

两个方程组同解，等价于它们的解空间相同，等价于行向量组等价、系数矩阵秩相等且拼起来秩不变。公共解则是两个解空间的交集：把两组方程联立，或设出通解代入另一组。

\(Ax=0\) 与 \(Bx=0\) 同解 \(\Leftrightarrow r(A)=r(B)=r\begin{pmatrix}A\B\end{pmatrix}\)行空间相同
公共解：联立 \(\begin{pmatrix}A\B\end{pmatrix}x=0\)交集即新零空间
同型 数一

已知两个齐次方程组有公共非零解，求参数。

要点 联立系数矩阵，令其秩小于未知量个数，即行列式为零；解出参数后再验证公共解确实非零。
完整解答
  1. 目标：求两齐次方程组有公共非零解的参数条件。
  2. 把两个系数矩阵上下拼成 \(M=\begin{pmatrix}A\B\end{pmatrix}\)。
  3. 公共解即 \(Mx=0\) 的非零解，存在条件为 \(r(M)<n\)。
  4. 令 \(r(M)<n\)（如三阶时 \(|M|=0\)）解出参数。
  5. 代回求公共解并确认非零。
易错
  • 把“同解”等同于“秩相等”，忽略行空间相同。
  • 求公共解时只解其中一个方程组。
讲法
张宇同解看行空间，公共解看交集；两个概念不要混。

专题 01

方程组判定三步法：秩、秩、再秩

数一每年都有一道方程组题，判定环节失分最可惜。三步法把“有解/唯一/无穷”变成机械流程，考场不需要灵感。

  1. 第一步：写出增广矩阵，只做行变换，化行阶梯形；不要做列变换，列变换会改变未知量顺序。
  2. 第二步：比较 \(r(A)\) 与 \(r(A\mid b)\)：不等则无解，相等则有解。
  3. 第三步：若相等，比较 \(r(A)\) 与未知量个数 \(n\)：等于 \(n\) 唯一解，小于 \(n\) 无穷多解，自由度为 \(n-r\)。
  4. 第四步：无穷多解时，化行最简形，写基础解系与特解。
  5. 第五步：含参数时，把主元表达式为零的临界值全部列出，逐个回代。
例

方程组 \(\begin{cases}x_{1}+x_{2}+x_{3}=1\x_{1}+2x_{2}+3x_{3}=2\\2x_{1}+3x_{2}+4x_{3}=a\end{cases}\)，问 \(a\) 为何值时有解。

解 第三行减去前两行之和得 \(0=a-3\)；故 \(a=3\) 时有解，此时 \(r(A)=r(A\mid b)=2<3\)，无穷多解，自由度 1。

踩坑点 行变换时把增广列也做列变换，等于偷偷改了常数项，结论必错。

专题 02

含参数方程组：分类讨论模板

这是数一解答题最稳定的题型，也是最能靠模板拿分的题。讨论不完整是主要失分点。

  1. 先算系数行列式 \(|A|\)（方阵时）：\(|A|\ne0\) 直接唯一解，用克拉默或行变换。
  2. \(|A|=0\) 时，把参数临界值逐个代入增广矩阵，化阶梯形。
  3. 每个临界值下判断最后一行：\(0=0\) 无穷多解，\(0=d\ne0\) 无解。
  4. 无穷多解时写出基础解系，注意自由变量个数。
  5. 最后用一句话汇总：参数取何值对应何种解，写成表格最清楚。
例

方程组系数矩阵含参数 \(\lambda\)，\(|A|=(\lambda-1)(\lambda+2)\)，讨论解的情况。

解 \(\lambda\ne1,-2\)：唯一解；\(\lambda=1\)：代入后若出现 \(0=0\) 则无穷多解，否则无解；\(\lambda=-2\)：同样回代判断。每个临界值都必须单独算，不能凭行列式为零就下结论。

踩坑点 行列式为零只说明“不是唯一解”，并不能区分无解与无穷多解；必须回代。
