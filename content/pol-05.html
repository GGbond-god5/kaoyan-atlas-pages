近代中国社会性质与两大历史任务

核心必考

1840 年鸦片战争后，中国逐步沦为半殖民地半封建社会。主要矛盾是帝国主义与中华民族的矛盾、封建主义与人民大众的矛盾。两大历史任务是争取民族独立、人民解放，实现国家富强、人民幸福；前者是后者的前提。

社会性质：半殖民地半封建社会不是「殖民地」也不是「封建社会」
两大矛盾：帝国主义↔中华民族；封建主义↔人民大众前者最主要
两大任务：独立解放 → 富强幸福先后顺序不能倒
同型 史纲选择题

近代中国社会的两大历史任务是（ ）。

要点 争取民族独立、人民解放；实现国家富强、人民幸福。前者为后者创造前提，后者是前者的最终目的。
完整解答
  1. 两大历史任务是争取民族独立、人民解放。
  2. 以及实现国家富强、人民幸福。
  3. 前者为后者创造前提，后者是前者的最终目的。
  4. 结论：两大任务相互联系。
易错
  • 把社会性质写成「半殖民地半资本主义」。
  • 把两大任务的顺序颠倒，认为可以先富强再独立。
  • 忽略帝国主义与中华民族的矛盾是最主要矛盾。
讲法
腿姐keywords：「半殖民地半封建」八个字完整写；两大任务「先独立、后富强」。

02

旧民主主义革命的探索与失败

核心高频

太平天国（1851—1864）提出《天朝田亩制度》《资政新篇》；洋务运动（1861—1895）以「自强」「求富」为口号；维新变法（1898）试图君主立宪；辛亥革命（1911）推翻君主专制制度。这些探索都未能改变半殖民地半封建社会性质。

太平天国：《天朝田亩制度》+《资政新篇》前者空想，后者未实施
洋务运动：自强（军事）→ 求富（民用）中体西用
辛亥革命：推翻帝制，未改变社会性质成败各一半
同型 史纲选择题

辛亥革命的历史功绩与局限性分别是什么？

要点 功绩：推翻清朝统治，结束两千多年君主专制制度，建立中华民国，传播民主共和观念。局限：没有完成反帝反封建任务，没有改变半殖民地半封建社会性质。
完整解答
  1. 功绩：推翻清朝统治，结束两千多年君主专制制度，建立中华民国，传播民主共和观念。
  2. 局限：没有完成反帝反封建任务。
  3. 没有改变中国半殖民地半封建社会的性质。
  4. 结论：功绩与局限并存。
易错
  • 认为辛亥革命完成了反帝反封建任务。
  • 把《资政新篇》说成太平天国实际实施的政策。
  • 把洋务运动的口号顺序记反（先自强后求富）。
讲法
徐涛用「器物—制度—思想」三层递进解释旧民主主义革命为何失败：只改一层，不动根基。

五四运动与中国共产党成立

核心必考

1919 年五四运动是新民主主义革命的开端，工人阶级开始登上政治舞台，马克思主义在中国广泛传播。1921 年中共一大召开，中国共产党成立，中国革命面貌焕然一新。

五四 1919 = 新民主主义革命开端旧民主主义→新民主主义的分界
中共一大 1921 = 中国共产党成立上海→嘉兴南湖
「焕然一新」：领导力量 · 指导思想 · 革命前途分析题常用
同型 史纲分析题

为什么说五四运动是中国新民主主义革命的开端？

要点 五四运动发生在俄国十月革命之后，以彻底反帝反封建的姿态出现；工人阶级作为独立政治力量登上舞台，马克思主义开始与工人运动结合，为中国共产党成立作了思想上干部上的准备。
完整解答
  1. 五四运动发生在俄国十月革命之后，以彻底反帝反封建的姿态出现。
  2. 工人阶级作为独立政治力量登上舞台。
  3. 马克思主义开始与工人运动结合，为中国共产党成立作了思想上干部上的准备。
  4. 结论：五四运动是新民主主义革命的开端。
易错
  • 把五四运动说成旧民主主义革命的一部分。
  • 把中共一大时间记成 1922 年。
  • 忽略工人阶级登上政治舞台这一关键标志。
讲法
腿姐keywords：五四「开端」、一大「成立」、遵义「转折」，三个定位词不能互换。

04

国民革命、土地革命与长征

基础高频

1924 年国共第一次合作，掀起国民革命；1927 年大革命失败后，党领导南昌起义、秋收起义，开辟井冈山革命根据地，走农村包围城市道路。1934—1936 年红军长征，1935 年遵义会议是党的历史上生死攸关的转折点。

1924 国共合作 → 1927 大革命失败第一次合作
1927 南昌起义 = 武装反抗国民党反动派第一枪8 月 1 日
1935 遵义会议 = 生死攸关的转折点事实上确立毛泽东领导地位
同型 史纲选择题

遵义会议为什么被称为党的历史上生死攸关的转折点？

要点 会议纠正了「左」倾教条主义错误，事实上确立了毛泽东在党中央和红军的领导地位，挽救了党、挽救了红军、挽救了中国革命，是党从幼年走向成熟的重要标志。
完整解答
  1. 会议纠正了“左”倾教条主义错误。
  2. 事实上确立了毛泽东在党中央和红军的领导地位。
  3. 挽救了党、挽救了红军、挽救了中国革命。
  4. 结论：是党从幼年走向成熟的重要标志。
易错
  • 把南昌起义与秋收起义的意义混淆。
  • 把遵义会议说成「确立毛泽东思想为指导思想」（那是 1945 年七大）。
  • 认为农村包围城市道路一开始就被全党接受。
讲法
徐涛用「城市失败—转向农村—长征转折」三步讲清道路探索的曲折。

05

抗日战争

核心必考

1931 年九一八事变后，中国开始局部抗战；1937 年七七事变后进入全民族抗战。抗日民族统一战线正式形成。中国共产党是全民族抗战的中流砥柱。1945 年抗日战争取得胜利，是近代以来中国反抗外敌入侵第一次取得完全胜利的民族解放战争。

1931 九一八 → 局部抗战；1937 七七 → 全民族抗战两个起点
统一战线：国共合作 + 全民族又联合又斗争
1945 胜利 = 近代反侵略第一次完全胜利意义题高频
同型 史纲分析题

为什么说中国共产党是全民族抗战的中流砥柱？

要点 党提出并坚持全面抗战路线，推动建立抗日民族统一战线；开辟敌后战场，开展游击战争；坚持团结抗战、反对分裂投降；在抗战中发挥政治领导作用和先锋模范作用。
完整解答
  1. 党提出并坚持全面抗战路线。
  2. 推动建立抗日民族统一战线。
  3. 开辟敌后战场，开展游击战争。
  4. 坚持团结抗战、反对分裂投降，发挥政治领导作用和先锋模范作用。
易错
  • 把九一八事变当作全民族抗战起点。
  • 忽略敌后战场与正面战场的相互配合。
  • 把抗战胜利仅归因于外部因素。
讲法
腿姐keywords：「中流砥柱」答四点——路线、统一战线、敌后战场、团结抗战。

解放战争与新中国成立

基础高频

1945 年重庆谈判后，1946 年全面内战爆发。1948—1949 年三大战役基本消灭国民党军队主力。1949 年 3 月七届二中全会提出党的工作重心由乡村转移到城市。1949 年 10 月 1 日中华人民共和国成立，标志着新民主主义革命取得基本胜利。

1949.3 七届二中全会：乡村 → 城市工作重心转移
三大战役：辽沈 · 淮海 · 平津顺序常考
1949.10.1 新中国成立 = 新民主主义革命基本胜利不是社会主义革命完成
同型 史纲选择题

新中国成立标志着什么？

要点 标志着新民主主义革命取得基本胜利，中国人民从此站起来了；社会主义制度确立则是 1956 年三大改造基本完成。
完整解答
  1. 新中国成立标志着新民主主义革命取得基本胜利。
  2. 中国人民从此站起来了。
  3. 社会主义制度确立则是 1956 年三大改造基本完成。
  4. 结论：不要把新中国成立与社会主义制度确立混为一谈。
易错
  • 把新中国成立等同于社会主义制度确立。
  • 把三大战役顺序记错。
  • 忽略七届二中全会的工作重心转移。
讲法
徐涛把「建国—改造—制度」三个时间点排成一条线：1949 建国、1953 总路线、1956 制度确立。

社会主义改造与制度确立

核心高频

1953 年提出过渡时期总路线「一化三改」。到 1956 年底，三大改造基本完成，实现了生产资料私有制向社会主义公有制的转变，社会主义基本制度在我国确立，中国进入社会主义社会。

1953 总路线：一化三改工业化 + 三大改造
1956 三大改造完成 = 社会主义制度确立最重要时间点
和平赎买 = 对资本主义工商业的独创区别于暴力剥夺
同型 史纲选择题

我国社会主义基本制度确立的标志是（ ）。

要点 1956 年底生产资料私有制社会主义改造基本完成，社会主义基本制度在我国确立。
完整解答
  1. 1956 年底生产资料私有制的社会主义改造基本完成。
  2. 私有制被改造为社会主义公有制。
  3. 社会主义基本制度在我国确立。
  4. 结论：标志是三大改造基本完成。
易错
  • 把新中国成立当作社会主义制度确立的标志。
  • 把「一化」理解为农业合作化。
  • 认为社会主义改造没有遗留问题。
讲法
腿姐keywords：制度确立只认 1956 年三大改造完成，其他时间一律排除。

改革开放与社会主义现代化建设

核心必考

1978 年 12 月党的十一届三中全会作出把党和国家工作中心转移到经济建设上来、实行改革开放的历史性决策，是新中国成立以来党的历史上具有深远意义的伟大转折。此后开辟了中国特色社会主义道路。

1978 十一届三中全会 = 伟大转折改革开放起点
工作中心：以经济建设为中心取代「以阶级斗争为纲」
道路：中国特色社会主义道路不是封闭僵化，也不是改旗易帜
同型 史纲分析题

为什么说十一届三中全会是新中国成立以来党的历史上具有深远意义的伟大转折？

要点 它重新确立了解放思想、实事求是的思想路线，作出把工作中心转移到经济建设上来、实行改革开放的决策，开启了社会主义现代化建设新时期，开辟了中国特色社会主义道路。
完整解答
  1. 重新确立了解放思想、实事求是的思想路线。
  2. 作出把工作中心转移到经济建设上来、实行改革开放的决策。
  3. 开启了社会主义现代化建设新时期。
  4. 开辟了中国特色社会主义道路，所以是伟大转折。
易错
  • 把十一届三中全会与十二大、十四大的贡献混淆。
  • 把改革开放起点记成 1979 年。
  • 忽略思想路线的重新确立。
讲法
徐涛用「思想路线—政治路线—组织路线」三条线说明「转折」的完整含义。

新时代十年的伟大变革

基础高频

2012 年党的十八大以来，中国特色社会主义进入新时代。2021 年建党百年，全面建成小康社会，历史性地解决了绝对贫困问题。2022 年党的二十大对全面建设社会主义现代化国家、全面推进中华民族伟大复兴作出战略部署。

2012 十八大 → 新时代历史方位
2021 建党百年 → 全面小康绝对贫困问题历史性解决
2022 二十大 → 中国式现代化战略部署最新坐标
同型 史纲选择题

全面建成小康社会、历史性解决绝对贫困问题是在哪一年宣布的？

要点 2021 年，中国共产党成立一百周年之际，我国全面建成小康社会，历史性地解决了绝对贫困问题。
完整解答
  1. 时间是 2021 年。
  2. 正值中国共产党成立一百周年。
  3. 我国全面建成小康社会，历史性地解决了绝对贫困问题。
  4. 结论：2021 年。
易错
  • 把「全面建成小康社会」与「全面建设社会主义现代化国家」混淆。
  • 把新时代起点记成 2017 年十九大。
  • 记错建党百年与二十大年份。
讲法
腿姐keywords：2012 新时代、2021 小康、2022 二十大，三个坐标成串。

历史和人民的选择

核心必考

近代以来的历史证明：历史和人民选择了马克思主义、选择了中国共产党、选择了社会主义道路、选择了改革开放。这「四个选择」是史纲的总收口，也是分析题最稳的结论句。

四个选择：马克思主义 · 中国共产党 · 社会主义 · 改革开放顺序固定
逻辑链：救亡 → 建国 → 制度 → 发展对应四个阶段
结论句：只有……才能……分析题收尾模板
同型 史纲分析题

结合近代以来中国历史，说明为什么说「历史和人民选择了中国共产党」。

要点 旧民主主义革命的各种方案均告失败；中国共产党成立后，领导新民主主义革命胜利、建立新中国、确立社会主义制度、开创改革开放和现代化建设新局面，实现了民族独立、人民解放和国家富强，历史证明只有中国共产党才能领导中国。
完整解答
  1. 旧民主主义革命的各种方案均告失败。
  2. 中国共产党成立后，领导新民主主义革命胜利、建立新中国。
  3. 确立社会主义制度，开创改革开放和现代化建设新局面。
  4. 实现民族独立、人民解放和国家富强，历史证明只有中国共产党才能领导中国。
易错
  • 把「四个选择」写成三个或顺序打乱。
  • 只讲结论不讲历史过程，分析题显得空。
  • 把「选择」理解为一次性的，忽略其历史必然性。
讲法
腿姐keywords：四个选择是史纲分析题的「万能收口」，但前面必须用史实铺垫。

2027 史纲周年考点：长征、西安事变、孙中山、八大

核心高频

2026 年是长征胜利 90 周年、西安事变 90 周年、孙中山诞辰 160 周年、社会主义改造完成与中共八大 70 周年。周年考点最爱考“事件—时间—主题—意义”，不要只记年份。

1936—2026：长征胜利 90 周年长征精神、党的成熟
1936—2026：西安事变 90 周年抗日民族统一战线初步形成
1866—2026：孙中山诞辰 160 周年振兴中华、民主革命先行者
1956—2026：社会主义改造完成 / 中共八大 70 周年制度确立、探索社会主义建设道路
同型 史纲选择题/分析题

2026 年有哪些重要史纲周年考点？分别说明其意义。

要点 长征胜利 90 周年、西安事变 90 周年、孙中山诞辰 160 周年、社会主义改造完成与中共八大 70 周年。
完整解答
  1. 长征胜利 90 周年（1936—2026）：长征实现革命转危为安，铸就长征精神，党在政治上走向成熟。
  2. 西安事变 90 周年（1936—2026）：事变的和平解决推动抗日民族统一战线初步形成。
  3. 孙中山诞辰 160 周年（1866—2026）：孙中山是民主革命先行者，提出振兴中华，推动国共合作。
  4. 社会主义改造完成与中共八大 70 周年（1956—2026）：社会主义基本制度确立，八大探索社会主义建设道路。
  5. 答题按“事件—时间—主题—意义”四列组织，避免只写年份。
易错
  • 把西安事变与七七事变的时间、意义混淆。
  • 只记周年数字，不写主题与意义。
讲法

[[T-topic-01]]
专题 01

史纲时间轴：八个锚点串起 180 年

史纲选择题的失分集中在时间错位。记住八个锚点，再把事件挂上去，比零散背年份有效得多；分析题也需要用时间顺序组织史实。

  1. 锚点一 1840：鸦片战争，半殖民地半封建社会起点。
  2. 锚点二 1911：辛亥革命，推翻帝制。
  3. 锚点三 1919/1921：五四开端、中共成立。
  4. 锚点四 1935：遵义会议，生死攸关的转折。
  5. 锚点五 1945：抗战胜利；1949：新中国成立。
  6. 锚点六 1956：三大改造完成，社会主义制度确立。
  7. 锚点七 1978：十一届三中全会，改革开放。
  8. 锚点八 2012/2021/2022：新时代、全面小康、二十大。
例

把「社会主义制度确立」「抗日战争胜利」「改革开放开始」按时间排序。

解 抗战胜利 1945 → 社会主义制度确立 1956 → 改革开放开始 1978。

踩坑点 不要只背年份数字，要把「事件—意义—定位词」一起记。只记年份，题干换成意义表述就失效。
[[T-topic-02]]
专题 02

史纲分析题：史实 + 理论 + 现实三段式

史纲分析题 10 分，常见失分是「只讲史实、没有理论」或「只喊口号、没有史实」。三段式能保证既有内容又有高度。

  1. 第一段史实：按时间顺序列 2–3 个关键事件，每个事件一句「时间 + 事件 + 意义」。
  2. 第二段理论：回到「四个选择」或社会主要矛盾、党的性质宗旨等原理。
  3. 第三段现实：联系新时代、中国式现代化或材料中的当代实践。
  4. 结尾用「历史证明……因此……」收口，不引入新史实。
  5. 控制篇幅：史实 40%，理论 30%，现实 30%。
例

结合抗日战争历史，说明中国共产党为什么能成为全民族抗战的中流砥柱。

解 史实：1931 九一八后主张抗战、1937 推动统一战线、开辟敌后战场。理论：党的性质和宗旨决定其代表全民族利益，坚持全面抗战路线。现实：这种领导力延续到新时代，是民族复兴的根本保证。

踩坑点 不要写成「历史故事会」：每个史实后面必须跟一句意义或理论判断，否则拿不到理论分。
