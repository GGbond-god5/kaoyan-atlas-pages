01

数学期望的定义与性质

核心必考

期望是加权平均：离散型按分布律加权，连续型按密度积分。最重要的一条是线性性，它不要求独立。求 \(E(g(X))\) 时直接对 g 加权，不必先求 g(X) 的分布。

\(E(X)=\sum_k x_kp_k\) 或 \(\int_{-\infty}^{+\infty}xf(x)\,dx\)离散 / 连续
\(E(g(X))=\sum_k g(x_k)p_k\) 或 \(\int g(x)f(x)\,dx\)直接加权
\(E(aX+bY+c)=aE(X)+bE(Y)+c\)线性性，无需独立
同型 数一

\(X\sim U(0,1)\)，求 \(E(e^X)\)。

要点 不必先求 \(e^X\) 的密度：\(E(e^X)=\int_0^1 e^xdx=e-1\)。
完整解答
  1. 用无意识统计学家公式 \(E[g(X)]=\int g(x)f(x)dx\)，不必先求 \(e^X\) 的密度。
  2. \(X\sim U(0,1)\)，\(f(x)=1\)，\(0<x<1\)。
  3. \(E(e^X)=\int_0^1 e^x dx=e-1\approx1.718\)。
  4. 检验：\(e^X\in(1,e)\)，期望落在 \((1,2.718)\) 内。
易错
  • 先求函数分布再算期望，绕远且易错；
  • 误认为 \(E(XY)=E(X)E(Y)\) 总成立。
讲法
武忠祥看到 \(E(g(X))\) 直接积分；线性性先拆再算。

02

方差与标准差

核心必考

方差度量偏离均值的程度，计算首选 \(D(X)=E(X^2)-[E(X)]^2\)。平移不变、缩放平方。和的方差只有在独立或不相关时才等于方差之和。

\(D(X)=E(X^2)-[E(X)]^2\)计算首选
\(D(aX+b)=a^2D(X)\)平移不影响方差
\(D(X\pm Y)=D(X)+D(Y)\pm2\mathrm{Cov}(X,Y)\)一般情形
同型 数一

已知 \(E(X)=1,D(X)=2\)，求 \(E[(2X+1)^2]\)。

要点 \(E(X^2)=3\)；展开得 \(4\times3+4\times1+1=17\)。
完整解答
  1. 由 \(D(X)=E(X^2)-[E(X)]^2\) 得 \(E(X^2)=2+1=3\)。
  2. 展开 \((2X+1)^2=4X^2+4X+1\)。
  3. 取期望 \(=4\times3+4\times1+1=17\)。
  4. 检验：结果大于 \((2EX+1)^2=9\)，差额来自方差，合理。
易错
  • \(D(2X)=2D(X)\)（应为 4 倍）；
  • \(D(X-Y)=D(X)-D(Y)\)（应加）；
  • 把 \(E(X^2)\) 当成 \([E(X)]^2\)。
讲法
张宇方差三句：平移不变、缩放平方、和差看协方差。

03

常见分布的期望与方差

核心必考

这张表必须条件反射：0-1、二项、泊松、均匀、指数、正态，加上后两章的 \(\chi^2,t,F\)。选填题直接查表，解答题用来校验结果。

\(B(n,p):\ E=np,\ D=np(1-p)\)二项
\(P(\lambda):\ E=D=\lambda\)泊松
\(U(a,b):\ E=\frac{a+b}{2},\ D=\frac{(b-a)^2}{12}\)均匀
\(E(\lambda):\ E=\frac1\lambda,\ D=\frac1{\lambda^2}\)指数
\(N(\mu,\sigma^2):\ E=\mu,\ D=\sigma^2\)正态
同型 数一

\(X\sim B(10,0.4)\)，求 \(E(X^2)\)。

要点 \(E(X)=4,D(X)=2.4\)，故 \(E(X^2)=2.4+16=18.4\)。
完整解答
  1. 二项分布 \(X\sim B(10,0.4)\)：\(E(X)=np=4\)，\(D(X)=np(1-p)=2.4\)。
  2. 由 \(E(X^2)=D(X)+[E(X)]^2\)。
  3. 代入 \(=2.4+16=18.4\)。
  4. 检验：\(E(X^2)\ge[E(X)]^2=16\)，成立。
易错
  • 指数分布把 \(\lambda\) 当均值；
  • 二项方差漏掉 \((1-p)\)；
  • 均匀分布方差漏除以 12。
讲法
没咋了六个分布的 E、D 写一张便利贴，每天默一遍，选填直接秒。

协方差与相关系数

核心必考

协方差度量线性联动，相关系数把它标准化到 \([-1,1]\)。\(\rho=0\) 只说明不存在线性相关，不代表独立。计算时先算三个量：\(E(X),E(Y),E(XY)\)。

\(\mathrm{Cov}(X,Y)=E(XY)-E(X)E(Y)\)计算式
\(\rho_{XY}=\dfrac{\mathrm{Cov}(X,Y)}{\sqrt{D(X)D(Y)}}\)\(|\rho|\le1\)
\(\mathrm{Cov}(aX+b,cY+d)=ac\,\mathrm{Cov}(X,Y)\)线性变换
同型 数一

已知 \(D(X)=4,D(Y)=9,\rho=0.5\)，求 \(D(X+Y)\) 与 \(\mathrm{Cov}(X+Y,X-Y)\)。

要点 \(\mathrm{Cov}=0.5\times2\times3=3\)；\(D(X+Y)=4+9+6=19\)；\(\mathrm{Cov}(X+Y,X-Y)=4-9=-5\)。
完整解答
  1. \(\mathrm{Cov}(X,Y)=\rho\sigma_X\sigma_Y=0.5\times2\times3=3\)。
  2. \(D(X+Y)=D(X)+D(Y)+2\mathrm{Cov}=4+9+6=19\)。
  3. \(\mathrm{Cov}(X+Y,X-Y)=\mathrm{Cov}(X,X)-\mathrm{Cov}(Y,Y)=4-9=-5\)（交叉项相消）。
  4. 检验：\(D(X+Y)\ge0\)；协方差为负说明 \(X+Y\) 与 \(X-Y\) 负相关。
易错
  • 协方差展开符号错；
  • 相关系数分母漏开方；
  • \(\rho=0\) 直接判独立。
讲法
武忠祥先列 \(E(X),E(Y),E(XY)\) 三格表，再代公式。

矩与协方差矩阵

基础低频

k 阶原点矩 \(E(X^k)\)，k 阶中心矩 \(E[(X-EX)^k]\)。协方差矩阵对称半正定，对角线是方差。数一偶有选填，掌握二阶矩即可。

\(\mu_k=E(X^k),\quad \nu_k=E[(X-EX)^k]\)原点矩 / 中心矩
\(\Sigma=\begin{pmatrix}D(X)&\mathrm{Cov}(X,Y)\mathrm{Cov}(X,Y)&D(Y)\end{pmatrix}\)协方差矩阵
同型 数一

已知 \(E(X)=0,E(X^2)=1,E(X^3)=0,E(X^4)=3\)，求四阶中心矩。

要点 均值为 0 时中心矩等于原点矩，故为 3。
完整解答
  1. 四阶中心矩定义为 \(\mu_4=E[(X-EX)^4]\)。
  2. 题中 \(E(X)=0\)，故 \(X-EX=X\)，中心矩等于原点矩。
  3. 所以 \(\mu_4=E(X^4)=3\)。
  4. 检验：中心矩非负，且与给定原点矩一致。
易错
  • 均值非 0 时把中心矩当原点矩；
  • 协方差矩阵对角线写成协方差。
讲法
张宇中心矩减均值，协方差矩阵对角方差、非对角协方差。

独立与不相关

进阶高频

独立是分布无关，不相关是线性无关。独立一定不相关；不相关不一定独立。唯一常见例外是二维正态。选择题常用“不相关但相依”设坑。

\(X,Y\text{ 独立}\Rightarrow \mathrm{Cov}(X,Y)=0\)反之不成立
\(X,Y\text{ 二维正态且 }\rho=0\Rightarrow\text{独立}\)例外
\(Y=X^2,\ X\sim N(0,1)\Rightarrow \mathrm{Cov}=0\text{ 但不独立}\)经典反例
同型 数一

设 \(X\sim N(0,1),Y=X^2\)，判断 X、Y 是否相关、是否独立。

要点 \(E(XY)=E(X^3)=0=E(X)E(Y)\)，不相关；但 Y 由 X 决定，不独立。
完整解答
  1. \(E(X)=0\)，\(E(Y)=E(X^2)=1\)。
  2. \(E(XY)=E(X\cdot X^2)=E(X^3)=0\)（标准正态三阶矩为 0）。
  3. 故 \(\mathrm{Cov}(X,Y)=0\)，不相关。
  4. 但 \(Y=X^2\) 完全由 \(X\) 决定，不独立；不相关只排除线性关系。
易错
  • 把不相关当独立；
  • 忽略二维正态例外；
  • 用 \(E(XY)=E(X)E(Y)\) 判独立。
讲法
没咋了独立最强，不相关最弱；二维正态两者重合。

07

用分解法求期望

进阶高频

把复杂变量拆成若干个 0-1 指示变量之和，用期望线性性绕开分布。典型场景：空盒数、配对问题、抽签。

\(X=\sum_{i=1}^n X_i,\quad E(X)=\sum_{i=1}^n E(X_i)\)指示变量分解
\(E(X_i)=P(A_i)\)0-1 变量的期望等于事件概率
\(E(\text{空盒数})=n\left(1-\frac1n\right)^n\)每盒为空概率
同型 数一

n 封信随机装入 n 个信封，求装对信封数的期望。

要点 设 \(X_i\) 表示第 i 封装对，\(P(X_i)=1/n\)，故 \(E(X)=1\)，与 n 无关。
完整解答
  1. 设 \(X_i=1\) 表示第 \(i\) 封装对，否则取 0；总对数 \(X=\sum_{i=1}^n X_i\)。
  2. 由对称性，每封信装对的概率 \(P(X_i=1)=1/n\)。
  3. 由期望的线性性 \(E(X)=\sum E(X_i)=n\cdot\frac1n=1\)。
  4. 不需要独立性；结果与 \(n\) 无关，这是指示变量法的典型应用。
易错
  • 试图先求总分布；
  • 指示变量不独立就不敢用线性性（线性性不要求独立）。
讲法
武忠祥看到个数或次数的期望，先拆 0-1 变量，拆完直接加。
[[T-topic-01]]
专题 01

数字特征速算：先拆、再套、后校验

概率大题最后一问常是期望或方差，分值高但方法固定。最后六周内最该练的是不动笔推导、直接列式的速度。

  1. 先拆：把复杂变量写成简单变量之和，如指示变量、独立分量。
  2. 再套：线性性拆期望；独立或不相关才拆方差，其余保留协方差项。
  3. 列三格：涉及相关系数时先算 \(E(X),E(Y),E(XY)\)。
  4. 校验：方差非负，相关系数在 \([-1,1]\)。
  5. 负协方差解释为负相关，不要当作算错。
例

\(X,Y\) 独立，\(E(X)=1,E(Y)=2,D(X)=3,D(Y)=4\)，求 \(E[(X-Y)^2]\)。

解 \(E(X^2)=4,E(Y^2)=8,E(XY)=2\)；结果 \(4-4+8=8\)。也可用 \(D(X-Y)+(E(X-Y))^2=7+1=8\)。

踩坑点 \(E(XY)=E(X)E(Y)\) 只在独立时成立；不独立必须保留协方差。
[[T-topic-02]]
专题 02

相关系数与线性组合：三步定型

相关系数是选填高频，也是独立与不相关辨析的计算载体。三步法能把计算压缩到两分钟。

  1. 定三个量：\(E(X),E(Y),E(XY)\)。
  2. 算协方差：\(\mathrm{Cov}=E(XY)-E(X)E(Y)\)。
  3. 算两个方差并开方，代入 \(\rho\)。
  4. 遇到 \(aX+bY\)：先写 \(D=a^2D_X+b^2D_Y+2ab\mathrm{Cov}\)。
  5. 判定：\(|\rho|=1\) 表示严格线性关系。
例

\(X\sim U(-1,1)\)，\(Y=X^2\)，求 \(\rho_{XY}\)。

解 \(E(X)=0,E(XY)=E(X^3)=0\)，故 \(\mathrm{Cov}=0,\rho=0\)；但 Y 与 X 明显相依。

踩坑点 \(\rho=0\) 只说明没有线性关系；问独立性时必须另找反例或验证联合分布。
