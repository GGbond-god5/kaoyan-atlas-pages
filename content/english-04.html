10 分、5 题、每题 2 分。三种题型轮换出现，你已经过完一轮，这一章的作用是防止手感回潮、把衔接手段变成条件反射。

01

三种题型与总策略

基础必考

英语一新题型在三种形式中选一种：七选五（段中/段尾填句）、排序（段落排序）、小标题（段落与标题匹配）。三者共同考“衔接”，区别在衔接单位：七选五看句际，排序看段际，小标题看段内主旨。先判断题型，再选方法。

七选五：句际衔接（代词、复现、逻辑）最常见
排序：段际衔接（首尾句、时间线）先定首段
小标题：段内主旨（首尾句、高频词）标题要覆盖整段
同型 英语一

给出文章与 7 个选项，要求填入 5 个空。先判断是七选五还是排序，再决定读法。

要点 看选项形式：完整句子多为七选五；段落编号被打乱多为排序；短标题多为小标题。题型判断错，方法会整体跑偏。
完整解答
  1. 先看选项形式：完整句子多为七选五，段落编号被打乱多为排序，短标题多为小标题。
  2. 再看文章结构：有无小标题、段落是否带编号、空的位置在段首/段中/段尾。
  3. 根据题型定读法：七选五先读空前后找衔接，排序先找首段与逻辑链，小标题先概括段意。
  4. 题型判断错会导致方法整体跑偏，动笔前用 30 秒确认。
易错
  • 不判断题型，直接逐空试读。
  • 把七选五当阅读做，逐句翻译耗时过长。
讲法
宋逸轩新题型先看题面定类型，再按“衔接单位”找线索。

02

七选五：代词与指代衔接

核心必考

七选五最硬的线索是代词：选项中的 it / they / this / these / such / the former 必须在空前或空后找到明确指代对象，且单复数、远近一致。看到选项以 This is because 开头，空后必须是一个现象；看到 They 开头，空前必须有复数名词。

this / these → 指代前文最近的名词短语注意单复数
such + 名词 → 前文出现过同类事物同义复现
the former / the latter → 前文必须有两个对象顺序不能反
同型 英语一

空后句以 They 开头，问哪个选项能填入。

要点 空前必须有复数名词（人或物），且选项末尾要能自然引出 They；单数主语的选项直接排除。
完整解答
  1. 看空后句首的 They，确定它指代复数名词（人或物）。
  2. 在选项中找末尾能引出复数名词的句子，且该名词在语义上能被 They 指代。
  3. 排除单数主语、抽象不可数名词的选项。
  4. 代入后读空后整句，确认指代明确、语法一致。
易错
  • 只看选项本身通顺，不回原文找指代对象。
  • 单复数不一致仍强行填。
  • the former/latter 与前文两个对象的顺序对应错。
讲法
宋逸轩代词是七选五的第一线索，先找指代，再谈语义。

03

七选五：逻辑与词汇复现

核心必考

第二层线索是逻辑关系与词汇复现：空前后出现 however 说明语义转折，出现 for example 说明空后是例证，出现 also/moreover 说明同向递进。词汇复现包括原词、同义词、反义词、上下义词；选项与空前后的关键词重合度越高，越可能是答案。

however → 前后语义相反转折
for example → 空后是例子，空前是观点例证
also / moreover / in addition → 同向递进语义不反转
复现：原词 / 同义 / 反义 / 上下义重合度高优先
同型 英语一

空位于段首，后文列举三个具体做法。问哪个选项适合填入。

要点 后文是并列举例，空处应是概括性总起句；含 for example 的选项不能放段首（会与后文重复），应选概括句。
完整解答
  1. 看空后内容：三个具体做法是并列举例，空处应是概括性总起句。
  2. 排除含 for example 的选项：它会与后文举例重复，且不能统领全段。
  3. 选能概括“三个做法共同目的”的句子。
  4. 代入后读段首与后文，确认总—分结构成立。
易错
  • 只按关键词重合选，忽略逻辑方向。
  • 把举例句放段首，造成重复。
  • 忽略段落主题，选项语义正确但位置不对。
讲法
宋逸轩先逻辑后复现：逻辑定方向，复现定具体选项。

04

排序题：首段与逻辑链

核心高频

排序题先定首段：首段通常引出话题、不含指代前文的词（无 However、无 This、无具体代词）。再找段际衔接：上一段末尾提出概念，下一段开头承接；时间词（first, then, finally）、因果词、转折词构成顺序。先排确定项，再用排除法压缩。

首段特征：引出话题、无前指代词先锁定
段尾 → 段首：概念承接上一段埋钩子，下一段接钩子
时间/逻辑链：first → then → finally顺序题常用
同型 英语一

五段排序，其中一段以 However 开头，另一段以 This approach 开头。如何定位？

要点 However 段不能作首段，且前一段应有相反观点；This approach 段前必须有介绍某方法的段落。先确定这两段的相对位置，再补其余。
完整解答
  1. 先找不能作首段的信号：However 段前必须有相反观点，This approach 段前必须介绍过某方法。
  2. 用这两个信号确定相邻关系：找出 However 前一段与 This approach 前一段。
  3. 再看时间/因果链，把剩余段落插入；每插一段都检查首尾衔接词。
  4. 排完后通读，确认每段首句都能承接上一段末句。
易错
  • 把含 However 的段落放首段。
  • 只看关键词，不看段尾与段首的承接。
  • 确定项不足时强行排序，不用排除法。
讲法
宋逸轩排序先定首段，再抓段尾—段首的钩子，最后排除。

05

小标题：段落主旨

核心高频

小标题题考段落主旨，不是细节。优先读段首句与段尾句，其次看反复出现的词；正确标题必须覆盖整段，过窄（只覆盖一个例子）或过宽（超出段落范围）都要排除。标题之间的区分点常在对象、范围、态度三个维度。

主旨 = 段首句 + 高频词先读首句
标题三要素：对象、范围、态度逐项比对
排除：过窄（例子）/ 过宽（全文主题）常见干扰
同型 英语一

某段先讲一个实验，再总结其启示。两个标题：一个描述实验过程，一个概括启示。

要点 选概括启示的标题；实验过程只是论据，不能覆盖整段主旨。
完整解答
  1. 读整段：实验是论据，段末总结才是主旨。
  2. 两个标题中，描述实验过程的只覆盖论据，概括启示的覆盖整段。
  3. 选概括启示的标题，排除以偏概全的实验描述。
  4. 把标题与段末总结句对照，确认意思一致。
易错
  • 被段中例子吸引，选了一个过窄的标题。
  • 忽略段落范围，选了全文主题作某段标题。
  • 标题动词与段落态度不一致。
讲法
宋逸轩小标题看首尾句；例子段看例子后的结论句。

06

干扰项与复查

进阶中频

新题型的干扰项通常语义相关但衔接错位：内容对，但代词指代不上、逻辑方向相反、位置不适配。填完后必须通读：每一空的下一句能否自然承接，全文是否有一条完整逻辑链。5 题 2 分，一错常常连带错两题，复查比速度重要。

复查三问：指代通吗？逻辑顺吗？位置对吗？逐空过
一错连错：相邻空互相依赖优先保证链条完整
同型 英语一

填完后发现第 3 空与第 4 空互换也读得通，如何判断？

要点 看第 3 空前后的时间/因果链：若前文已提出方法、后文才给结果，则方法段必须在结果段之前；按逻辑链而非语感定序。
完整解答
  1. 不要凭语感：先找第 3 空前后与第 4 空前后的逻辑信号（时间、因果、指代）。
  2. 若前文提出方法、后文才给结果，则方法段必须在结果段之前。
  3. 检查两段之间的代词与连接词：This approach / These results 必须指向前文。
  4. 按逻辑链定序，再通读确认没有“互换也读得通”的模糊地带。
易错
  • 填完不读全文，局部通顺但整体断裂。
  • 为省时间跳过复查，导致连带失分。
讲法
宋逸轩新题型最后 3 分钟必须通读，检查衔接链是否闭合。
[[T-topic-01]]
专题 01

衔接手段清单

新题型的本质是衔接。把衔接手段列成清单，做题时逐项扫描，比凭语感快且稳。

  1. 代词：it / they / this / these / such / the former / the latter，先找指代对象。
  2. 复现：原词、同义词、反义词、上下义词，优先看空前后的关键词。
  3. 逻辑：转折、因果、并列、递进、举例、总结，先定方向。
  4. 时间与顺序：first / then / finally / later / meanwhile。
  5. 结构：总—分、问题—对策、现象—原因—结论。
例

选项以 Such a view 开头，如何判断它接在哪一空？

解 空前必须出现一种“观点”（view），且该观点在前文被明确表述；找最近的观点句，而不是最近的名词。

踩坑点 不要只盯关键词重合；衔接手段是“指代 + 逻辑 + 复现”三项同时成立，缺一不可。
[[T-topic-02]]
专题 02

新题型 15 分钟流程

新题型分值高、单题 2 分，但很容易超时。固定流程能把时间压在 15–18 分钟，并留出复查。

  1. 第 1 分钟：判断题型，读首段与各空前后句，写下一句话主旨。
  2. 第 2–8 分钟：先做线索最明确的 2–3 空（代词、逻辑词、复现明显）。
  3. 第 8–13 分钟：用排除法处理剩余空，每填一空立刻回读上下句。
  4. 第 13–16 分钟：通读全文，检查指代、逻辑、位置。
  5. 第 16–18 分钟：只改明显不通的地方，不因“感觉”反复改答案。
例

只剩 5 分钟还有两空没定，怎么办？

解 用排除法：先把已用选项划掉，再看剩余两个选项的代词与逻辑，能对上哪个就填哪个；不要留空。

踩坑点 新题型最忌反复改答案；第一遍的依据通常比第二遍的语感可靠。
