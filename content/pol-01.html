01

物质与意识的辩证关系

核心必考

物质是不依赖于人的意识、又能为人的意识所反映的客观实在，客观实在性是物质的唯一特性。意识是物质世界长期发展的产物，是人脑的机能和对客观存在的反映。物质决定意识，意识对物质具有能动的反作用，二者统一于实践。

物质 ≠ 具体物质形态把二者等同是古代朴素唯物主义
意识 = 人脑机能 + 客观存在的反映缺一不可，选择题常偷换
能动作用 = 认识世界 + 改造世界受客观规律制约，不是万能
同型 马原选择题

「物质是标志客观实在的哲学范畴，这种客观实在是人通过感觉感知的」与「存在就是被感知」的根本分歧在哪？

要点 前者坚持唯物主义反映论，承认物质独立于意识；后者是主观唯心主义，把存在归结为感觉。分歧实质是物质与意识何者为第一性。
完整解答
  1. 抓两种表述的差别：前者承认物质独立于意识，后者把存在等同于被感知。
  2. 对应派别：前者是唯物主义反映论，后者是主观唯心主义。
  3. 根本分歧是物质与意识何者为第一性，即哲学基本问题的第一方面。
  4. 结论：前者正确，后者错误。
同型 马原分析题

结合人工智能可以写诗、作画、生成论文的材料，说明人工智能为什么不能取代人的意识。

要点 意识是人脑的机能和社会实践的产物，具有社会性、目的性和自觉能动性；人工智能只是对人类思维某一方面功能的模拟，没有社会关系基础，也不具备真正的自觉能动性。
完整解答
  1. 先定意识本质：意识是人脑的机能，是社会实践的产物，具有社会性、目的性和自觉能动性。
  2. 人工智能是对人类思维某些功能的模拟，本质是物质工具与算法，不是人脑。
  3. 它没有社会关系基础，也没有真正的目的、价值判断和自觉能动性，不能独立产生意识。
  4. 结论：人工智能可以替代部分脑力劳动，但不能取代人的意识，要辩证看待其作用与局限。
易错
  • 把「物质」等同于「物质的具体形态」，这是古代朴素唯物主义。
  • 把意识的能动作用夸大为可以创造、消灭或改变规律。
  • 混淆主观唯心（心外无物）与客观唯心（理在事先）。
讲法
徐涛用「物质—意识—实践」三角框架讲，先定第一性，再谈反作用，最后落到实践统一。腿姐keywords 法则：看到「决定」找物质，看到「反作用」找意识，看到「万能」直接判错。

实践的本质与认识的基础

核心必考

实践是人类能动地改造世界的客观物质活动，具有直接现实性、自觉能动性、社会历史性三个基本特征。实践由主体、中介、客体构成。实践是认识的基础：是认识的来源、发展的动力、检验真理的唯一标准，也是认识的目的。

实践三特征：直接现实性 · 自觉能动性 · 社会历史性缺一不可，选择常删一项
实践结构：主体 — 中介 — 客体中介是工具、手段及运用方式
实践是认识的基础：来源 · 动力 · 标准 · 目的四个作用可单独设问
同型 马原分析题

为什么说实践是检验真理的唯一标准？

要点 真理的本性是主观认识与客观对象相符合，这在主观范围内无法判定；实践具有直接现实性，能把主观认识转化为客观结果，从而对照检验认识是否正确。
完整解答
  1. 真理的本性是主观认识与客观对象相符合，这种符合不能在主观范围内自证。
  2. 实践具有直接现实性，能把主观认识转化为客观结果。
  3. 用客观结果对照认识，才能判定认识是否符合实际，所以实践是唯一标准。
  4. 逻辑证明是辅助，不能替代实践；实践标准是确定性与不确定性的统一。
易错
  • 把实践等同于生产劳动，缩小了实践的外延。
  • 把实践的直接现实性与意识的能动性混为一谈。
  • 认为逻辑证明可以替代实践作为最终检验标准。
讲法
徐涛强调实践是贯穿马原的一条红线：物质观、认识论、历史观都用它串起来。腿姐keywords：「唯一标准」只能接实践，出现「理论」「多数人意见」直接排除。

03

普遍联系与永恒发展

核心高频

联系具有普遍性、客观性、多样性、条件性。发展是前进上升的运动，实质是新事物的产生和旧事物的灭亡。新事物不是时间上后出现的事物，而是符合发展规律、具有远大前途的事物。

联系四性：普遍 · 客观 · 多样 · 条件「无条件联系」是错误表述
发展实质：新事物产生 + 旧事物灭亡新事物≠新出现的事物
同型 马原选择题

「城门失火，殃及池鱼」与「揠苗助长」分别体现了什么哲学道理？

要点 前者体现联系的普遍性与条件性；后者违背事物发展的客观规律，把发展理解为外力速成。
完整解答
  1. “城门失火，殃及池鱼”说明事物普遍联系，联系具有条件性。
  2. “揠苗助长”违背事物发展的客观规律，把发展理解为外力速成。
  3. 方法论：用联系的观点看问题，按规律办事，不能急于求成。
  4. 结论：前者对应联系的普遍性，后者对应规律的客观性。
易错
  • 把联系的条件性说成无条件、绝对普遍。
  • 把「新出现」当作「新事物」，忽略是否符合发展规律。
  • 用发展否定静止，或用量变代替发展。
讲法
腿姐keywords 四连背：普遍、客观、多样、条件；题干出现「任何事物都联系」要结合条件判断。

04

对立统一规律

核心必考

矛盾是事物之间以及事物内部诸要素之间的对立统一。同一性是有条件的、相对的，斗争性是无条件的、绝对的。矛盾普遍性与特殊性的关系是共性与个性、一般与个别的关系，是矛盾问题的精髓。矛盾发展不平衡：主要矛盾决定事物发展进程，矛盾的主要方面决定事物性质。

同一性：相对 · 有条件；斗争性：绝对 · 无条件选择题最爱颠倒
普遍性寓于特殊性之中不是特殊性寓于普遍性
主要矛盾 → 进程；主要方面 → 性质两句话不可互换
同型 马原分析题

「中国式现代化既有各国现代化的共同特征，更有基于自己国情的中国特色。」运用矛盾普遍性与特殊性原理分析。

要点 矛盾的普遍性即共性，特殊性即个性，共性寓于个性之中。中国式现代化既遵循现代化的一般规律，又立足中国国情形成中国特色，是共性与个性的统一。
完整解答
  1. 点：矛盾普遍性即共性，特殊性即个性，共性寓于个性之中。
  2. 析：现代化有工业化、城镇化、市场化等共同特征；中国立足人口规模巨大、共同富裕等国情，形成五个中国特色。
  3. 结：中国式现代化是共性与个性的统一，既遵循现代化一般规律，又坚持中国特色。
同型 马原选择题

「牵牛要牵牛鼻子」与「抓主流」分别对应什么原理？

要点 前者抓主要矛盾，后者抓矛盾的主要方面；二者都是矛盾发展不平衡原理的方法论要求。
完整解答
  1. “牵牛要牵牛鼻子”是抓主要矛盾，集中力量解决关键问题。
  2. “抓主流”是抓矛盾的主要方面，把握事物的性质。
  3. 二者都体现矛盾发展不平衡原理，但对象不同：主要矛盾看发展，主要方面看性质。
  4. 方法论：坚持两点论与重点论统一。
易错
  • 把同一性与斗争性的绝对、相对关系说反。
  • 把主要矛盾与矛盾的主要方面混用：前者管全局进程，后者管事物性质。
  • 认为矛盾一方可以脱离另一方单独存在。
讲法
徐涛用「共性寓于个性」一句打穿普遍性与特殊性，再配中国式现代化等时政材料。腿姐keywords：主要矛盾找「重点、关键、中心」，主要方面找「主流、性质、本质」。

质量互变规律

基础高频

量变是质变的必要准备，质变是量变的必然结果，质变又为新的量变开辟道路。度是保持事物质的稳定性的数量界限，关节点是度的两端。方法论上既要重视量的积累，又要抓住时机促成质变。

量变 → 质变 → 新的量变循环上升，不是简单重复
度 = 质与量的统一；关节点 = 度的两端「过犹不及」即超出度
同型 马原选择题

「防微杜渐」与「过犹不及」分别强调什么？

要点 前者强调重视量的积累、防量变引起质变；后者强调把握度，超过关节点事物性质就会改变。
完整解答
  1. “防微杜渐”强调重视量的积累，防止坏的量变引起质变。
  2. “过犹不及”强调把握度，超过关节点事物性质就会改变。
  3. 方法论：重视量的积累，坚持适度原则。
  4. 结论：二者共同体现质量互变规律。
易错
  • 认为只要有量变就必然发生质变，忽略度与条件。
  • 把质变说成对量变的否定，割裂二者联系。
  • 把「度」理解为固定不变的数值点。
讲法
腿姐记「度—关节点—飞跃」三件套，选择题看到「适度」「底线」就对度。

否定之否定规律

基础中频

辩证否定是事物的自我否定，实质是「扬弃」——既克服又保留。事物发展经过两次否定、三个阶段，呈现螺旋式上升、波浪式前进，说明发展的前进性与曲折性统一。

否定 = 扬弃 = 克服 + 保留不是全盘抛弃，也不是全盘肯定
两次否定 · 三个阶段 · 螺旋上升「前途光明，道路曲折」
同型 马原选择题

「前途是光明的，道路是曲折的」体现了什么规律？

要点 否定之否定规律，揭示事物发展是前进性与曲折性的统一；新事物必然战胜旧事物，但道路不是直线。
完整解答
  1. 否定之否定规律揭示事物发展是前进性与曲折性的统一。
  2. 新事物必然战胜旧事物，但道路不是直线，会有反复和曲折。
  3. 方法论：既要坚定信心，又要准备走曲折的路。
  4. 结论：体现否定之否定规律。
易错
  • 把辩证否定理解为全盘否定或简单抛弃。
  • 把螺旋上升等同于循环论，否认发展的前进性。
  • 认为三个阶段可以任意跳过。
讲法
徐涛用「扬弃」二字统摄，提醒学生否定不是「归零」而是「升级」。

唯物辩证法的基本范畴

基础中频

五对范畴：原因与结果、必然与偶然、可能与现实、现象与本质、内容与形式。每对范畴既对立又统一，并在一定条件下相互转化。范畴是辩证思维的逻辑形式，选择题常以成语、俗语设题。

必然性通过偶然性开辟道路偶然性背后隐藏必然性
现象包括真象与假象假象也是本质的表现
现实可能 vs 抽象可能区分有无客观根据
同型 马原选择题

「偶然性是科学的敌人」这一说法错在哪里？

要点 错在割裂必然与偶然。偶然性是必然性的表现形式和补充，科学正是通过偶然现象发现必然规律。
完整解答
  1. 该说法割裂必然与偶然，是形而上学的。
  2. 必然性通过偶然性开辟道路，偶然性是必然性的表现形式和补充。
  3. 科学正是通过偶然现象发现必然规律。
  4. 结论：说法错误。
易错
  • 认为假象不表现本质，或把假象等同于错觉。
  • 把一切可能都当作现实可能，忽略客观根据。
  • 把必然与偶然绝对对立。
讲法
腿姐五对范畴各配一句口诀，做题先判「这对范畴在问哪一面」。

认识的本质与过程

核心必考

认识是主体在实践基础上对客体的能动反映。两条根本对立的认识路线：唯物主义反映论与唯心主义先验论；能动反映论与旧唯物主义直观反映论。认识过程是感性认识—理性认识—实践，包含两次飞跃。

两次飞跃：感性 → 理性 → 实践第二次飞跃更重要
感性认识：现象 · 外部联系理性认识：本质 · 内部联系
理性认识依赖于感性认识二者不是高低优劣的简单排序
同型 马原分析题

「纸上得来终觉浅，绝知此事要躬行。」运用认识论原理分析。

要点 实践是认识的来源和检验标准；间接经验必须回到实践中检验、深化。认识要经历从感性到理性、再回到实践的两次飞跃。
完整解答
  1. 实践是认识的来源、动力和检验标准；间接经验最终也来源于实践。
  2. 书本知识必须回到实践中检验、深化，否则容易脱离实际。
  3. 认识要经历从感性到理性、再回到实践的两次飞跃。
  4. 结论：坚持实践第一，重视躬行。
易错
  • 认为理性认识一定比感性认识可靠，忽略其来源于感性并需实践检验。
  • 把两次飞跃的顺序颠倒，或认为第二次飞跃可有可无。
  • 混淆唯物主义反映论与唯心主义先验论的分歧点。
讲法
徐涛框架：实践—感性—理性—实践，强调第二次飞跃是「回到实践」而非「再认识」。腿姐keywords：出现「直接经验」「间接经验」先回到实践与认识的来源。

真理与价值

核心高频

真理是主观与客观相符合，具有客观性、绝对性和相对性。真理与谬误相互依存、在一定条件下相互转化。价值是客体对主体需要的满足。真理尺度与价值尺度统一于实践。

真理三性：客观性 · 绝对性 · 相对性绝对性不等于「永恒不变」
真理与谬误：对立统一 · 有条件转化超出条件真理会变谬误
真理尺度 + 价值尺度 = 实践的两把尺子缺一不可
同型 马原选择题

「有用即真理」错在哪里？

要点 这是实用主义真理观，把真理的有用性等同于真理本身，否认真理的客观性；有用性是真理的价值属性，不是真理的根据。
完整解答
  1. 该说法是实用主义真理观，把有用性等同于真理。
  2. 真理是主观与客观相符合，客观性是真理的本质属性。
  3. 有用性是真理的价值属性，不是真理的根据；有用未必真。
  4. 结论：说法错误。
易错
  • 认为相对真理中包含着错误，混淆相对性与谬误。
  • 用真理的绝对性否认真理的相对性，或反之。
  • 把价值等同于主观好恶，否定价值的客观基础。
讲法
腿姐keywords：真理「一元」，价值「多元」；看到「真理多元」直接判错。

唯物史观：社会存在与社会意识

核心必考

社会存在决定社会意识，社会意识具有相对独立性并反作用于社会存在。社会基本矛盾是社会发展的根本动力，生产力是最终决定力量。人民群众是历史的创造者；人的本质是一切社会关系的总和。

社会存在 → 社会意识（决定）社会意识反作用，且有相对独立性
生产力 → 生产关系；经济基础 → 上层建筑两对社会基本矛盾
人的本质 = 一切社会关系的总和不是抽象人性
同型 马原分析题

运用社会存在与社会意识辩证关系，说明为什么要培育和践行社会主义核心价值观。

要点 社会存在决定社会意识，社会意识反作用于社会存在并具有相对独立性。核心价值观根植于中国特色社会主义实践，又能凝聚共识、反作用于经济社会发展。
完整解答
  1. 点：社会存在决定社会意识，社会意识具有相对独立性并反作用于社会存在。
  2. 析：社会主义核心价值观根植于中国特色社会主义实践，反映人民共同利益。
  3. 结：它能凝聚共识、规范行为、反作用于经济社会发展，所以要培育和践行。
易错
  • 把社会意识等同于社会存在，或否认社会意识的相对独立性。
  • 把人民群众等同于「人人」，忽略其质的规定性。
  • 认为英雄人物决定历史发展方向。
讲法
徐涛用「两对矛盾、一个主体」收口：生产力与生产关系、经济基础与上层建筑，人民群众是主体。腿姐keywords：「决定」找社会存在，「反作用」「相对独立性」找社会意识。

专题 01

马原分析题：原理 + 材料的三步模板

马原分析题 10 分，评分看两点：原理是否准确、是否结合材料。背得多不如定位准、贴得紧。最后六周内最该练的是「读设问—定原理—贴材料」的流程。

  1. 读设问，圈出限定词：问的是「体现什么原理」「如何理解」「为什么」，决定答题重心。
  2. 定位原理：从设问关键词回溯到章节（如「共性个性」→ 矛盾普遍性与特殊性），只写与设问直接相关的原理。
  3. 写原理：一句定义 + 一句方法论，控制在 2–3 行，不展开教材原文。
  4. 贴材料：逐句对应，用「材料中……正体现了……」的句式，至少两处材料细节。
  5. 收口：用「点—析—结」结构，最后一句回到设问，不另起新原理。
例

材料：中国式现代化既没有照搬西方模式，也没有脱离世界现代化一般规律。设问：运用矛盾普遍性与特殊性原理分析这一做法。

解 点：矛盾普遍性与特殊性是共性与个性、一般与个别的关系，共性寓于个性之中。析：现代化的一般规律是共性，中国国情是个性；中国式现代化既遵循共性，又立足个性，没有把二者割裂。结：这要求我们在普遍规律指导下具体分析特殊国情，走自己的路。

踩坑点 最常见的失分是「原理堆砌」：把矛盾观、发展观、实践观全写上，却不与设问对应。宁可只写一个原理、贴足材料，也不要写三个原理、每个只说一句。

专题 02

马原选择题排错三招

选择题 50 分是政治的基本盘，马原选择又最爱在「绝对化」「偷换概念」「关系颠倒」上设坑。掌握排错顺序，比反复背书提分快。

  1. 第一招看绝对化：出现「一定」「必然」「完全」「唯一」「任何」先警惕，除非是教材原话（如「实践是唯一标准」）。
  2. 第二招看概念偷换：物质 vs 物质形态、规律 vs 现象、社会存在 vs 社会意识、主要矛盾 vs 主要方面。
  3. 第三招看关系颠倒：决定/反作用、绝对/相对、第一性/第二性、内容/形式。
  4. 第四招回题干：把选项放回题干限定语境，检查是否答非所问。
  5. 最后用「教材原话优先」原则：与大纲原文高度一致的选项优先保留。
例

「意识是人脑的分泌物」这一说法属于（ ）。

解 这是庸俗唯物主义，把意识归结为物质，否认意识的特殊性；正确表述是意识是人脑的机能和对客观存在的反映。

踩坑点 不要一看到「决定」就选对：还要看谁决定谁。也不要因为选项「听起来正确」就选，必须回到题干主体。
