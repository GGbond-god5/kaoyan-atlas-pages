01

评分标准与采分点

核心必考

翻译按采分点给分：每句 2 分，通常拆成 3–4 个采分点（主谓、从句、关键词、逻辑）。整句大意对但某个结构译错，仍会扣该点。所以策略是先保证结构正确，再追求通顺；不要为了中文漂亮而合并结构，导致采分点丢失。

每句 2 分 = 3–4 个采分点结构点 + 关键词
采分点：主谓、从句归属、逻辑词、关键词逐点落实
扣分：漏译、错译、语序混乱大意对也可能扣
同型 英语一

一句含定语从句与插入语，译文大意正确但把定语从句译成了并列句，问能得几分。

要点 结构点可能扣 0.5–1 分；若关键词与逻辑正确，通常得 1–1.5 分。采分点制下，结构错误不会因“读起来顺”而免扣。
完整解答
  1. 先看采分点：定语从句的结构与逻辑是独立采分点，译成并列句通常扣 0.5–1 分。
  2. 判断其余部分：关键词、主句主干、逻辑关系是否正确。
  3. 若其余正确，通常得 1–1.5 分；不会因“读起来顺”而免扣结构分。
  4. 改写时把定语从句前置或后置，保留修饰关系，再检查扣分点是否消除。
易错
  • 追求意译，丢掉结构采分点。
  • 漏译插入语或同位语。
  • 中文通顺但主谓关系译反。
讲法
唐静翻译先拆后合，采分点逐点落实，不要一上来就写整句。

02

拆分组合法

核心必考

唐静的核心方法：先拆成意群，再逐群翻译，最后按中文逻辑组合。拆分点通常在连接词、介词、分词、标点处；每个意群内部先译主干，再挂修饰。组合时允许调整语序、增补逻辑词，但不能改变原意。

拆分点：连词 / 介词 / 分词 / 标点意群边界
每群：主干 + 修饰先主后次
组合：按中文逻辑重排 + 补逻辑词可增不可改
同型 英语一

一句 40 词，含两个从句与一个插入语，要求翻译。

要点 在 that/which、介词短语、双逗号处拆成 4 个意群；逐群译出后，把定语从句移到先行词前或独立成句，插入语用括号或前置，最后通读调整。
完整解答
  1. 在 that/which、介词短语、双逗号处把句子拆成 4 个意群。
  2. 逐群直译，先保证每个意群的主谓宾与关键词准确。
  3. 按中文逻辑重排：短定语前置，长定语后置或独立成句，插入语用括号或破折号。
  4. 补出逻辑词，通读检查没有漏译、没有改变因果。
易错
  • 不拆直接逐词译，中文语序混乱。
  • 拆得太碎，意群之间逻辑断裂。
  • 组合时擅自增删原文信息。
讲法
唐静拆分是手段，组合才是目的；拆完必须能拼回一条通顺的中文逻辑链。

03

定语从句译法

核心必考

定语从句有三种译法：前置法（短从句，译成“……的”）、后置法（长从句，独立成句，用“这/它/该”承接）、融合法（there be 或主从关系紧密时，把先行词与从句合并）。选择依据是从句长度与中文可读性，不是固定规则。

短从句 → 前置：……的 + 名词不超过 10 字
长从句 → 后置：独立成句 + 这/它避免头重脚轻
非限制性从句 → 常后置补充说明
同型 英语一

先行词后接一个 20 词的 which 从句，问如何译。

要点 前置会导致定语过长，应后置：先译主句，再用“这一……/它……”引出从句内容；若从句与主句是因果关系，补“因为/从而”。
完整解答
  1. 判断从句长度：20 词的 which 从句前置会导致定语过长，中文不成立。
  2. 后置处理：先译主句，再用“这一……/它……”引出从句内容。
  3. 若从句与主句是因果关系，补“因为/从而”，但不能改变原逻辑。
  4. 通读译文，确认先行词明确、从句内容独立可读。
易错
  • 所有定语从句都前置，中文定语过长。
  • 后置时缺少承接词，句子断裂。
  • 把非限制性定语从句误译成限制性。
讲法
唐静定语从句先看长短，再定前置还是后置；不要死记一种译法。

04

状语从句译法

核心高频

状语从句表时间、原因、条件、让步、结果、方式。中文习惯状语前置（原因、条件、时间），结果后置；但英语从句位置灵活，翻译时按中文逻辑重排。让步状语常译成“尽管/即使”，结果状语常译成“从而/因此”。

原因/条件/时间 → 前置中文习惯
结果 → 后置：从而/因此so that / such that
让步 → 尽管/即使although / even if
同型 英语一

主句后置一个 because 从句，直译会变成“……，因为……”，问是否调整。

要点 中文可保留后置，但若原因较长，前置更通顺；考试中两种都可，关键是逻辑关系不能反。
完整解答
  1. 先判断 because 从句的功能：解释原因，不是结果。
  2. 中文可后置“因为……”，也可前置“由于……，主句”；两种都行，关键是逻辑不能反。
  3. 若原因较长，前置更通顺；若原因短，后置更自然。
  4. 检查译文没有把因果译成转折或并列。
易错
  • 把让步译成因果。
  • 结果状语漏译逻辑词。
  • 条件句译成陈述句，语气改变。
讲法
唐静状语从句先判断逻辑类型，再决定中文位置；逻辑词必须译出。

05

被动语态译法

基础高频

英语被动多，中文被动少。译法有三：译成中文被动（被/受/遭到）、译成主动（补充泛指主语“人们/我们”，或把 by 宾语提前）、译成无主句（“据认为/可以说”）。选择依据是动作是否有明确施动者、中文是否自然。

is considered → 被认为 / 人们认为两种都可
it is said that → 据说无主句
be subjected to → 遭受/受到保留被动义
同型 英语一

句子为被动语态且 by 短语缺失，问如何译。

要点 优先译成无主句或补充泛指主语（人们/研究者），避免生硬“被……”；若动作含负面义，用“遭到/受到”更自然。
完整解答
  1. 识别被动语态与 by 短语是否出现；by 缺失时不要生造施动者。
  2. 优先译成无主句或补泛指主语（人们/研究者/当局）。
  3. 若动作含负面义，用“遭到/受到”比“被”更自然。
  4. 通读检查：中文主语是否成立、动作方向是否正确、没有增删信息。
易错
  • 所有被动都译成“被”，中文生硬。
  • 补充主语超出原文范围。
  • 漏译被动所带的负面/正面含义。
讲法
唐静被动先看有没有施动者，再决定被动、主动还是无主句。

06

名词性从句与同位语

核心高频

主语从句、宾语从句、表语从句、同位语从句在中文里常译为独立分句或“……”的内容。同位语从句（fact/idea/belief/evidence + that）译成“……”这一事实/观点”，不能译成定语。识别方法：从句成分完整、that 只起连接作用，就是同位语。

the fact that ... → ……这一事实同位语
what 引导主语从句 → ……的事情what = the thing that
it is + adj. + that → ……是……的形式主语
同型 英语一

句中出现 the idea that ...，问 that 从句是定语还是同位语。

要点 从句成分完整，that 不作成分，是同位语；译成“……这一观点”，不要译成“那个……的观点”。
完整解答
  1. 看 that 从句成分：主谓宾齐全，that 不作成分，是同位语从句。
  2. 确认先行词是 fact/idea/news/belief 等抽象名词。
  3. 译成“……这一观点/事实”，不要译成“那个……的观点”（定语）。
  4. 通读确认从句内容就是先行词的具体内容，而非修饰关系。
易错
  • 同位语从句误译成定语从句。
  • what 从句按“什么”直译。
  • 形式主语 it 漏译或误译。
讲法
唐静同位语看“成分完整 + 抽象名词”，译成“……这一……”。
[[K-kp-07]]
07

词义引申与增删

进阶中频

翻译允许在不变更原意的前提下增补逻辑词、范畴词，或删去冗余代词。词义引申要贴上下文：抽象名词具体化、动词方向明确化。增删的边界是“不加新信息、不减原信息”，只让中文更通顺。

增：逻辑词（因为/从而）、范畴词（现象/过程）不增信息
删：冗余代词、重复的冠词不减信息
引申：抽象 → 具体，按上下文定不脱离语境
同型 英语一

原文抽象名词在中文中单独成句不自然，问是否可加范畴词。

要点 可以增补“这一现象/这一过程”等范畴词，使中文成立；但不能增加原文没有的因果或评价。
完整解答
  1. 判断抽象名词单独成句是否成立；不成立时可增补范畴词（这一现象/这一过程/这一做法）。
  2. 增补只补范畴，不补原文没有的因果、评价或程度。
  3. 把增补后的译文与原文对照，确认信息量没有增加。
  4. 通读检查中文是否自然、术语是否统一。
易错
  • 增补过度，加入原文没有的观点。
  • 为通顺删掉关键限定词。
  • 词义引申脱离上下文。
讲法
唐静增删只为通顺，不为发挥；边界是原意不变。
[[T-topic-01]]
专题 01

五步翻译流程

考场上每句只有 3–4 分钟，必须有一套不依赖灵感的手续。五步能把“看不懂”拆成可执行的动作。

  1. 找主干：圈出主句的主谓宾，暂时忽略修饰。
  2. 拆意群：在连词、介词、分词、标点处切分。
  3. 逐群译：每群先译主干，再挂修饰，关键词先定。
  4. 组合：按中文逻辑重排，补逻辑词，处理定语与被动。
  5. 回读：检查采分点是否齐全、有无漏译、中文是否通顺。
例

翻译：What matters is not how long a policy lasts but whether it addresses the conditions that produced the problem.

解 主干：What matters is not ... but ...。主语从句 what matters 译“重要的”；whether 从句译“是否”；that produced the problem 是定语从句，前置译“产生该问题的”。合译：重要的不是一项政策持续多久，而是它是否针对了产生该问题的那些条件。

踩坑点 不要先写中文再找结构；先把主干与采分点定下来，中文自然顺。
[[T-topic-02]]
专题 02

采分点自检表

翻译丢分往往不是不会，而是漏点。用固定清单逐项自检，能把“会做的分”拿满。

  1. 主谓是否译对，有没有把从句谓语当主句谓语。
  2. 每个从句是否都有归属，修饰对象是否正确。
  3. 逻辑词（因果、转折、让步、条件）是否译出。
  4. 关键词是否准确，是否漏译插入语、同位语。
  5. 被动是否处理自然，中文是否缺主语。
  6. 是否有增补过度或删减关键信息。
例

一句译完，如何快速判断能得几分？

解 按 3–4 个采分点逐项打勾：主谓、从句、逻辑、关键词。缺一项约扣 0.5 分；结构全对、中文略生硬通常只扣语言分。

踩坑点 不要用“读起来顺”代替采分点检查；顺不等于对。
