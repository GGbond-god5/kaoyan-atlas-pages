商品二因素与劳动二重性

核心必考

商品是使用价值与价值的矛盾统一体：使用价值是自然属性，价值是社会属性，二者对立统一。生产商品的劳动具有二重性——具体劳动创造使用价值，抽象劳动形成价值。劳动二重性是理解政治经济学的枢纽。

商品 = 使用价值 + 价值二者缺一不成商品
具体劳动 → 使用价值；抽象劳动 → 价值同一劳动的两重属性，不是两次劳动
私人劳动与社会劳动的矛盾 = 商品经济基本矛盾私有制条件下
同型 马原选择题

「上衣能满足人的保暖需要，同时又能与 20 斤米交换。」这两句话分别指商品的什么属性？

要点 前者是使用价值，由具体劳动创造；后者是价值，由抽象劳动形成。交换比例的基础是价值。
完整解答
  1. 保暖需要是使用价值，由具体劳动创造。
  2. 与 20 斤米交换体现价值，由抽象劳动形成。
  3. 交换比例的基础是价值，使用价值是交换的物质前提。
  4. 结论：前者是使用价值，后者是价值。
易错
  • 把具体劳动与抽象劳动理解为两种先后进行的劳动。
  • 认为使用价值是商品独有的，忽略它是一切劳动产品的自然属性。
  • 把商品二因素与劳动二重性一一对应错位。
讲法
徐涛用「一件商品、两重属性、同一劳动的两面」讲，强调二重性是枢纽而非并列概念。腿姐keywords：看到「自然属性」找使用价值，看到「社会属性」找价值。

价值量的决定与劳动生产率

核心高频

商品价值量由生产商品的社会必要劳动时间决定，而不是个别劳动时间。单位商品价值量与社会劳动生产率成反比，与生产该商品的社会必要劳动时间成正比。个别企业提高劳动生产率可获得超额剩余价值。

价值量 ∝ 社会必要劳动时间个别劳动时间不决定价值量
单位商品价值量 × 社会劳动生产率 = 常数成反比关系
同一时间创造的价值总量与社会劳动生产率无关常见计算陷阱
同型 马原计算题

某部门社会劳动生产率提高一倍，同一劳动时间内生产的商品数量与单位商品价值量如何变化？

要点 商品数量翻倍，单位商品价值量减半，同一劳动时间内创造的价值总量不变。
完整解答
  1. 社会劳动生产率提高一倍，同一劳动时间内生产的商品数量翻倍。
  2. 单位商品价值量与社会劳动生产率成反比，因此减半。
  3. 同一劳动时间内创造的价值总量不变。
  4. 结论：数量翻倍、单位价值减半、价值总量不变。
易错
  • 把个别劳动时间当作价值量的决定因素。
  • 认为社会劳动生产率提高会使价值总量增加。
  • 混淆「单位商品价值量」与「同一时间价值总量」的变化方向。
讲法
腿姐计算题口诀：「单位反比、总量不变」，先判断问的是单位还是总量。

货币的本质与职能

基础高频

货币是固定充当一般等价物的商品，本质是一般等价物。五大职能：价值尺度、流通手段、贮藏手段、支付手段、世界货币。其中价值尺度和流通手段是基本职能。

货币本质 = 一般等价物不是普通商品，也不是符号
五职能：价值尺度 · 流通手段 · 贮藏 · 支付 · 世界货币基本职能仅前两个
流通中所需货币量 = 商品价格总额 ÷ 货币流通速度计算题常用
同型 马原选择题

「商场标价 99 元」与「一手交钱一手交货」分别体现货币的什么职能？

要点 前者是价值尺度（观念上的货币），后者是流通手段（现实的货币）。
完整解答
  1. 标价 99 元是观念上的货币，执行价值尺度职能。
  2. 一手交钱一手交货是现实货币，执行流通手段职能。
  3. 区分：价值尺度不需要现实货币，流通手段需要现实货币。
  4. 结论：前者价值尺度，后者流通手段。
易错
  • 把价值尺度与流通手段混为一种职能。
  • 认为货币天然具有价值，忽略它是商品交换发展的产物。
  • 把支付手段（赊购、工资、租金）误判为流通手段。
讲法
徐涛用「标价—买卖—存钱—还债—出国」五个场景对应五职能，一场景一职能。

价值规律及其作用

核心高频

价值规律的基本内容：商品价值量由社会必要劳动时间决定，商品交换以价值量为基础实行等价交换。表现形式：价格受供求影响围绕价值上下波动。作用：调节资源配置、刺激技术进步、促进优胜劣汰，也可能导致资源浪费与两极分化。

价格围绕价值波动 ≠ 否定价值规律恰恰是价值规律的表现形式
供不应求 → 价格高于价值；供过于求 → 价格低于价值供求影响价格，不决定价值
同型 马原选择题

「价格围绕价值上下波动，说明价值规律被否定了。」这一说法是否正确？

要点 错误。价格波动不仅不否定价值规律，反而是价值规律在商品经济中的实现形式；从长期看价格总额与价值总额趋于一致。
完整解答
  1. 价值规律的表现形式是价格围绕价值上下波动。
  2. 供求影响价格，但价格最终由价值决定。
  3. 长期看价格总额与价值总额趋于一致，波动不否定价值规律。
  4. 结论：说法错误。
易错
  • 认为供求决定价值，混淆价值与价格。
  • 把价值规律的自发作用只理解为积极面。
  • 认为价格与价值始终一致才叫价值规律。
讲法
腿姐keywords：价值「决定」价格，供求「影响」价格，二者不能互换。

资本与剩余价值

核心必考

资本是能带来剩余价值的价值。不变资本（c）购买生产资料，只转移价值；可变资本（v）购买劳动力，能创造新价值。剩余价值率 m′ = m/v = 剩余劳动时间/必要劳动时间。绝对剩余价值靠延长工作日，相对剩余价值靠缩短必要劳动时间，超额剩余价值来自个别企业劳动生产率高于社会平均水平。

m′ = m / v = 剩余劳动时间 / 必要劳动时间衡量剥削程度
商品价值 = c + v + m不变资本 + 可变资本 + 剩余价值
绝对：延长工作日；相对：缩短必要劳动时间；超额：个别效率领先三种剩余价值生产
同型 马原计算题

某企业预付资本 100 万元，其中不变资本 60 万元、可变资本 40 万元，剩余价值 20 万元。求剩余价值率与利润率。

要点 m′ = 20/40 = 50%；利润率 p′ = 20/100 = 20%。剩余价值率按可变资本计算，利润率按全部预付资本计算。
完整解答
  1. 剩余价值率 m′ = m/v = 20/40 = 50%。
  2. 利润率 p′ = m/(c+v) = 20/100 = 20%。
  3. 区别：剩余价值率按可变资本计算，利润率按全部预付资本计算。
  4. 结论：m′ = 50%，p′ = 20%。
易错
  • 把剩余价值率与利润率混用：前者分母是 v，后者分母是 c+v。
  • 认为不变资本也创造剩余价值。
  • 把相对剩余价值与超额剩余价值混为一谈：前者是社会普遍提高，后者是个别企业领先。
讲法
徐涛用「c 转移、v 增殖、m 被占有」九个字讲清三者关系。腿姐计算题先写公式再代数，m′ 与 p′ 的分母一定要分清。

资本积累与资本有机构成

核心高频

资本积累是把剩余价值转化为资本，实质是资本家用无偿占有的剩余价值扩大资本规模。资本有机构成 c:v 随技术进步而提高，导致可变资本相对减少，形成相对过剩人口。资本积累的一般规律是财富积累与贫困积累并存。

资本有机构成 = c : v用价值形式表示的技术构成
有机构成提高 → 可变资本相对减少 → 相对过剩人口不是绝对减少
资本积聚（单个资本增大）≠ 资本集中（多个资本合并）选择常考
同型 马原选择题

资本有机构成提高为什么会导致相对过剩人口？

要点 有机构成提高意味着总资本中可变资本占比下降，对劳动力的需求相对减少，而劳动力供给仍在增加，于是形成相对于资本增殖需要而言的过剩人口。
完整解答
  1. 资本有机构成 c:v 提高，总资本中可变资本占比下降。
  2. 对劳动力的需求相对减少，而劳动力供给仍在增加。
  3. 于是形成相对于资本增殖需要而言的相对过剩人口。
  4. 结论：是相对过剩，不是人口绝对过剩。
易错
  • 把相对过剩人口理解为「人口绝对过多」。
  • 混淆资本积聚与资本集中。
  • 认为有机构成提高会使可变资本绝对减少。
讲法
腿姐keywords：「相对」过剩不是「绝对」过剩，选择题常在此设陷。

资本循环与资本周转

基础中频

资本循环经历购买、生产、售卖三个阶段，相应采取货币资本、生产资本、商品资本三种职能形式。连续循环的条件是三种形式在空间上并存、在时间上继起。资本周转研究速度，固定资本与流动资本的划分依据是价值周转方式。

循环三阶段：购买 — 生产 — 售卖对应货币、生产、商品资本
连续条件：空间并存 + 时间继起缺一不可
固定资本：价值逐步转移；流动资本：价值一次转移划分依据是周转方式
同型 马原选择题

机器、厂房属于固定资本，原材料、燃料属于流动资本，划分依据是什么？

要点 依据价值周转方式：固定资本价值逐步转移到产品中，流动资本价值一次全部转移。不是按物质形态或使用年限划分。
完整解答
  1. 划分依据是价值周转方式，不是物质形态或使用年限。
  2. 固定资本价值逐步转移到产品中，多次周转。
  3. 流动资本价值一次全部转移。
  4. 结论：机器厂房属固定资本，原材料燃料属流动资本。
易错
  • 按物品的物理属性划分固定资本与流动资本。
  • 把资本循环三阶段与资本周转影响因素混淆。
  • 认为三种职能形式可以只保留一种。
讲法
徐涛画「三段—三形式—两条件」简图，强调并存与继起是同一过程的两面。

社会总资本再生产与经济危机

基础中频

社会总资本再生产的核心问题是社会总产品的实现，包括价值补偿与实物补偿。社会生产分为生产资料生产（第Ⅰ部类）和消费资料生产（第Ⅱ部类）。资本主义经济危机的实质是生产相对过剩，根源是资本主义基本矛盾。

核心问题：总产品如何卖出 + 如何买回价值补偿 + 实物补偿
两大部类：Ⅰ 生产资料；Ⅱ 消费资料简单再生产 Ⅰ(v+m)=Ⅱc
危机实质：生产相对过剩相对于劳动人民有支付能力的需求
同型 马原选择题

资本主义经济危机的实质是（ ）。

要点 生产相对过剩，即相对于劳动人民有支付能力的需求而言商品过剩，而不是绝对过剩。
完整解答
  1. 资本主义经济危机的实质是生产相对过剩。
  2. 是相对于劳动人民有支付能力的需求而言的过剩。
  3. 不是绝对过剩，而是资本无限增殖与有支付能力需求不足的矛盾。
  4. 结论：生产相对过剩。
易错
  • 把经济危机实质说成「生产绝对过剩」。
  • 认为危机根源是消费不足或货币不足。
  • 混淆价值补偿与实物补偿。
讲法
腿姐keywords：「相对过剩」四个字必须完整写出，少「相对」就错。

垄断资本主义与经济全球化

基础中频

自由竞争引起生产集中，生产集中发展到一定程度必然产生垄断。金融资本是工业垄断资本与银行垄断资本融合形成的。国家垄断资本主义是垄断资本与国家政权相结合的资本主义。经济全球化是生产社会化、国际化发展的必然结果，具有二重性。

自由竞争 → 生产集中 → 垄断垄断没有消除竞争，而是使竞争更复杂
金融资本 = 工业垄断资本 + 银行垄断资本不是单纯银行资本
经济全球化：生产 · 贸易 · 金融 · 企业全球化二重性：机遇 + 风险
同型 马原选择题

垄断形成后，为什么说竞争依然存在？

要点 垄断没有消除产生竞争的经济条件，垄断组织之间、垄断与非垄断之间、垄断组织内部仍存在竞争，且竞争形式更复杂、更激烈。
完整解答
  1. 垄断没有消除商品经济，产生竞争的经济条件仍然存在。
  2. 垄断组织之间、垄断与非垄断之间、垄断组织内部都存在竞争。
  3. 竞争形式更复杂、更激烈。
  4. 结论：垄断与竞争并存。
易错
  • 认为垄断消除了竞争。
  • 把金融资本等同于银行资本。
  • 只讲经济全球化的积极面，忽略二重性。
讲法
徐涛用「垄断是竞争的产物，又加剧竞争」一句打通，避免把二者对立。

社会主义从空想到科学

核心高频

空想社会主义代表：圣西门、傅立叶、欧文。马克思、恩格斯创立唯物史观和剩余价值学说，使社会主义从空想变为科学。《共产党宣言》1848 年发表，标志科学社会主义诞生。社会主义发展道路具有多样性，共产主义社会的基本特征是物质财富极大丰富、人民精神境界极大提高、每个人自由而全面发展。

两大发现：唯物史观 + 剩余价值学说空想变科学的关键
《共产党宣言》1848 = 科学社会主义诞生常考时间点
共产主义特征：物质极大丰富 · 精神极大提高 · 自由全面发展三句并列
同型 马原选择题

使社会主义从空想变为科学的根本原因是什么？

要点 唯物史观揭示了社会发展规律，剩余价值学说揭示了资本主义剥削的秘密，二者共同为科学社会主义奠定理论基础。
完整解答
  1. 唯物史观揭示了社会发展的一般规律。
  2. 剩余价值学说揭示了资本主义剥削的秘密。
  3. 两大发现共同为科学社会主义奠定理论基础。
  4. 结论：使社会主义从空想变为科学。
易错
  • 把空想社会主义者误记为马克思、恩格斯。
  • 把《共产党宣言》与《资本论》的里程碑意义混淆。
  • 认为社会主义发展道路只有一种模式。
讲法
腿姐时间线：1848《宣言》—两大发现—科学社会主义；用「两个人、两发现、一本书」记。

专题 01

政经计算题：四类公式与固定流程

马原计算题只在政经部分出现，题型高度固定：剩余价值率、利润率、资本有机构成、货币流通量。背住公式、按步代入，基本是送分题；但分母写错就会整题归零。

  1. 先判断题问哪个量：m′、p′、c:v、流通货币量，还是价值量变化。
  2. 写出对应公式，不跳步：m′ = m/v；p′ = m/(c+v)；有机构成 = c:v。
  3. 标注已知量，统一单位；缺少的量先用总资本或价值构成求出。
  4. 代入计算，结果保留百分数或比例，注明含义。
  5. 遇到劳动生产率变化，先判断问「单位商品价值量」还是「同一时间价值总量」。
例

某资本 c=80 万元、v=20 万元、m=20 万元。求剩余价值率、利润率与资本有机构成。

解 m′ = 20/20 = 100%；p′ = 20/(80+20) = 20%；资本有机构成 c:v = 80:20 = 4:1。

踩坑点 最常见的错误是把利润率分母写成 v，或把有机构成写成 v:c。写完公式先检查分母含义，再动笔算。
[[T-topic-02]]
专题 02

科社与垄断部分的关键词记忆

科社与垄断资本主义以选择题为主，考的是「谁、什么时候、哪本书、什么标志」。这些点碎但固定，适合用关键词卡片集中突破。

  1. 人物—著作—标志三列成表：圣西门/傅立叶/欧文—空想；马恩—《共产党宣言》1848—科学社会主义诞生。
  2. 垄断链条：自由竞争→生产集中→垄断→金融资本→国家垄断→经济全球化。
  3. 每个概念只记一个判别词：垄断「没有消除竞争」；金融资本「融合」；危机「相对过剩」。
  4. 用排除法做选择：出现「消除竞争」「绝对过剩」「唯一模式」直接排除。
  5. 考前只复习自己整理的关键词表，不再重读教材。
例

「垄断资本主义阶段，竞争已经被消除。」判断正误。

解 错误。垄断没有消除产生竞争的经济条件，反而使竞争在更大范围、更高层次上展开。

踩坑点 不要把「垄断」理解成「一家独大、没有竞争」；考研政治的标准表述是「垄断与竞争并存」。
