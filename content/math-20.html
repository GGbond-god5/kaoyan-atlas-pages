01

矩估计

核心必考

矩估计用样本矩代替总体矩：令 \(E(X)=\bar X\)、\(E(X^2)=\frac1n\sum X_i^2\)，解出参数。单参数只需一阶矩；双参数需要一阶与二阶矩联立。矩估计不依赖分布的具体形式，计算稳定。

\(E(X)=\bar X\)一阶矩
\(E(X^2)=\dfrac1n\sum X_i^2\)二阶矩，注意分母是 n
\(D(X)=\dfrac1n\sum(X_i-\bar X)^2\)等价写法，便于双参数
同型 数一

总体 \(X\sim E(\lambda)\)，求 \(\lambda\) 的矩估计。

要点 \(E(X)=1/\lambda=\bar X\)，故 \(\hat\lambda=1/\bar X\)。
完整解答
  1. 一阶总体矩 \(E(X)=1/\lambda\)（指数分布）。
  2. 令总体矩等于样本矩：\(\frac1\lambda=\bar X\)。
  3. 解出 \(\hat\lambda=1/\bar X\)（\(\bar X>0\)）。
  4. 检验：\(\hat\lambda>0\)；当 \(\bar X\to1/\lambda\) 时，\(\hat\lambda\to\lambda\)。
易错
  • 二阶矩误用样本方差 \(S^2\)（分母 n-1）导致有偏；
  • 双参数只列一个方程。
讲法
武忠祥矩估计就是“样本矩替换总体矩”，有几个参数列几个方程。

02

最大似然估计

核心必考

最大似然的思想是“让已观测到的样本出现概率最大”。步骤固定：写似然函数、取对数、求导令零、解出参数并验证最大值。遇到似然函数关于参数单调时，导数无零点，参数估计取边界（如均匀分布取最大观测值）。

\(L(\theta)=\prod_{i=1}^n f(x_i;\theta)\)连续型；离散型用分布律
\(\ell(\theta)=\ln L(\theta),\quad \ell'(\theta)=0\)对数似然
\(X\sim U(0,\theta)\Rightarrow\hat\theta=max_i X_i\)单调情形的边界解
同型 数一

总体 \(X\sim E(\lambda)\)，样本 \(x_1,\dots,x_n\)，求 \(\lambda\) 的最大似然估计。

要点 \(L=\lambda^n e^{-\lambda\sum x_i}\)，\(\ln L=n\ln\lambda-\lambda\sum x_i\)，求导得 \(\hat\lambda=n/\sum x_i=1/\bar x\)。
完整解答
  1. 似然函数 \(L(\lambda)=\prod_{i=1}^n\lambda e^{-\lambda x_i}=\lambda^n e^{-\lambda\sum x_i}\)。
  2. 取对数 \(\ln L=n\ln\lambda-\lambda\sum x_i\)。
  3. 求导并令零：\(\frac{d\ln L}{d\lambda}=\frac n\lambda-\sum x_i=0\)，得 \(\hat\lambda=\frac{n}{\sum x_i}=\frac1{\bar x}\)。
  4. 二阶导 \(-\frac{n}{\lambda^2}<0\)，故为极大值；与矩估计一致。
易错
  • 忘记取对数直接求导；
  • 单调似然仍强行令导数为零；
  • 求出驻点不验证是极大值。
讲法
张宇MLE 四步：写 L、取对数、求导、回代；先判断是否单调再动导数。

03

估计量的评选标准

核心高频

无偏性看期望是否等于真值；有效性在无偏前提下比较方差，方差越小越有效；一致性看样本量趋于无穷时是否依概率收敛到真值。\(\bar X\) 与 \(S^2\) 分别是 \(\mu\) 与 \(\sigma^2\) 的无偏估计，这是最常用的两条结论。

\(E(\hat\theta)=\theta\)无偏
\(D(\hat\theta_1)<D(\hat\theta_2)\)更有效
\(\hat\theta_n\xrightarrow{P}\theta\)一致
同型 数一

判断 \(\frac1n\sum(X_i-\bar X)^2\) 是否为 \(\sigma^2\) 的无偏估计。

要点 不是。其期望为 \(\frac{n-1}{n}\sigma^2\)，修正为 \(S^2\)（分母 n-1）后才无偏。
完整解答
  1. 记 \(T=\frac1n\sum_{i=1}^n(X_i-\bar X)^2\)。
  2. 利用 \(\sum(X_i-\bar X)^2=(n-1)S^2\)，且 \(E(S^2)=\sigma^2\)。
  3. \(E(T)=\frac{n-1}{n}\sigma^2\ne\sigma^2\)，故有偏，偏差为 \(-\sigma^2/n\)。
  4. 修正：\(S^2=\frac1{n-1}\sum(X_i-\bar X)^2\) 才无偏。
易错
  • 把有效性用于有偏估计比较；
  • 认为无偏一定一致；
  • 分母 n 与 n-1 混用。
讲法
武忠祥先判无偏，再比方差，最后看一致性；顺序不能乱。

区间估计

核心高频

区间估计给出未知参数的置信区间。均值区间分两种：方差已知用 u 分位数，方差未知用 t 分位数。方差的区间用 \(\chi^2\) 分位数，注意两侧分位数方向相反。置信度 95% 的含义是重复抽样下 95% 的区间会覆盖真值，不是参数有 95% 概率落在某个固定区间。

\(\bar X\pm z_{\alpha/2}\dfrac{\sigma}{\sqrt n}\)\(\sigma\) 已知
\(\bar X\pm t_{\alpha/2}(n-1)\dfrac{S}{\sqrt n}\)\(\sigma\) 未知
\(\left(\dfrac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)},\ \dfrac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right)\)方差区间，分母大小位置易反
同型 数一

总体正态，方差未知，n=16，\(\bar X=10,S=2\)，求 \(\mu\) 的 95% 置信区间（\(t_{0.025}(15)=2.131\)）。

要点 \(10\pm2.131\times\frac{2}{4}=10\pm1.0655\)，即 \((8.93,11.07)\)。
完整解答
  1. 方差未知，用 \(t\) 枢轴量 \(t=\frac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)\)。
  2. 置信水平 0.95，\(\alpha/2=0.025\)，临界值 \(t_{0.025}(15)=2.131\)。
  3. 误差限 \(=2.131\times\frac{S}{\sqrt n}=2.131\times\frac24=1.0655\)。
  4. 区间 \(\bar X\pm\) 误差限 \(=10\pm1.0655\)，即 \((8.93,11.07)\)。
易错
  • 方差未知仍用 z 分位数；
  • 方差区间的两个分位数写反；
  • 把置信度解释为参数的概率。
讲法
张宇区间估计先定“方差已知还是未知”，再选 z 或 t；方差区间记“小除大、大除小”。

假设检验与两类错误

核心必考

假设检验先设 \(H_0\)，在 \(H_0\) 成立下构造统计量，按显著性水平 \(\alpha\) 划拒绝域。第一类错误是“弃真”，概率为 \(\alpha\)；第二类错误是“取伪”，概率为 \(\beta\)。样本量固定时，减小 \(\alpha\) 会增大 \(\beta\)，不能同时减小。

\(\alpha=P(\text{拒绝}H_0\mid H_0\text{真})\)第一类错误
\(\beta=P(\text{接受}H_0\mid H_1\text{真})\)第二类错误
\(\text{功效}=1-\beta\)检出真实差异的能力
同型 数一

已知检验的第一类错误概率为 0.05，问“\(\alpha\) 减小到 0.01 时，\(\beta\) 如何变化”。

要点 在样本量不变时 \(\beta\) 增大；要同时减小两类错误，只能增大样本量。
完整解答
  1. 第一类错误 \(\alpha=P(\text{拒绝}H_0\mid H_0\text{真})\)，第二类错误 \(\beta=P(\text{接受}H_0\mid H_1\text{真})\)。
  2. 样本量固定时，减小 \(\alpha\) 会使拒绝域变小，更难拒绝 \(H_0\)。
  3. 因此 \(\beta\) 必然增大；两类错误此消彼长。
  4. 要同时减小两类错误，只能增大样本量 \(n\)。
易错
  • 把 \(\alpha\) 与 \(\beta\) 混为一谈；
  • 认为减小 \(\alpha\) 总更好；
  • 接受 \(H_0\) 说成“证明 \(H_0\) 成立”。
讲法
武忠祥记“弃真 α、取伪 β；α 严则 β 松”，这是选填的固定结论。

正态总体参数的假设检验

核心高频

四种检验对应四种统计量：均值方差已知用 u 检验，方差未知用 t 检验；方差用 \(\chi^2\) 检验；两方差比用 F 检验。拒绝域由备择假设的方向决定：双侧取两端，单侧取一端。

\(u=\dfrac{\bar X-\mu_0}{\sigma/\sqrt n}\sim N(0,1)\)u 检验
\(t=\dfrac{\bar X-\mu_0}{S/\sqrt n}\sim t(n-1)\)t 检验
\(\chi^2=\dfrac{(n-1)S^2}{\sigma_0^2}\sim\chi^2(n-1)\)方差检验
\(F=\dfrac{S_1^2}{S_2^2}\sim F(n_1-1,n_2-1)\)两方差比
同型 数一

总体正态，方差未知，检验 \(H_0:\mu=\mu_0\) 对 \(H_1:\mu\ne\mu_0\)，写出拒绝域。

要点 \(|t|>t_{\alpha/2}(n-1)\)，其中 \(t=(\bar X-\mu_0)/(S/\sqrt n)\)。双侧检验取两端，每端面积 \(\alpha/2\)。
完整解答
  1. 建立假设：\(H_0:\mu=\mu_0\)，\(H_1:\mu\ne\mu_0\)，方差未知。
  2. 检验统计量 \(t=\frac{\bar X-\mu_0}{S/\sqrt n}\)，在 \(H_0\) 下服从 \(t(n-1)\)。
  3. 双侧检验显著性 \(\alpha\)，拒绝域为 \(|t|>t_{\alpha/2}(n-1)\)。
  4. 等价地计算 \(p=P(|T|>|t|)\)，若 \(p<\alpha\) 则拒绝 \(H_0\)。
易错
  • 单双侧的拒绝域写反；
  • 方差未知用 u 检验；
  • \(H_0\) 与 \(H_1\) 的方向设反。
讲法
没咋了先看题目问“是否等于”还是“是否大于”，再决定双侧或单侧；统计量只由已知条件决定。

专题 01

最大似然四步与边界情形

MLE 是数一概率解答题最稳定的得分点，步骤固定。真正拉开差距的是“单调似然”这一类不考导数的情况。

  1. 写似然：连续型连乘密度，离散型连乘分布律，注意支撑集。
  2. 取对数：把乘积变求和，定义域先写清楚。
  3. 求导令零：解出驻点；多参数时对每个参数分别求偏导。
  4. 验证极大：二阶导或单调性；单调时取边界。
  5. 回代写估计量：用样本表示，加帽子，注明参数范围。
例

总体 \(X\sim U(0,\theta)\)，求 \(\theta\) 的 MLE。

解 似然 \(L=\theta^{-n}\) 在 \(\theta\ge max x_i\) 上单调递减，故在边界 \(\hat\theta=max x_i\) 取最大，不能令导数为零。

踩坑点 先看支撑集是否依赖参数；依赖参数时，边界往往就是答案。这是 MLE 最容易漏的一类。
[[T-topic-02]]
专题 02

假设检验流程与两类错误

数一对检验的考查以选填和小计算为主，重点是“设对假设、选对统计量、写对拒绝域”，以及 α 与 β 的此消彼长。

  1. 设假设：把“想证明的”放在备择 \(H_1\)，\(H_0\) 取等号。
  2. 选统计量：均值方差已知 u，未知 t；方差 \(\chi^2\)；两方差比 F。
  3. 定拒绝域：双侧两端、单侧一端，分位数按 \(\alpha\) 或 \(\alpha/2\)。
  4. 算观测值并比较，落到拒绝域则拒绝 \(H_0\)。
  5. 解释结论：拒绝 \(H_0\) 是有统计依据的差异；接受 \(H_0\) 只是证据不足。
例

\(n=25\)，\(S=2\)，\(\bar X=10.5\)，检验 \(H_0:\mu=10\) 对 \(H_1:\mu>10\)，\(\alpha=0.05\)，\(t_{0.05}(24)=1.711\)。

解 \(t=\frac{10.5-10}{2/5}=1.25<1.711\)，不拒绝 \(H_0\)。单侧检验的临界值取 \(t_{\alpha}\) 而非 \(t_{\alpha/2}\)。

踩坑点 “接受 H0”不等于“H0 为真”；两类错误与样本量三者相互制约，选择题常在此设陷阱。
