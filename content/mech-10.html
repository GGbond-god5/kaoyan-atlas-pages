外力功与应变能

基础高频

在线弹性范围内，外力由零缓慢增加到最终值，外力功等于应变能：\(W=U=\tfrac12F\Delta\)。应变能是状态量，与加载路径无关；但外力功在非线性或卸载时不再等于应变能。能量法的所有公式都建立在这一关系上。

\(W=U=\dfrac12F\Delta\)线弹性、静载
\(u=\dfrac{\sigma^2}{2E}\)拉压应变能密度
\(U=\iiint u\,dV\)整个构件的应变能
同型 807 概念题

为什么外力功等于应变能只在线弹性静载下成立？

要点 线弹性静载下加载与卸载路径重合、无能量耗散；若进入塑性或有动载，部分能量转化为热或动能，外力功不再全部储存为应变能。
完整解答
  1. 线弹性静载下，加载与卸载沿同一路径，无塑性耗散。
  2. 外力功全部转化为应变能，\(W=U\)。
  3. 若进入塑性，部分功转化为热；若有动载，部分转化为动能。
  4. 此时 \(W\ne U\)，需用能量守恒另列方程。
  5. 结论：\(W=U\) 的适用条件是线弹性、静载、无耗散。
易错
  • 把 \(W=F\Delta\) 当成通用公式（缺少 1/2）。
  • 认为应变能与加载顺序有关。
讲法
瞌睡哥能量法第一句先写 \(U=\tfrac12F\Delta\)，再往下推。

基本变形的应变能

核心必考

拉压杆 \(U=F_N^2l/(2EA)\)；圆轴 \(U=T^2l/(2GI_p)\)；梁 \(U=\int M^2dx/(2EI)\)。组合变形时各项相加。这些公式是卡氏定理与单位载荷法的基础，必须能按内力类型快速写出。

\(U=\dfrac{F_N^2l}{2EA}\)拉压
\(U=\dfrac{T^2l}{2GI_p}\)扭转
\(U=\int\dfrac{M^2(x)}{2EI}\,dx\)弯曲
\(U=\int\dfrac{F_S^2}{2GA}k\,dx\)剪切，k 为截面系数，通常忽略
同型 807 高频题型

简支梁受均布载荷，求梁内应变能。

要点 \(M(x)=qx(l-x)/2\)，代入 \(U=\int_0^l M^2/(2EI)dx\) 积分得 \(U=q^2l^5/(240EI)\)。
完整解答
  1. 简支梁均布载荷，\(M(x)=qx(l-x)/2\)。
  2. 应变能 \(U=\int_0^l M^2/(2EI)\,dx\)。
  3. 代入 \(M(x)\) 并利用对称性积分。
  4. 得 \(U=q^2l^5/(240EI)\)。
  5. 校核量纲：\(q^2l^5/(EI)\) 为能量量纲。
易错
  • 忘记平方，写成 \(Fl/(2EA)\)。
  • 弯曲应变能漏掉积分，直接用 \(M^2l/(2EI)\)。
讲法
瞌睡哥三个应变能公式结构相同：内力平方 × 长度 /（2 × 刚度）。

03

卡氏第二定理

核心高频

线弹性结构的应变能对某个广义力的偏导数，等于该力作用点沿力方向的广义位移：\(\Delta_i=\partial U/\partial F_i\)。求哪一点的位移，就在该点沿所求方向加一个力，求偏导后令其为零。卡氏第二定理适合集中力作用点的位移。

\(\Delta_i=\dfrac{\partial U}{\partial F_i}\)卡氏第二定理
\(\Delta=\dfrac{\partial}{\partial F}\int\dfrac{M^2}{2EI}dx=\int\dfrac{M}{EI}\dfrac{\partial M}{\partial F}dx\)弯曲问题常用形式
同型 807 题

悬臂梁自由端受集中力，用卡氏定理求自由端挠度。

要点 \(M(x)=Fx\)，\(U=\int_0^l F^2x^2/(2EI)dx=F^2l^3/(6EI)\)；\(\Delta=\partial U/\partial F=Fl^3/(3EI)\)。
完整解答
  1. 悬臂梁自由端集中力 \(F\)，距固定端 \(x\) 处 \(M(x)=F(l-x)\)（或从自由端量 \(M=Fx\)）。
  2. 应变能 \(U=\int_0^l F^2(l-x)^2/(2EI)\,dx=F^2l^3/(6EI)\)。
  3. 卡氏第二定理 \(\Delta=\partial U/\partial F\)。
  4. 求导得 \(\Delta=Fl^3/(3EI)\)。
  5. 与积分法结果一致，方向沿 \(F\) 方向。
易错
  • 所求点没有力，忘记先加一个虚拟力。
  • 对 \(U\) 求导时把 \(F\) 当常数。
讲法
瞌睡哥卡氏定理的适用条件是“所求位移处有对应的广义力”；没有就加零力法。

单位载荷法（莫尔积分）

核心必考

在所求位移方向加单位力（求转角加单位力偶），分别计算实际载荷与单位载荷下的内力，则位移为 \(\Delta=\int M\bar M/(EI)dx\)（弯曲为主，拉压、扭转类似）。单位载荷法不要求所求点有力，是求任意点位移的通用方法。

\(\Delta=\int\dfrac{M\bar M}{EI}\,dx\)弯曲位移
\(\Delta=\sum\int\dfrac{F_N\bar F_N}{EA}dx+\sum\int\dfrac{T\bar T}{GI_p}dx+\sum\int\dfrac{M\bar M}{EI}dx\)组合变形
\(\theta=\int\dfrac{M\bar M}{EI}\,dx\)求转角时单位载荷为力偶
真题 2025 · 807 计算（25 分）

半圆轴（曲杆）在载荷作用下，要求用单位载荷法求指定点位移。

要点 在所求点沿位移方向加单位力；分段（或分角）写出实际弯矩与单位弯矩；沿曲杆积分 \(\int M\bar M/(EI)ds\)，注意 ds=Rdθ 与弯矩正负。
完整解答
  1. 在所求点沿待求位移方向加单位力（求转角加单位力偶）。
  2. 用角度 \(\theta\) 参数写实际弯矩 \(M(\theta)\) 与单位弯矩 \(\bar M(\theta)\)。
  3. 曲杆弧长微元 \(ds=R\,d\theta\)。
  4. 积分 \(\Delta=\int_0^{\theta_0} M\bar M/(EI)\,ds\)，注意各段弯矩正负。
  5. 结果为正表示位移与单位力同向。
易错
  • 单位力方向与所求位移方向不一致。
  • 曲杆忘记 \(ds=R\,d\theta\)，直接对 \(dx\) 积分。
  • 实际弯矩与单位弯矩的正负号不统一。
讲法
瞌睡哥单位载荷法四步：加单位力、写两套弯矩、积分、定符号；曲杆把 ds 换成 Rdθ。

图乘法

核心必考

当 \(EI\) 为常数、且两个弯矩图中至少有一个是直线时，莫尔积分可用图乘法：\(\Delta=\sum \omega y_c/(EI)\)，其中 \(\omega\) 为其中一个弯矩图的面积，\(y_c\) 为该图形心处另一弯矩图的纵坐标。图乘法是 807 求位移最快的工具。

\(\Delta=\sum\dfrac{\omega y_c}{EI}\)ω 为面积，y_c 为形心对应纵坐标
\(\omega=\dfrac23\cdot\dfrac{ql^2}{8}\cdot l\)简支均布弯矩图面积示例
\(y_c=\bar M(x_c)\)单位弯矩图在形心横坐标处的纵坐标
同型 807 高频题型

悬臂梁受均布载荷，用图乘法求自由端挠度。

要点 实际弯矩图为抛物线，面积 \(\omega=ql^3/6\)，形心距自由端 \(3l/4\)；单位力弯矩图为直线，在该处 \(y_c=3l/4\)；\(\Delta=\omega y_c/(EI)=ql^4/(8EI)\)。若用简支梁，单位弯矩图在跨中有折点，必须从中点分开图乘。
完整解答
  1. 实际弯矩图为均布载荷下的抛物线，面积 \(\omega=ql^3/6\)。
  2. 抛物线形心距自由端 \(3l/4\)。
  3. 单位力弯矩图为直线，在形心处纵标 \(y_c=3l/4\)。
  4. 图乘 \(\Delta=\omega y_c/(EI)=(ql^3/6)(3l/4)/EI=ql^4/(8EI)\)。
  5. 与积分法结果一致。
易错
  • 两个弯矩图都是曲线时仍用图乘法。
  • 把面积图的形心位置取错（抛物线形心不在中点）。
  • 正负号不统一，导致位移相减。
讲法
瞌睡哥图乘法只适用于“至少一张直线图”；抛物线×抛物线必须积分。

互等定理

进阶低频

功的互等定理：第一组力在第二组力引起的位移上做的功，等于第二组力在第一组力引起的位移上做的功。位移互等定理是其特例：\(\delta_{ij}=\delta_{ji}\)。互等定理多用于概念题与简化计算，不直接考大题。

\(W_{12}=W_{21}\)功的互等
\(\delta_{ij}=\delta_{ji}\)位移互等
同型 807 概念题

位移互等定理的适用条件是什么？

要点 线弹性、小变形、两个广义力与广义位移对应；结构几何与支承不变。
完整解答
  1. 结构必须线弹性、小变形。
  2. 两个广义力与广义位移一一对应。
  3. 结构的几何、支承与材料不随加载改变。
  4. 满足时 \(F_1\Delta_{21}=F_2\Delta_{12}\)。
  5. 结论：互等定理不能用于塑性、大变形或变结构问题。
易错
  • 把互等定理用于非线性或大变形结构。
  • 广义力与广义位移不对应。
讲法
瞌睡哥低频点只记结论与适用条件，不展开证明。

图乘法进阶：变刚度与分段

进阶高频

阶梯梁的 \(EI\) 分段为常数，必须分段图乘再相加；同一段内 \(M\) 图面积与单位力图的纵标要取自同一段。把整根梁用同一个 \(EI\) 是这类题最常见的失分点。

\(\Delta=\sum_i\dfrac{\omega_i\,y_{Ci}}{E_iI_i}\)分段图乘
\(\omega_1=\dfrac{Pa^2}{2},\ y_{C1}=\dfrac{2a}{3}\)自由半段三角形
\(\omega_2=\dfrac{3Pa^2}{2},\ y_{C2}=\dfrac{14a}{9}\)固定半段梯形
同型 807 题

悬臂梁长 \(2a\)，自由半段抗弯刚度 \(EI\)，固定半段 \(2EI\)，自由端受集中力 \(P\)，用图乘法求自由端挠度。

要点 \(\Delta=\dfrac{3Pa^3}{2EI}\)。
完整解答
  1. 实际弯矩图：自由端为 0，中点 \(Pa\)，固定端 \(2Pa\)。
  2. 单位力弯矩图：自由端 0，中点 \(a\)，固定端 \(2a\)。
  3. 自由半段（三角形，\(EI\)）：\(\omega_1=Pa^2/2\)，形心处单位弯矩 \(2a/3\)，贡献 \(Pa^3/(3EI)\)。
  4. 固定半段（梯形，\(2EI\)）：\(\omega_2=3Pa^2/2\)，形心距自由端 \(14a/9\)，贡献 \(\omega_2(14a/9)/(2EI)=7Pa^3/(6EI)\)。
  5. 相加：\(\Delta=Pa^3/(3EI)+7Pa^3/(6EI)=3Pa^3/(2EI)\)，方向向下。
易错
  • 整根梁用同一 \(EI\)，忘记固定半段是 \(2EI\)。
  • 梯形形心位置取错，或单位力图纵标与面积不在同一段。
讲法
瞌睡哥图乘先分段、再定面积与形心，最后逐段除以各自 \(EI\)。

专题 01

单位载荷法求位移：四步闭环

2025 年以 25 分考了半圆轴位移，说明 807 对曲杆 + 单位载荷法的组合有偏好。步骤固定，但曲杆积分与符号是主要失分点。

  1. 确定所求位移方向，在该点加单位力（或单位力偶）。
  2. 分别写实际载荷与单位载荷下的弯矩方程，分段（曲杆分角）。
  3. 统一正负号与坐标，沿杆长积分 \(\int M\bar M/(EI)ds\)。
  4. 曲杆用 \(ds=R\,d\theta\)，注意积分限。
  5. 结果为正表示位移与单位力同向；负号说明反向。
例

半圆曲杆一端固定，自由端受铅垂力 F，求自由端铅垂位移（EI 常数，半径 R）。

解 取角 θ 从自由端量起，\(M=FR\sin\theta\)；单位力下 \(\bar M=R\sin\theta\)；\(\Delta=\int_0^{\pi} F R^2\sin^2\theta\cdot R\,d\theta/(EI)=\pi F R^3/(2EI)\)。

踩坑点 曲杆的弯矩是 \(FR\sin\theta\)，不是 \(FR\theta\)；角度从自由端或固定端量起都可以，但两套弯矩必须用同一角度。

专题 02

图乘法速算与形心表

图乘法能把积分变成乘法，是 807 节省时间的核心工具；但形心位置与图形面积必须记准，否则快而不对。

  1. 画出实际弯矩图与单位力弯矩图。
  2. 确认至少一张是直线图，且 EI 为常数。
  3. 取曲线图的面积 ω，找其形心横坐标。
  4. 在直线图上取该横坐标对应的纵坐标 y_c。
  5. 相乘除以 EI，同号相加、异号相减。
例

悬臂梁受均布载荷 q，用图乘法求自由端挠度。

解 实际弯矩图面积 \(\omega=ql^3/6\)，形心距固定端 \(3l/4\)；单位力弯矩图在该处 \(y_c=3l/4\)；\(\Delta=\omega y_c/(EI)=ql^4/(8EI)\)。

踩坑点 抛物线图形的形心不在中点：均布载荷弯矩图的形心距固定端 3l/4（悬臂）或跨中（简支对称）。

专题 03

推导：卡氏第二定理与单位载荷法

807 的能量法几乎每年出现。知道 \(\Delta=\partial U/\partial F\) 怎么来，才能在图乘、温度、弹簧、超静定之间自由切换。

  1. 应变能：弯曲 \(U=\int \dfrac{M^2}{2EI}dx\)；拉压 \(U=\int \dfrac{F_N^2}{2EA}dx\)；扭转 \(U=\int \dfrac{T^2}{2GI_p}dx\)。
  2. 卡氏第二定理：\(\Delta_i=\dfrac{\partial U}{\partial F_i}\)。对弯曲项求偏导，\(\Delta_i=\int \dfrac{M}{EI}\dfrac{\partial M}{\partial F_i}dx\)。
  3. 单位载荷法：在所求位移方向加单位力 \(1\)，其弯矩记为 \(\bar M=\partial M/\partial F_i\)，则 \(\Delta=\int \dfrac{M\bar M}{EI}dx\)。
  4. 这等价于虚功原理：单位力做的虚功 \(1\cdot\Delta\) 等于内力虚功 \(\int M\bar M/(EI)dx\)。
  5. 图乘法：当 \(EI\) 分段为常数、且 \(M\) 与 \(\bar M\) 至少一个是直线时，\(\int M\bar M\,dx=\omega\cdot\bar y_C\)，其中 \(\omega\) 是 \(M\) 图面积、\(\bar y_C\) 是 \(\bar M\) 图在形心处的纵标。
  6. 符号：同侧取正、异侧取负；变刚度、分段、温度项要拆开分别图乘或积分。
例

悬臂梁长 \(l\)、抗弯刚度 \(EI\)，自由端受集中力 \(P\)，用卡氏第二定理求自由端挠度。

解 取自由端为原点，\(M(x)=-Px\)，\(U=\int_0^l P^2x^2/(2EI)dx=P^2l^3/(6EI)\)；\(\Delta=\partial U/\partial P=Pl^3/(3EI)\)，方向向下。

踩坑点 单位力要加在所求位移的方向上；\(\bar M\) 只能由单位力产生；图乘前先判断能否图乘（至少一个直线），变刚度要分段。
