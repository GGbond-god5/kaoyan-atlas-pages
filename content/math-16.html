联合分布函数

基础中频

二维联合分布函数 \(F(x,y)=P(X\le x,Y\le y)\) 是“左下角矩形”的概率。四条性质与一维平行：对每个变量单调不减、右连续、两端极限为 0 或 1。用它求矩形概率时注意端点归属。

\(F(x,y)=P(X\le x,\,Y\le y)\)联合分布函数
\(P(a<X\le b,\ c<Y\le d)=F(b,d)-F(a,d)-F(b,c)+F(a,c)\)容斥，符号易错
\(F(-\infty,y)=F(x,-\infty)=0,\ F(+\infty,+\infty)=1\)边界性质
同型 数一

已知联合分布函数 \(F(x,y)\)，求 \(P(1<X\le2,\ 0<Y\le1)\)。

要点 直接套容斥：\(F(2,1)-F(1,1)-F(2,0)+F(1,0)\)。四个角缺一不可，这是选填常考的符号题。
完整解答
  1. 矩形概率公式：\(P(a<X\le b,c<Y\le d)=F(b,d)-F(a,d)-F(b,c)+F(a,c)\)。
  2. 取 \(a=1,b=2,c=0,d=1\) 代入。
  3. 得 \(P(1<X\le2,0<Y\le1)=F(2,1)-F(1,1)-F(2,0)+F(1,0)\)。
  4. 检验：四个角符号为 \(+,-,-,+\)；端点等号在连续情形不影响结果。
易错
  • 容斥四项漏一项或符号写反；
  • 把 \(F(x,y)\) 当成 \(P(X\le x\text{ 或 }Y\le y)\)。
讲法
武忠祥用“左下角矩形”理解 F，矩形概率就是四个角加减，画图比背公式可靠。

联合分布与边缘分布

核心必考

联合分布完整决定边缘分布，反之不成立。离散型边缘化就是按行/列求和；连续型边缘密度就是对另一个变量积分。非矩形支撑集是数一最爱设的坎：积分上下限必须由区域图形读出来。

\(f_X(x)=\int_{-\infty}^{+\infty}f(x,y)\,dy\)边缘密度
\(f_Y(y)=\int_{-\infty}^{+\infty}f(x,y)\,dx\)另一个方向
\(p_{i\cdot}=\sum_j p_{ij},\quad p_{\cdot j}=\sum_i p_{ij}\)离散型边缘分布律
同型 数一

\((X,Y)\) 在三角形区域 \(D=\{(x,y):0<y<x<1\}\) 上服从均匀分布，求边缘密度 \(f_X,f_Y\)。

要点 区域面积 \(1/2\)，故 \(f=2\)。\(0<x<1\) 时 \(f_X(x)=\int_0^x2dy=2x\)；\(0<y<1\) 时 \(f_Y(y)=\int_y^1 2dx=2(1-y)\)。两条边缘密度不同，说明 X、Y 不独立。
完整解答
  1. 区域 \(D=\{0<y<x<1\}\) 是三角形，面积 \(=1/2\)，故联合密度 \(f=2\)（在 \(D\) 内）。
  2. \(f_X(x)=\int_0^x2\,dy=2x\)，\(0<x<1\)。
  3. \(f_Y(y)=\int_y^1 2\,dx=2(1-y)\)，\(0<y<1\)。
  4. 检验：\(\int_0^1 2x\,dx=1\)，\(\int_0^1 2(1-y)dy=1\)；两条边缘不同，故不独立。
易错
  • 边缘积分限直接写 0 到 1，忽略三角形约束；
  • 把边缘分布相乘当成联合分布。
讲法
张宇先画区域，再画一条竖线/横线穿过区域，穿入穿出点就是积分限。

条件分布

核心高频

条件分布是用联合分布除以边缘分布，本质仍是“缩小样本空间”。连续型条件密度 \(f_{Y|X}(y|x)=f(x,y)/f_X(x)\)，要求 \(f_X(x)>0\)；离散型条件分布律是联合分布律除以边缘分布律。

\(f_{Y|X}(y|x)=\dfrac{f(x,y)}{f_X(x)},\quad f_X(x)>0\)连续型
\(P(Y=y_j\mid X=x_i)=\dfrac{p_{ij}}{p_{i\cdot}}\)离散型
\(f(x,y)=f_X(x)f_{Y|X}(y|x)\)联合=边缘×条件
同型 数一

承上题三角形均匀分布，求 \(f_{Y|X}(y|x)\)，并说明给定 \(X=x\) 后 Y 服从什么分布。

要点 \(f_{Y|X}(y|x)=\frac{2}{2x}=\frac1x,\ 0<y<x\)，即 \(Y|X=x\sim U(0,x)\)。条件分布随 x 变化，是联合分布非矩形支撑的直接结果。
完整解答
  1. 条件密度 \(f_{Y\mid X}(y\mid x)=\frac{f(x,y)}{f_X(x)}\)。
  2. 在 \(D\) 内 \(f=2\)，且 \(f_X(x)=2x\)（由上一题）。
  3. 故 \(f_{Y\mid X}(y\mid x)=\frac{2}{2x}=\frac1x\)，\(0<y<x\)。
  4. 这是 \(U(0,x)\) 的密度；检验 \(\int_0^x\frac1x dy=1\)，且随 \(x\) 变化，说明不独立。
易错
  • 分母用 \(f_Y\) 而不是 \(f_X\)；
  • 条件密度的支撑集忘记随 x 变化。
讲法
武忠祥条件分布就是“固定 x 后切一刀”，截面上的相对密度；画图能立刻看出支撑。

随机变量的独立性

核心必考

X、Y 独立等价于联合分布等于边缘分布之积：\(f(x,y)=f_X(x)f_Y(y)\)（几乎处处），离散型对应 \(p_{ij}=p_{i\cdot}p_{\cdot j}\)。判定独立最快的方法是看支撑集是否为矩形：若支撑集不是两个区间的笛卡尔积，必不独立。

\(f(x,y)=f_X(x)f_Y(y)\)连续型独立
\(p_{ij}=p_{i\cdot}p_{\cdot j}\)离散型独立
\(F(x,y)=F_X(x)F_Y(y)\)等价定义
同型 数一

\((X,Y)\) 在单位圆内均匀分布，判断 X、Y 是否独立。

要点 不独立。支撑集是圆而非矩形，且边缘密度 \(f_X(x)=\frac{2}{\pi}\sqrt{1-x^2}\) 的乘积不等于常数 \(1/\pi\)。圆域均匀是“不独立但可能不相关”的经典反例。
完整解答
  1. 单位圆面积 \(\pi\)，联合密度 \(f=1/\pi\)（圆内）。
  2. \(f_X(x)=\int_{-\sqrt{1-x^2}}^{\sqrt{1-x^2}}\frac1\pi dy=\frac{2}{\pi}\sqrt{1-x^2}\)。
  3. 同理 \(f_Y(y)=\frac{2}{\pi}\sqrt{1-y^2}\)。
  4. \(f_Xf_Y\ne1/\pi\)，且支撑集不是矩形，故不独立；但对称性给出 \(\mathrm{Cov}=0\)，说明不相关不等于独立。
易错
  • 只在个别点验证乘积；
  • 把“不相关”当“独立”；
  • 忽略支撑集对独立性的否定作用。
讲法
张宇先看支撑：不是矩形直接判不独立，能省大量积分。

二维均匀分布

核心高频

\((X,Y)\) 在区域 D 上均匀分布，密度为 \(1/S_D\)（D 内），区域外为 0。所有概率都化为面积比。它是数一解答题最常用的载体，因为联合密度简单，难点全在区域与积分限。

\(f(x,y)=\dfrac{1}{S_D},\ (x,y)\in D\)\(S_D\) 为区域面积
\(P((X,Y)\in G)=\dfrac{S_{D\cap G}}{S_D}\)面积比
\(E(X)=\iint_D \dfrac{x}{S_D}\,dxdy\)期望也可用面积比算
同型 数一

\((X,Y)\) 在 \(D=\{(x,y):x^2+y^2\le1\}\) 上均匀，求 \(P(X^2+Y^2\le 1/4)\)。

要点 面积比：\(\pi(1/2)^2/\pi=1/4\)。均匀分布下不必积分，直接算面积，能显著节省时间。
完整解答
  1. 区域为半径 1 的圆，面积 \(\pi\)。
  2. 事件 \(X^2+Y^2\le1/4\) 是半径 \(1/2\) 的圆，面积 \(\pi/4\)。
  3. 均匀分布下概率等于面积比：\(\frac{\pi/4}{\pi}=1/4\)。
  4. 检验：结果在 \([0,1]\)，且小于 \(1/2\)，与半径缩小一致。
易错
  • 密度写成 1 而不是 \(1/S_D\)；
  • 区域面积算错（三角形、圆缺）；
  • 求期望时忘记乘密度。
讲法
武忠祥二维均匀题先算面积，再把事件翻译成子区域，能画图就不积分。

二维正态分布

进阶中频

二维正态由 \(\mu_1,\mu_2,\sigma_1,\sigma_2,\rho\) 五个参数确定。两条边缘都是一维正态；独立当且仅当 \(\rho=0\)（这是二维正态独有的性质）；非退化线性组合仍服从正态。

\((X,Y)\sim N(\mu_1,\mu_2;\sigma_1^2,\sigma_2^2;\rho)\)五参数
\(X\sim N(\mu_1,\sigma_1^2),\ Y\sim N(\mu_2,\sigma_2^2)\)边缘正态
\(X,Y\text{ 独立}\iff\rho=0\)仅二维正态成立
同型 数一

已知 \((X,Y)\) 服从二维正态分布且 \(\rho=0\)，判断 X、Y 是否独立；若 \(X,Y\) 服从一般分布且不相关，能否推出独立？

要点 二维正态下 \(\rho=0\) 等价于独立；一般分布不能，不相关只说明线性无关，可能存在非线性依赖。
完整解答
  1. 二维正态的联合密度由 \(\mu_1,\mu_2,\sigma_1,\sigma_2,\rho\) 完全决定。
  2. 当 \(\rho=0\) 时，联合密度可分解为两个一维正态密度之积。
  3. 故 \(X,Y\) 独立；反过来，一般分布不相关只说明 \(\mathrm{Cov}=0\)，不能推出独立。
  4. 反例：\(X\sim N(0,1),Y=X^2\)，\(\mathrm{Cov}=0\) 但 \(Y\) 由 \(X\) 决定。
易错
  • 把“二维正态且不相关⇒独立”推广到任意分布；
  • 线性组合的方差漏掉协方差项。
讲法
张宇二维正态是“不相关=独立”的唯一常见例外，考选择题必背这一条。

两个随机变量和的分布

核心必考

独立时和的密度用卷积公式：\(f_Z(z)=\int f_X(x)f_Y(z-x)dx\)。关键是确定 \(z\) 的分段：让 \(f_X(x)\) 与 \(f_Y(z-x)\) 同时非零的 x 区间随 z 移动，积分限随之改变。

\(f_Z(z)=\int_{-\infty}^{+\infty}f_X(x)f_Y(z-x)\,dx\)独立，连续型
\(P(Z=z_k)=\sum_i P(X=x_i)P(Y=z_k-x_i)\)离散型卷积
\(Z\sim N(\mu_1+\mu_2,\sigma_1^2+\sigma_2^2)\)独立正态的可加性
同型 数一

\(X,Y\) 独立同分布于 \(U(0,1)\)，求 \(Z=X+Y\) 的密度。

要点 \(0<z<1\) 时积分限 \(0\) 到 \(z\)，得 \(f_Z=z\)；\(1\le z<2\) 时积分限 \(z-1\) 到 \(1\)，得 \(2-z\)；其余为 0。三角形分布。
完整解答
  1. 用卷积公式 \(f_Z(z)=\int f_X(x)f_Y(z-x)dx\)，其中 \(f_X=f_Y=1\) 在 \((0,1)\)。
  2. 当 \(0<z<1\)，积分限 \(0\) 到 \(z\)，得 \(f_Z(z)=z\)。
  3. 当 \(1\le z<2\)，积分限 \(z-1\) 到 \(1\)，得 \(f_Z(z)=2-z\)。
  4. 其余为 0；检验 \(\int_0^1z\,dz+\int_1^2(2-z)dz=\frac12+\frac12=1\)。
易错
  • 积分限不随 z 分段；
  • 把卷积写成 \(f_X(x)f_Y(x)\)；
  • 忘记先判断 X、Y 是否独立。
讲法
武忠祥卷积题画两条数轴：固定 z，找 x 与 z-x 同时落在支撑集的交叠段，分段自然出现。

最大值与最小值的分布

进阶高频

独立同分布时，\(M=\max(X_1,\dots,X_n)\) 的分布用“全部不超过”转化：\(F_M(m)=[F(m)]^n\)；\(N=\min\) 用对立事件：\(F_N(n)=1-[1-F(n)]^n\)。这两个公式在可靠性、寿命题中反复出现。

\(F_{\max}(z)=[F(z)]^n\)独立同分布
\(F_{\min}(z)=1-[1-F(z)]^n\)独立同分布
\(f_{\max}(z)=n[F(z)]^{n-1}f(z)\)求导得密度
同型 数一

n 个独立同分布的指数 \(E(\lambda)\) 元件串联，求系统寿命（最小值）的分布。

要点 \(F_{\min}(t)=1-e^{-n\lambda t}\)，即最小值仍服从指数分布 \(E(n\lambda)\)。串联系统寿命是各元件寿命的最小值。
完整解答
  1. 串联系统寿命 \(T=\min(X_1,\dots,X_n)\)。
  2. 事件 \(T>t\) 等价于所有 \(X_i>t\)，由独立性 \(P(T>t)=\prod e^{-\lambda t}=e^{-n\lambda t}\)。
  3. 分布函数 \(F_T(t)=1-e^{-n\lambda t}\)，\(t>0\)。
  4. 即 \(T\sim E(n\lambda)\)；\(E(T)=1/(n\lambda)\)，比单个元件更短，符合串联直觉。
易错
  • max 与 min 的公式对调；
  • 非独立时直接套 \([F]^n\)；
  • 求密度时漏掉链式因子 n。
讲法
张宇max 记“都不超过”，min 记“至少一个不超过”，两句话推出公式，不必死背。

专题 01

卷积公式：分段积分限的画图法

和的分布是数一概率解答题的常客，真正难的从来不是积分，而是 z 的分段与上下限。只要把支撑集画对，题目就完成了一半。

  1. 判独立：只有独立才能用卷积，否则先求联合密度再换元。
  2. 写支撑：标出 \(f_X(x)>0\) 与 \(f_Y(y)>0\) 的区间。
  3. 固定 z：在 y 轴上把 \(y=z-x\) 画成一条斜率为 -1 的直线，找它与支撑矩形交叠的 x 范围。
  4. 分段：随着 z 移动，交叠方式改变的位置就是分段点（通常是支撑端点之和）。
  5. 逐段积分：每段写出上下限，积分后检查总积分为 1。
例

\(X\sim U(0,1),Y\sim U(0,2)\) 独立，求 \(Z=X+Y\) 的密度。

解 支撑为 \(0<x<1,0<z-x<2\)。分三段：\(0<z<1\) 时 \(x\in(0,z)\)；\(1\le z<2\) 时 \(x\in(0,1)\)；\(2\le z<3\) 时 \(x\in(z-2,1)\)。每段被积函数为 \(1/2\)，高度分别为 \(z/2,1/2,(3-z)/2\)。

踩坑点 不要凭记忆写“三角形”，支撑长度不同（1 与 2）时分段点和形状都会变；每次重新画。
[[T-topic-02]]
专题 02

max / min 分布：两句话推出全部公式

可靠性、系统寿命、次序统计量的题都归结为最大值或最小值。公式短，但方向极易记反，考场要用“事件翻译”现场推。

  1. max：\(M\le z\) 等价于“每个都 \(\le z\)”，独立时概率相乘，得 \([F(z)]^n\)。
  2. min：\(N>z\) 等价于“每个都 \(>z\)”，得 \([1-F(z)]^n\)，再取对立得 \(1-[1-F(z)]^n\)。
  3. 求密度：对分布函数求导，注意链式因子 n。
  4. 非独立：不能相乘，必须回到联合分布，或先求联合密度再积分。
  5. 混合情形：若求 \(P(\min\le a,\max\le b)\)，先拆成“全部落在 (a,b]”再处理。
例

三个独立同分布 \(U(0,1)\) 的元件并联，求系统寿命（最大值）超过 0.5 的概率。

解 \(P(M>0.5)=1-[F(0.5)]^3=1-(0.5)^3=7/8\)。并联系统只要一个工作即可，故取最大值。

踩坑点 串联取 min、并联取 max，先判断系统结构再套公式；方向反了整题归零。
