01

词汇分层与 最后六周取舍

核心必考

大纲 5500 词，但真正决定阅读速度的是高频核心词。按三层处理：核心 1500 会拼会用、认知 2500 见词知义、其余不背。冲刺期不再开新词表，只在真题句子里补漏；孤立背单词的投入产出，在 最后六周里已经很低。

核心 1500：真题词频 ≥ 5 次优先动词、抽象名词、逻辑词
认知 2500：阅读中能反应出中文即可不要求拼写，不要求辨析
同型 英语一

阅读中反复出现 subject to、account for、take hold、give way to 等短语，题干常就这些搭配设问。

要点 先判断短语在句中的褒贬与逻辑方向，再代入选项；不要按单词第一义逐字硬译。
完整解答
  1. 先把短语放回原句，标出它在句中的语法作用：是谓语、定语还是状语。
  2. 判断褒贬与逻辑方向：subject to 多表“受制于/易受”，account for 表“解释/占比”，give way to 表“让位于”。
  3. 把方向代入四个选项，先排除褒贬相反的；再比较程度与搭配。
  4. 把选中的义项放回原句通读，确认句子逻辑通顺、搭配成立。
易错
  • 追求 5500 全量，结果核心词不熟、阅读仍然卡。
  • 只背词表不做真题语境，熟词僻义一考就错。
讲法
田静词汇要放进句子里记，长难句精读时顺带解决词汇，而不是两套系统并行。

02

熟词僻义

核心高频

考研阅读最典型的失分点：address（处理/演讲）、subject（使遭受/易受）、capital（资本）、practice（做法/惯例）、school（学派）、deal（处理）。判断依据只有上下文搭配，不是词频；同一个词在不同学科文章里取义不同。

address the issue = 处理问题不是“地址”
be subject to = 易受……影响 / 服从考研高频，表被动或条件
the practice of = ……的做法不是“练习”
同型 英语一

词义题：问某段中 practice 的具体含义。四个选项分别给“练习、实践、做法、开业”。

要点 回到原句看搭配：the practice of doing 表示“做某事的做法/惯例”，选“做法”；“实践”过于空泛，是干扰项。
完整解答
  1. 定位原句：找到 practice 所在句，注意它前面的冠词与后面的 of doing 结构。
  2. 看搭配：the practice of doing sth 表示“做某事的做法/惯例”，是可数名词用法。
  3. 逐一排除：practice 作“练习”多指技能训练，作“实践”不可数且抽象，作“开业”需法律/医学语境。
  4. 把“做法/惯例”代回原句，确认与上下文（某群体长期如此行事）一致。
易错
  • 用第一义硬套，导致整句逻辑反转。
  • 忽略词性变化：同一词作名词与动词时取义不同。
讲法
唐迟熟词僻义靠真题积累，遇到一次记一次，不单独背僻义词表。

03

构词法与词义猜测

基础中频

前缀定方向、后缀定词性、词根定义场。猜词题不要求给出精确中文，只要能判断褒贬与逻辑关系，就足以排除选项。常见前缀：over-（过度）、under-（不足）、re-（再/反）、counter-（反）、pre-（前）。

over- / under- = 过度 / 不足overestimate / underestimate
-free = 无……的carefree / duty-free
-ize / -ify = 使……化判断动词词性
同型 英语一

词义猜测题：画线词由常见词根加前缀构成，要求根据上下文判断其含义。

要点 先拆前缀定方向（过度/不足/反向），再看该词在句中修饰谁、与前后分句是并列还是转折，最后选方向一致的选项。
完整解答
  1. 拆词：先看前缀（over-/under-/anti-/counter-）定方向，再看词根定核心义。
  2. 看句法：该词修饰谁、与前后分句是并列还是转折；转折处往往提示“反向”。
  3. 用上下文找同义或反义复现：附近若有解释性短语（that is / in other words），直接取其义。
  4. 把候选义代入原句，检查是否与作者态度一致；方向不一致的选项直接排除。
易错
  • 拆词过度，把不相关的词根硬套。
  • 忽略上下文的同义复现：画线词的解释往往就在下一句。
讲法
田静构词法只用来定方向和词性，精确词义必须回到上下文。

长难句五步拆解

核心必考

①找谓语动词（一句一谓语，除非并列或从句）②定主干（主谓宾/主系表）③切分从句与修饰④辨逻辑（定语/状语/同位/插入）⑤回译中文。任何长句先做第二步，不要从头逐词翻译；先有骨架，再挂修饰。

主干 = 主语 + 谓语 + 宾语/表语先抓主干，再挂修饰
修饰 = 定语（修饰名词）+ 状语（修饰动作）位置服从逻辑，不服从语序
同型 英语一

给出一句 40–50 词长句，要求划分主干与修饰并翻译，采分点在从句归属与逻辑关系。

要点 先圈出所有谓语，排除从句谓语后剩下的即主句谓语；再标出每个 that/which/who 的先行词；最后按中文逻辑重排，不要保留英文语序。
完整解答
  1. 圈出所有谓语动词，排除从句谓语后，剩下的就是主句谓语，主句主干随之确定。
  2. 标出每个 that/which/who 的先行词，判断从句到哪结束；插入语先用括号括起来。
  3. 先译主干，再把定语从句、状语从句按中文逻辑安放：短的前置，长的后置或独立成句。
  4. 补出逻辑词（因为/尽管/从而），最后通读，检查主干完整、从句归属正确、没有漏译。
易错
  • 见词就译，译到一半发现主语还没找到。
  • 把插入语当主干，导致主谓关系断裂。
  • 定语从句先行词找错，修饰对象整体偏移。
讲法
田静固定顺序：找谓语—找主干—挂修饰—回译，练到成为条件反射。

05

三大从句

核心必考

定语从句修饰名词，状语从句修饰动作，名词性从句充当主语/宾语/表语/同位语。阅读里从句决定修饰范围，翻译里从句决定语序；判断从句类型的关键是看它修饰谁、在句中充当什么成分。

which / that 前必有先行词找不到先行词就不是定语从句
逗号后一般用 which，不用 that非限制性定语从句
that 可引导同位语从句解释抽象名词的内容
同型 英语一

长句中出现两个 that：一个引导定语从句，一个引导同位语从句，要求判断各自修饰对象。

要点 从句缺成分→定语从句（that 作主/宾）；从句成分完整→同位语从句（that 只起连接作用），其前多为 fact/idea/belief/evidence 等抽象名词。
完整解答
  1. 看第一个 that 后的从句：若缺主语或宾语，that 作成分，是定语从句。
  2. 看第二个 that 后的从句：若主谓宾齐全，that 不作成分，是同位语从句，先行词多为 fact/idea/news/belief。
  3. 把两个 that 分别替换成“which/that”与“the fact that”试读，哪个通顺即可确认。
  4. 翻译时定语从句前置或后置，同位语从句译成“……这一事实/观点”，不要混成定语。
易错
  • 把所有 that 都当定语从句。
  • where 既能引导定语从句也能引导地点状语从句，未看先行词就判断。
讲法
田静从句判断只看两件事：缺不缺成分、修饰谁。

非谓语动词

核心高频

不定式表目的/将来，动名词作名词，现在分词表主动/进行，过去分词表被动/完成。非谓语本质是压缩的从句；翻译时把它还原成从句或并列句，句子立刻顺。判断主动被动看逻辑主语，不看位置。

doing = 主动 / 进行逻辑主语发出动作
done = 被动 / 完成逻辑主语承受动作
to do 常表目的或将来in order to / be to do
同型 英语一

句中含两个分词短语，要求判断其逻辑主语，并说明修饰的是主句主语还是宾语。

要点 分词的逻辑主语通常是最靠近的名词或主句主语；若语义不通，则向前找真正的施动者。翻译时补出“因为/当……时/这使得”等逻辑词。
完整解答
  1. 找分词短语，先判断它是现在分词（主动/进行）还是过去分词（被动/完成）。
  2. 找逻辑主语：通常是主句主语；若语义不通，向前找最近的名词，确认谁是动作的发出者。
  3. 判断修饰对象：修饰主语时译成“因为/当……时”，修饰宾语时译成“这使得/从而”。
  4. 把补出的逻辑关系放回译文，检查动作发出者与主句主语是否一致。
易错
  • 悬垂分词：分词逻辑主语与主句主语不一致，理解全错。
  • doing 与 done 混用，主动被动反转。
讲法
田静非谓语先问“谁做的”，再问“做完没有”，最后才看形式。

07

倒装、虚拟、插入语与省略

进阶中频

四类特殊结构会打断主谓：倒装（否定词/only 提前）、虚拟（if 省略后倒装）、插入语（双逗号/双破折号，先删掉读主干）、省略（并列与比较结构）。阅读时先把插入语括起来，句子立刻变短。

Not until ... did + 主语 + 动词部分倒装
Were / Had / Should + 主语 ...省略 if 的虚拟条件句
than / as 后的省略补全比较对象再判断
同型 英语一

句中含否定词提前的倒装，问作者强调的是什么；或比较结构省略，问比较对象。

要点 倒装还原成正常语序再读；比较句把省略的成分补全，确认是同类对象相比，避免把“部分”与“整体”混比。
完整解答
  1. 遇到否定词提前：先把句子还原成正常语序，再找被强调的成分。
  2. 遇到比较结构：把省略的成分补全，确认比较对象是同类（人和人、措施和措施）。
  3. 检查是否把“部分”与“整体”混比，或把“至少/最多”译成“等于”。
  4. 把还原后的句子与选项逐一对照，选与强调点一致的项。
易错
  • 插入语切断主谓后，把插入内容当谓语。
  • 比较结构省略没补全，比较对象判断错。
讲法
田静插入语先删、倒装先还原、省略先补全，三步处理特殊结构。

真题句精读法

进阶高频

每天 3 句：限时拆解→对照译文→标出“当时没看懂的连接点”（先行词、指代、逻辑词）→第二天回译。精读目标不是译文漂亮，而是把阅读卡顿点清零；同一类连接点错三次，就必须回到语法专题。

3 句/天 × 30 天 = 90 句足以覆盖绝大多数句型
回译：中文→英文→对照原句检验是否真懂，而不是眼熟
同型 英语一

从阅读真题中取一句含两个从句的长句，要求在不查词典的情况下口头翻译，并指出主干。

要点 评分自检：主干是否完整、从句归属是否正确、逻辑词是否译出、中文是否通顺；四项缺一即为未掌握。
完整解答
  1. 先找主干：圈谓语、去从句、去插入语，用一句话说出“谁做了什么”。
  2. 再切从句：标出每个连接词与先行词，确定从句修饰谁、到哪里结束。
  3. 口头翻译：先直译意群，再按中文习惯调整语序，补出逻辑词。
  4. 四项自检：主干完整、从句归属正确、逻辑词译出、中文通顺；缺一项就重译该部分。
易错
  • 只读译文不动笔，误以为看懂。
  • 精读只做新句，不回看错过的连接点。
讲法
唐迟阅读的进步来自“同一类错误不再犯”，精读要留下错因记录。
[[T-topic-01]]
专题 01

长难句五步拆解：以真题句为例

阅读与翻译共用同一套拆句能力。最后六周里不可能重学语法，但可以把五步练成固定动作，让每个长句都有下手处。

  1. 圈谓语：把句中所有动词圈出，区分谓语与非谓语。
  2. 定主干：排除从句谓语，剩下的主谓宾即主干。
  3. 切从句：在每个连接词处断开，标出先行词或逻辑关系。
  4. 辨修饰：定语修饰名词、状语修饰动作，插入语先括起来。
  5. 回译：按中文逻辑重排，补出省略的逻辑词，再对照参考译文。
例

拆解并翻译：The idea that companies should be held accountable for the social costs they impose has gained ground among policymakers who once treated such concerns as peripheral.

解 谓语：should be held、impose、has gained、treated。主干：The idea has gained ground。that 从句是同位语，解释 idea；they impose 是定语从句修饰 costs；who once treated... 是定语从句修饰 policymakers。译：企业应为其施加的社会成本负责这一观念，在曾经视此类关切为边缘问题的决策者中逐渐获得认同。

踩坑点 看到 that 就译成“那个”；先判断从句缺不缺成分，再决定是定语还是同位语。
[[T-topic-02]]
专题 02

最后六周词汇与长难句并行表

冲刺期最怕两件事：词表从头再来、长难句只听课不练。把两者绑在每天固定的 30 分钟里，才能持续到考前。

  1. 每天 15 分钟：高频词 80 个快速过，只记真题例句中的搭配。
  2. 每天 15 分钟：真题长句 3 句，按五步拆解并回译。
  3. 每周日：把本周标红的连接点集中重做一次，仍错的写进错因本。
  4. 每两周：用一套真题阅读限时检验，只看“因句子没读懂而错”的题是否减少。
  5. 考前 7 天：停止新词，只回看错因本与高频搭配。
例

只有 30 分钟，词汇和长难句怎么分配？

解 前 15 分钟过词，后 15 分钟拆句；拆句时遇到生词当场查、当场记，避免词汇与语境脱节。

踩坑点 不要把 30 分钟全用来抄单词；抄写是低效劳动，回译才是检验。
