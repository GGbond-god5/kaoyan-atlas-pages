新时代的历史方位与社会主要矛盾

核心必考

中国特色社会主义进入新时代，是我国发展新的历史方位。社会主要矛盾已转化为人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。我国仍处于并将长期处于社会主义初级阶段的基本国情没有变，我国是世界最大发展中国家的国际地位没有变。

主要矛盾：美好生活需要 ↔ 不平衡不充分的发展两边都不能写错
「两个没有变」：初级阶段国情 + 最大发展中国家地位与主要矛盾转化并列考
新时代「三个意味着」：强起来 · 科学社会主义 · 现代化途径分析题常用
同型 新思想选择题

新时代我国社会主要矛盾转化后，是否意味着我国已不再处于社会主义初级阶段？

要点 不是。主要矛盾转化没有改变我国仍处于并将长期处于社会主义初级阶段的基本国情，也没有改变我国是世界最大发展中国家的国际地位。
完整解答
  1. 主要矛盾转化没有改变我国仍处于并将长期处于社会主义初级阶段的基本国情。
  2. 也没有改变我国是世界最大发展中国家的国际地位。
  3. 主要矛盾变化是阶段性的，基本国情是长期的。
  4. 结论：不意味着不再处于初级阶段。
易错
  • 把主要矛盾写成「人民日益增长的物质文化需要同落后的社会生产之间的矛盾」——这是旧表述。
  • 认为主要矛盾转化等于初级阶段结束。
  • 只写「不平衡不充分」而漏掉「美好生活需要」。
讲法
腿姐keywords：主要矛盾「需要—发展」两端成对背；「两个没有变」单独成组。徐涛把新时代放在「站起来—富起来—强起来」的历史链条里讲，避免孤立记忆。

世界观和方法论：「六个必须坚持」

核心必考

习近平新时代中国特色社会主义思想的世界观和方法论集中体现为「六个必须坚持」：必须坚持人民至上、自信自立、守正创新、问题导向、系统观念、胸怀天下。这是继续推进理论创新的科学方法。

六个必须坚持：人民至上 · 自信自立 · 守正创新 · 问题导向 · 系统观念 · 胸怀天下顺序与数量都可能考
人民至上 = 根本立场；系统观念 = 基本方法分析题常单拎一条
同型 新思想选择题

习近平新时代中国特色社会主义思想的世界观和方法论集中体现为（ ）。

要点 「六个必须坚持」：人民至上、自信自立、守正创新、问题导向、系统观念、胸怀天下。
完整解答
  1. “六个必须坚持”：人民至上、自信自立、守正创新、问题导向、系统观念、胸怀天下。
  2. 这是习近平新时代中国特色社会主义思想世界观和方法论的集中体现。
  3. 排除“十个明确”“十四个坚持”等其它概括。
  4. 结论：六个必须坚持。
易错
  • 把「六个必须坚持」与「十四个坚持」混淆。
  • 漏写「胸怀天下」或把「自信自立」写成「自力更生」。
  • 把「六个必须坚持」当作具体政策而非世界观方法论。
讲法
腿姐keywords：六个词编成「人自守问系胸」，先记首字再还原。

中国式现代化

核心必考

中国式现代化是中国共产党领导的社会主义现代化，既有各国现代化的共同特征，更有基于自己国情的中国特色：人口规模巨大、全体人民共同富裕、物质文明和精神文明相协调、人与自然和谐共生、走和平发展道路。其本质要求涵盖党的领导、中国特色社会主义、高质量发展、全过程人民民主、人民精神世界、共同富裕、人与自然和谐共生、人类命运共同体、人类文明新形态。

五个中国特色：人口规模巨大 · 共同富裕 · 两个文明协调 · 人与自然和谐 · 和平发展五条按顺序背
本质要求九句：党的领导 + 中特 + 高质量发展 + 全过程人民民主 + 精神世界 + 共同富裕 + 和谐共生 + 命运共同体 + 文明新形态分析题可挑 3–4 条
重大原则：党的领导 · 中特道路 · 人民为中心 · 改革开放 · 斗争精神五条原则
同型 新思想分析题

为什么说中国式现代化是「既有各国现代化的共同特征，更有基于自己国情的中国特色」？

要点 现代化有一般规律（工业化、城镇化、市场化等共性），但各国国情不同，道路不能照搬。中国式现代化立足人口规模巨大、共同富裕等国情，形成五个中国特色，是共性与个性的统一。
完整解答
  1. 现代化有共同特征：工业化、城镇化、市场化等。
  2. 各国国情不同，道路不能照搬。
  3. 中国立足人口规模巨大、共同富裕等国情，形成五个中国特色。
  4. 结论：中国式现代化是共性与个性的统一。
易错
  • 把「五个中国特色」与「本质要求」混为一谈。
  • 漏掉「中国共产党领导的社会主义现代化」这一根本定性。
  • 把中国式现代化说成「西方现代化的翻版」或「另起炉灶」。
讲法
腿姐keywords：中国特色五条用「人、富、文、绿、和」五字串；本质要求记「党、路、质、民、文、富、绿、球、文明」。徐涛用「共性—个性」框架讲，直接对接马原矛盾普遍性与特殊性，分析题可跨章得分。

坚持和加强党的全面领导

核心必考

中国共产党领导是中国特色社会主义最本质的特征，是中国特色社会主义制度的最大优势。「两个确立」是确立习近平同志党中央的核心、全党的核心地位，确立习近平新时代中国特色社会主义思想的指导地位；「两个维护」是坚决维护习近平总书记党中央的核心、全党的核心地位，坚决维护党中央权威和集中统一领导。

最本质特征 + 最大优势 = 中国共产党领导两句话常配对考
两个确立：核心地位 + 指导思想地位一个是人，一个是思想
两个维护：总书记核心地位 + 党中央权威和集中统一领导与两个确立区分
同型 新思想选择题

「两个确立」与「两个维护」分别指什么？

要点 「两个确立」：确立习近平同志党中央的核心、全党的核心地位，确立习近平新时代中国特色社会主义思想的指导地位。「两个维护」：坚决维护习近平总书记党中央的核心、全党的核心地位，坚决维护党中央权威和集中统一领导。
完整解答
  1. “两个确立”：确立习近平同志党中央的核心、全党的核心地位；确立习近平新时代中国特色社会主义思想的指导地位。
  2. “两个维护”：坚决维护习近平总书记党中央的核心、全党的核心地位；坚决维护党中央权威和集中统一领导。
  3. 注意“确立”讲地位，“维护”讲行动。
  4. 结论：二者相互贯通。
易错
  • 把「两个确立」与「两个维护」的内容互换。
  • 漏掉「最本质的特征」或「最大优势」中的一句。
  • 把党的领导理解为「包办一切」。
讲法
腿姐keywords：「确立」是理论层面的定位，「维护」是行动层面的要求，用「一静一动」区分。

以人民为中心与共同富裕

核心高频

江山就是人民，人民就是江山。坚持以人民为中心的发展思想，把实现人民对美好生活的向往作为现代化建设的出发点和落脚点。共同富裕是社会主义的本质要求，是中国式现代化的重要特征，要构建初次分配、再分配、第三次分配协调配套的基础性制度安排。

发展思想：以人民为中心出发点和落脚点 = 人民对美好生活的向往
共同富裕：本质要求 + 重要特征不是平均主义，也不是同步富裕
三次分配：初次（市场）· 再分配（政府）· 第三次（慈善）顺序不能乱
同型 新思想分析题

如何理解「共同富裕是社会主义的本质要求」？

要点 社会主义本质包含最终达到共同富裕；共同富裕体现以人民为中心，是区别于资本主义现代化的显著特征。实现共同富裕要循序渐进，在高质量发展中促进，不是劫富济贫或平均主义。
完整解答
  1. 社会主义本质包含最终达到共同富裕。
  2. 共同富裕体现以人民为中心，是区别于资本主义现代化的显著特征。
  3. 实现路径是高质量发展、循序渐进，不是平均主义，也不是劫富济贫。
  4. 结论：共同富裕是社会主义的本质要求。
易错
  • 把共同富裕理解为同步富裕、同等富裕。
  • 把第三次分配当作主渠道。
  • 只讲经济分配，忽略精神生活共同富裕。
讲法
徐涛用「做大蛋糕—分好蛋糕—共享成果」三步讲共同富裕，避免空喊口号。

全面深化改革

核心高频

全面深化改革的总目标是完善和发展中国特色社会主义制度、推进国家治理体系和治理能力现代化。改革是一场深刻革命，要坚持党的全面领导、以人民为中心、守正创新、以制度建设为主线、全面依法治国、系统观念。

总目标：制度 + 治理体系/治理能力现代化两句话缺一不可
改革定位：深刻革命 / 关键一招不是修修补补
「六个坚持」：党的领导 · 人民中心 · 守正创新 · 制度主线 · 依法治国 · 系统观念与「六个必须坚持」区分
同型 新思想选择题

全面深化改革的总目标是（ ）。

要点 完善和发展中国特色社会主义制度，推进国家治理体系和治理能力现代化。
完整解答
  1. 总目标是完善和发展中国特色社会主义制度。
  2. 同时推进国家治理体系和治理能力现代化。
  3. 两句话缺一不可，前者定方向，后者定能力。
  4. 结论：完善和发展中国特色社会主义制度，推进国家治理体系和治理能力现代化。
易错
  • 把「六个坚持」与「六个必须坚持」混淆。
  • 把总目标只写成「推进治理现代化」，漏掉制度一句。
  • 把改革理解为纯经济改革。
讲法
腿姐keywords：总目标两句话必须成对；「制度建设为主线」是改革题的高频得分点。

新发展理念与高质量发展

核心必考

新发展理念是创新、协调、绿色、开放、共享。高质量发展是全面建设社会主义现代化国家的首要任务。构建以国内大循环为主体、国内国际双循环相互促进的新发展格局。教育、科技、人才是基础性、战略性支撑。

新发展理念：创新 · 协调 · 绿色 · 开放 · 共享五指顺序可考
新发展格局：国内大循环为主体 + 双循环相互促进不是封闭内循环
首要任务：高质量发展与「第一要务=发展」区分
同型 新思想分析题

为什么说高质量发展是全面建设社会主义现代化国家的首要任务？

要点 我国已转向高质量发展阶段，主要矛盾转化为美好生活需要与不平衡不充分的发展之间的矛盾；只有高质量发展才能提供物质技术基础、满足人民需要、增强国际竞争力。
完整解答
  1. 我国已转向高质量发展阶段。
  2. 主要矛盾转化为美好生活需要与不平衡不充分的发展之间的矛盾。
  3. 高质量发展提供物质技术基础、满足人民需要、增强国际竞争力。
  4. 结论：高质量发展是全面建设社会主义现代化国家的首要任务。
易错
  • 把新发展格局理解为「关起门来搞内循环」。
  • 把「首要任务」写成「第一要务」。
  • 漏掉「共享」或把「绿色」写成「环保」。
讲法
腿姐keywords：理念五词成串；格局记「一体两翼」，高质量发展是「首要任务」。

全面依法治国

基础高频

全面依法治国的总目标是建设中国特色社会主义法治体系、建设社会主义法治国家。坚持党的领导、人民当家作主、依法治国有机统一。坚持依法治国、依法执政、依法行政共同推进，法治国家、法治政府、法治社会一体建设。

总目标：法治体系 + 法治国家两句并列
三者统一：党的领导 · 人民当家作主 · 依法治国顺序固定
三个共同推进 / 三个一体建设选择常拆开考
同型 新思想选择题

全面依法治国的总目标是（ ）。

要点 建设中国特色社会主义法治体系、建设社会主义法治国家。
完整解答
  1. 总目标是建设中国特色社会主义法治体系。
  2. 同时建设社会主义法治国家。
  3. 注意区分总目标与“法治体系”下的子目标。
  4. 结论：建设中国特色社会主义法治体系、建设社会主义法治国家。
易错
  • 把「法治体系」写成「法律体系」。
  • 把三者统一写成「党的领导、依法治国、以德治国」。
  • 混淆「法治国家、法治政府、法治社会」与「依法治国、依法执政、依法行政」。
讲法
徐涛画「三者统一—三个共同推进—三个一体建设」三层图，层次分明不易混。

文化自信与「两个结合」

核心高频

文化自信是更基础、更广泛、更深厚的自信。「两个结合」是把马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合；「第二个结合」是又一次思想解放。要推动中华优秀传统文化创造性转化、创新性发展，建设中华民族现代文明。

两个结合：中国具体实际 + 中华优秀传统文化第二个结合是重点
文化自信：更基础 · 更广泛 · 更深厚三个「更」
两创：创造性转化 + 创新性发展不是简单复古
同型 新思想分析题

为什么说「第二个结合」是又一次思想解放？

要点 它把马克思主义思想精髓同中华优秀传统文化精华贯通起来，让马克思主义在中国牢牢扎根，也让传统文化在马克思主义指导下实现现代转化，开辟了理论和实践的新空间。
完整解答
  1. “第二个结合”把马克思主义思想精髓同中华优秀传统文化精华贯通起来。
  2. 让马克思主义在中国牢牢扎根，也让传统文化在马克思主义指导下实现现代转化。
  3. 它开辟了理论和实践的新空间，所以是又一次思想解放。
  4. 结论：第二个结合是又一次思想解放。
易错
  • 把「两个结合」写成「一个结合」。
  • 把传统文化复兴理解为照搬复古。
  • 忽略「第二个结合」的思想解放意义。
讲法
腿姐keywords：「两个结合」后一个才是分析题高频；「两创」要写出「转化」与「发展」两个动作。

生态文明建设

核心高频

绿水青山就是金山银山。坚持人与自然和谐共生，尊重自然、顺应自然、保护自然。统筹山水林田湖草沙一体化保护和系统治理，积极稳妥推进碳达峰碳中和（2030 年前碳达峰、2060 年前碳中和）。

两山理念：绿水青山就是金山银山不是「先污染后治理」
双碳：2030 碳达峰 · 2060 碳中和年份与顺序不能错
系统治理：山水林田湖草沙一体化「沙」不能漏
同型 新思想分析题

如何理解「绿水青山就是金山银山」？

要点 生态优势可以转化为发展优势，保护生态环境就是保护生产力、改善生态环境就是发展生产力；要处理好发展与保护的关系，走生态优先、绿色发展之路。
完整解答
  1. 生态优势可以转化为发展优势。
  2. 保护生态环境就是保护生产力，改善生态环境就是发展生产力。
  3. 要处理好发展与保护的关系，走生态优先、绿色发展之路。
  4. 结论：绿水青山就是金山银山。
易错
  • 把「碳达峰」与「碳中和」的年份写反。
  • 认为生态文明建设只是环保部门的事。
  • 把「两山」理念理解为不要发展。
讲法
腿姐keywords：双碳「30 达峰、60 中和」，先峰后和；两山理念答「保护也是发展」。

总体国家安全观与人类命运共同体

基础高频

总体国家安全观以人民安全为宗旨、政治安全为根本、经济安全为基础、军事科技文化社会安全为保障、促进国际安全为依托。对外推动构建人类命运共同体，弘扬和平、发展、公平、正义、民主、自由的全人类共同价值。

宗旨：人民安全；根本：政治安全；基础：经济安全三个定位常考
共同体：持久和平 · 普遍安全 · 共同繁荣 · 开放包容 · 清洁美丽五个世界
全人类共同价值：和平 · 发展 · 公平 · 正义 · 民主 · 自由六个词
同型 新思想选择题

总体国家安全观以什么为宗旨、以什么为根本？

要点 以人民安全为宗旨，以政治安全为根本，以经济安全为基础。
完整解答
  1. 总体国家安全观以人民安全为宗旨。
  2. 以政治安全为根本。
  3. 以经济安全为基础。
  4. 结论：宗旨、根本、基础三句话要按顺序记。
易错
  • 把「宗旨」「根本」「基础」三者对调。
  • 把人类命运共同体与「全人类共同价值」混为同一概念。
  • 认为国家安全只是军事安全。
讲法
徐涛用「宗旨—根本—基础—保障—依托」五层结构记总体国家安全观。

新质生产力

核心必考

新质生产力是创新起主导作用，摆脱传统经济增长方式、生产力发展路径，具有高科技、高效能、高质量特征，符合新发展理念的先进生产力质态。它以科技创新为核心，以劳动者、劳动资料、劳动对象及其优化组合的跃升为基本内涵，以全要素生产率大幅提升为核心标志。发展新质生产力要因地制宜，不能忽视、放弃传统产业。

科技创新 → 产业创新 → 全要素生产率提升答题主线
高科技 · 高效能 · 高质量三个特征
因地制宜，先立后破方法论限定
同型 新思想分析题

结合某地以关键技术突破带动产业升级的材料，说明发展新质生产力对中国式现代化的意义。

要点 新质生产力以科技创新为核心，推动产业升级与全要素生产率提升，为中国式现代化提供物质技术基础。
完整解答
  1. 点：新质生产力以科技创新为核心，具有高科技、高效能、高质量特征，以全要素生产率大幅提升为核心标志。
  2. 析：材料中的关键技术突破、产业升级、人才引育，正对应“劳动者—劳动资料—劳动对象”的优化组合。
  3. 结：这推动高质量发展、提升国际竞争力，为中国式现代化提供物质技术基础，并促进共同富裕。
  4. 限定：发展新质生产力要因地制宜，不能一哄而上，也不能忽视传统产业。
易错
  • 把新质生产力等同于一般科技创新，忽略生产要素组合与产业载体。
  • 只讲技术、不讲人才与生产关系，答题不完整。
讲法
腿姐keywords：创新主导、三高、全要素生产率；分析题按“是什么—为什么—怎么做”展开。

「十五五」规划与中国式现代化

核心高频

2025 年 10 月党的二十届四中全会通过《中共中央关于制定国民经济和社会发展第十五个五年规划的建议》；2026 年 3 月十四届全国人大四次会议审查批准「十五五」规划纲要。「十五五」时期是基本实现社会主义现代化夯实基础、全面发力的关键时期，主线是高质量发展、新质生产力、共同富裕和中国式现代化。

二十届四中全会（2025-10）→ 十五五建议党的建议
2026-03 全国人大 → 十五五规划纲要国家意志
高质量发展 · 新质生产力 · 共同富裕主线关键词

说明「十五五」规划与中国式现代化的关系。

要点 规划把中国式现代化的五个特征转化为阶段性任务，为 2035 年基本实现现代化打基础。
完整解答
  1. 点：2025 年 10 月二十届四中全会通过「十五五」规划建议，2026 年 3 月全国人大批准纲要。
  2. 析：「十五五」时期是基本实现社会主义现代化夯实基础的关键时期，主线是高质量发展、新质生产力、共同富裕。
  3. 结：规划把中国式现代化的五个特征转化为阶段性任务，为 2035 年基本实现现代化打基础。
  4. 注意：不要编造具体指标，答题用“建议—纲要—任务”的逻辑。

  • 把二十届四中全会与 2026 年两会混淆。
  • 背未公布的指标数字，反而失分。

专题 01

新思想关键词速记：三组成对记

新思想的考点密、表述长，逐句背不现实。把易混的成对概念放在一起对比，能用最少的记忆量覆盖最多的选择题。

  1. 第一组「两个确立 / 两个维护」：一个讲定位，一个讲行动。
  2. 第二组「六个必须坚持 / 六个坚持」：前者是世界观方法论，后者是全面深化改革的原则。
  3. 第三组「五个中国特色 / 九个本质要求 / 五个重大原则」：中国式现代化三套表述，按「特色—要求—原则」分层。
  4. 每组只记首字串，再在纸上还原全称；还原不出立刻回看。
  5. 把本年度时政材料往这三组上靠，分析题就不会跑题。
例

「六个必须坚持」与全面深化改革的「六个坚持」有什么区别？

解 前者是习近平新时代中国特色社会主义思想的世界观和方法论（人民至上、自信自立、守正创新、问题导向、系统观念、胸怀天下）；后者是全面深化改革必须贯彻的原则（党的领导、人民中心、守正创新、制度主线、依法治国、系统观念）。

踩坑点 两组都有「守正创新」「系统观念」，最容易混。判别方法是看题干主语：讲理论创新→六个必须坚持；讲改革→六个坚持。
[[T-topic-02]]
专题 02

中国式现代化分析题：四层作答

中国式现代化是近几年分析题的最高频主题，几乎可以套所有时政材料。准备一个四层框架，比临场组织语言稳得多。

  1. 第一层定性：中国式现代化是中国共产党领导的社会主义现代化。
  2. 第二层讲中国特色：人口规模巨大、共同富裕、两个文明协调、人与自然和谐、和平发展，按材料挑 2–3 条。
  3. 第三层讲本质要求或重大原则：党的领导、高质量发展、全过程人民民主、共同富裕等，挑与材料相关的。
  4. 第四层结合材料收口：材料中的做法体现了哪一条，最后回到「以中国式现代化全面推进中华民族伟大复兴」。
  5. 全程控制 12–15 分钟，原理与材料比例约 4:6。
例

材料：某地推进共同富裕示范区建设，同时发展数字经济、保护生态。设问：运用中国式现代化理论分析该地做法。

解 定性：这是党领导的中国式现代化在地方的具体实践。特色：体现全体人民共同富裕、人与自然和谐共生。要求：在高质量发展中促进共同富裕，发展成果由人民共享。收口：为全面推进中华民族伟大复兴提供了地方样本。

踩坑点 不要把所有中国特色五条全写上。材料只涉及两三条时，全写会显得堆砌，反而挤掉结合材料的篇幅。
