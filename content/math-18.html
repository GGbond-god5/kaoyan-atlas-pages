切比雪夫不等式

基础高频

在只知道期望和方差时，切比雪夫不等式给出偏离均值的概率上界：\(P(|X-EX|\ge\varepsilon)\le D(X)/\varepsilon^2\)。它给出的是保守估计，不是精确值；题目问“至少”“不超过”时优先想它。

\(P(|X-E X|\ge\varepsilon)\le\dfrac{D(X)}{\varepsilon^2}\)偏离上界
\(P(|X-E X|<\varepsilon)\ge1-\dfrac{D(X)}{\varepsilon^2}\)落在邻域内的下界
同型 数一

已知 \(E(X)=\mu,D(X)=\sigma^2\)，估计 \(P(|X-\mu|<3\sigma)\) 的下界。

要点 \(1-\frac{\sigma^2}{9\sigma^2}=\frac89\)。这是下界，真实概率可能更高；若题目给正态分布则应改用 \(\Phi\) 精确计算。
完整解答
  1. 切比雪夫不等式：\(P(|X-EX|\ge\varepsilon)\le D(X)/\varepsilon^2\)。
  2. 取 \(\varepsilon=3\sigma\)，得 \(P(|X-\mu|\ge3\sigma)\le\frac{\sigma^2}{9\sigma^2}=\frac19\)。
  3. 取对立事件：\(P(|X-\mu|<3\sigma)\ge1-\frac19=\frac89\)。
  4. 这是下界；若已知正态，精确值为 \(0.9973\)，说明不等式保守。
易错
  • 把不等式方向写反；
  • 把它当成精确概率；
  • 忘记 \(\varepsilon\) 与方差同量纲。
讲法
武忠祥切比雪夫只用于信息不足的估计题；一旦给了分布，改用精确方法。

02

依概率收敛

基础低频

\(X_n\xrightarrow{P}X\) 指对任意 \(\varepsilon>0\)，\(P(|X_n-X|\ge\varepsilon)\to0\)。它比几乎处处收敛弱，但在大数定律里足够用。考试只需会判断“样本均值依概率收敛到总体均值”。

\(X_n\xrightarrow{P}X\iff\forall\varepsilon>0,\ P(|X_n-X|\ge\varepsilon)\to0\)定义
\(\bar X_n\xrightarrow{P}\mu\)辛钦大数定律的结论
同型 数一

判断 \(\bar X_n\) 是否依概率收敛于 \(\mu\)，需要什么条件？

要点 独立同分布且 \(E(X_i)=\mu\) 存在即可，不要求方差存在。
完整解答
  1. 辛钦大数定律：若 \(X_i\) 独立同分布且 \(E(X_i)=\mu\) 存在，则 \(\bar X_n\xrightarrow{P}\mu\)。
  2. 定理只要求一阶矩存在，不要求方差存在。
  3. 若方差存在，也可用切比雪夫不等式给出证明。
  4. 检验：若期望不存在（如柯西分布），结论不成立。
易错
  • 把依概率收敛与分布收敛混为一谈；
  • 误以为必须方差有限。
讲法
张宇记样本均值稳定到总体均值，条件只有 iid 与均值存在。

03

三个大数定律

核心中频

切比雪夫大数定律要求独立、方差一致有界；伯努利大数定律是频率稳定于概率的特例；辛钦大数定律只要求独立同分布、均值存在，条件最弱。考试常考“哪个定律适用”的辨析。

\(\dfrac1n\sum_{i=1}^n X_i\xrightarrow{P}E(X)\)辛钦，iid，均值存在
\(\dfrac{n_A}{n}\xrightarrow{P}p\)伯努利，频率稳定于概率
同型 数一

掷硬币 n 次，用大数定律说明正面频率为何稳定于 1/2。

要点 设 \(X_i\) 为第 i 次是否正面，iid 且 \(E(X_i)=1/2\)，由辛钦大数定律频率趋近 1/2。
完整解答
  1. 设 \(X_i=1\) 表示第 \(i\) 次正面，\(0\) 表示反面；\(X_i\) 独立同分布，\(E(X_i)=1/2\)。
  2. 正面频率 \(\bar X_n=\frac1n\sum X_i\)。
  3. 由辛钦大数定律，\(\bar X_n\xrightarrow{P}1/2\)。
  4. 这解释了频率的稳定性；误差大小需再用中心极限定理。
易错
  • 辛钦定律误加方差存在；
  • 切比雪夫定律的条件记成同分布。
讲法
武忠祥三条定律按条件强弱记：切比雪夫、伯努利、辛钦。

列维-林德伯格中心极限定理

核心必考

独立同分布、均值与方差存在时，无论原分布是什么，样本均值经标准化后近似标准正态。这是“正态无处不在”的来源，也是用正态近似计算和的概率的依据。

\(\dfrac{\sum X_i-n\mu}{\sqrt{n}\sigma}\xrightarrow{d}N(0,1)\)和的标准化
\(\dfrac{\bar X-\mu}{\sigma/\sqrt n}\xrightarrow{d}N(0,1)\)均值的标准化
\(\sum X_i\ \dot\sim\ N(n\mu,n\sigma^2)\)近似写法
同型 数一

某设备由 100 个独立部件组成，每个部件寿命均值 10、方差 4，求总寿命超过 1040 的概率近似值。

要点 总和近似 \(N(1000,400)\)，\(z=\frac{1040-1000}{20}=2\)，概率 \(1-\Phi(2)\approx0.0228\)。
完整解答
  1. 设第 \(i\) 个部件寿命为 \(X_i\)，独立同分布，\(\mu=10,\sigma^2=4,n=100\)。
  2. 总和 \(S=\sum X_i\)，\(E(S)=1000\)，\(D(S)=400\)，\(\sigma_S=20\)。
  3. 由中心极限定理，\(S\) 近似服从 \(N(1000,400)\)。
  4. \(P(S>1040)=P\!\left(Z>\frac{1040-1000}{20}=2\right)=1-\Phi(2)\approx0.0228\)。
易错
  • 方差写成 \(n\sigma\) 而不是 \(n\sigma^2\)；
  • 标准化分母漏 \(\sqrt n\)；
  • 离散情形忘记连续性修正。
讲法
张宇CLT 三步：求和、标准化、查表；先写 \(n\mu,n\sigma^2\) 再动笔。

棣莫弗-拉普拉斯定理

核心高频

二项分布 \(B(n,p)\) 在 n 大时近似正态 \(N(np,np(1-p))\)。这是 CLT 的离散特例。离散转连续时，边界要加连续性修正 \(\pm0.5\)。

\(X\sim B(n,p)\Rightarrow X\ \dot\sim\ N(np,np(1-p))\)n 大、p 不接近 0 或 1
\(P(a\le X\le b)\approx\Phi(\frac{b+0.5-np}{\sqrt{np(1-p)}})-\Phi(\frac{a-0.5-np}{\sqrt{np(1-p)}}\)\)连续性修正
同型 数一

掷均匀硬币 400 次，求正面次数在 190 到 210 之间的概率近似值。

要点 \(np=200,np(1-p)=100\)；修正后 \(z=\pm\frac{10.5}{10}=\pm1.05\)，概率约 \(2\Phi(1.05)-1\approx0.706\)。
完整解答
  1. \(X\sim B(400,0.5)\)，\(np=200\)，\(np(1-p)=100\)，\(\sigma=10\)。
  2. 用正态近似并做连续性修正：\(P(190\le X\le210)\approx P(189.5<X<210.5)\)。
  3. 标准化：\(z_1=\frac{189.5-200}{10}=-1.05\)，\(z_2=\frac{210.5-200}{10}=1.05\)。
  4. 概率 \(\approx2\Phi(1.05)-1\approx0.706\)；区间关于均值对称，接近 0.7 合理。
易错
  • 忘记连续性修正；
  • 方差用 \(np\) 而不是 \(np(1-p)\)；
  • p 接近 0 或 1 时仍用正态近似。
讲法
没咋了二项近似正态，先算 np 与 np(1-p)，再决定是否修正。

用中心极限定理确定样本量

进阶中频

样本量确定是 CLT 的逆用：给定置信水平与允许误差，把标准化不等式反解出 n。σ 未知时用样本标准差或预调查估计；比例情形取 p=0.5 最保守，因为此时 p(1-p) 最大。

\(n\ge\left(\dfrac{z_{\alpha/2}\sigma}{\delta}\right)^2\)均值估计，δ 为允许误差
\(n\ge\dfrac{z_{\alpha/2}^2p(1-p)}{\delta^2}\)比例估计，p=0.5 最保守
同型 数一

某调查要求 95% 置信水平下误差不超过 0.05，比例 p 未知，求最少样本量（\(z_{0.025}=1.96\)）。

要点 取 p=0.5：\(n\ge1.96^2\times0.25/0.0025=384.16\)，向上取整为 385。
完整解答
  1. 比例估计的误差限 \(e=z_{\alpha/2}\sqrt{\frac{p(1-p)}{n}}\)。
  2. 解出 \(n\ge\frac{z^2p(1-p)}{e^2}\)。
  3. \(p\) 未知取最保守的 \(p=0.5\)，\(z=1.96,e=0.05\)：\(n\ge\frac{1.96^2\times0.25}{0.0025}=384.16\)。
  4. 样本量向上取整，最少 \(n=385\)；检验 \(n\) 必须是不小于计算值的整数。
易错
  • 算出小数不向上取整；
  • p 未知时随意取 0.1，1 导致样本量偏小；
  • 把 σ 与 σ² 混用。
讲法
武忠祥样本量题一律“代公式、向上取整”；比例未知直接写 0.5。
[[T-topic-01]]
专题 01

中心极限定理标准化三步

这是本章唯一稳定得分的题型，也是数一概率里最模板化的 10 分。失分几乎都在方差与分母。

  1. 识别：题目出现 n 个独立变量之和或平均，且 n 较大，先想 CLT。
  2. 求和：写出 \(S_n=\sum X_i\) 的均值 \(n\mu\) 与方差 \(n\sigma^2\)。
  3. 标准化：\(Z=(S_n-n\mu)/(\sqrt n\sigma)\)，或均值形式 \((\bar X-\mu)/(\sigma/\sqrt n)\)。
  4. 修正：离散分布加 \(\pm0.5\) 连续性修正。
  5. 查表：化为 \(\Phi\) 值，负号用 \(\Phi(-z)=1-\Phi(z)\)。
例

1000 个独立同分布 \(U(0,1)\) 变量之和超过 520 的概率近似值。

解 \(\mu=1/2,\sigma^2=1/12\)；总和近似 \(N(500,1000/12)\)；\(z\approx2.19\)，概率 \(1-\Phi(2.19)\approx0.014\)。

踩坑点 和的方差是 \(n\sigma^2\)，不是 \(n\sigma\)；标准化分母是 \(\sqrt{n}\sigma\)，少一个根号整题作废。
