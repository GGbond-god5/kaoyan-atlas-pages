01

毛泽东思想及其活的灵魂

核心必考

毛泽东思想是马克思列宁主义在中国的运用和发展，是被实践证明了的关于中国革命和建设的正确理论原则和经验总结，是中国共产党集体智慧的结晶。活的灵魂是实事求是、群众路线、独立自主。

活的灵魂：实事求是 · 群众路线 · 独立自主三个词必须完整
实事求是 = 精髓群众路线 = 根本工作路线；独立自主 = 基本立足点
毛泽东思想 ≠ 毛泽东个人思想是集体智慧的结晶
同型 毛中特选择题

毛泽东思想活的灵魂是（ ）。

要点 实事求是、群众路线、独立自主。其中实事求是是毛泽东思想的精髓。
完整解答
  1. 毛泽东思想活的灵魂是实事求是、群众路线、独立自主。
  2. 实事求是是毛泽东思想的精髓。
  3. 排除“解放思想”“与时俱进”等后世的表述。
  4. 结论：实事求是、群众路线、独立自主。
易错
  • 把毛泽东思想等同于毛泽东个人的全部思想。
  • 把「活的灵魂」与「三大法宝」混淆。
  • 漏写三个词中的任意一个。
讲法
腿姐keywords：活的灵魂三个词成组背，选择题少一个就排除。徐涛用「实事求是是根、群众路线是路、独立自主是骨」帮助记忆。

02

新民主主义革命理论

核心必考

新民主主义革命总路线：无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命。三大法宝：统一战线、武装斗争、党的建设。中国革命道路是农村包围城市、武装夺取政权。

总路线：无产阶级领导 + 人民大众 + 反三座大山领导权是核心问题
三大法宝：统一战线 · 武装斗争 · 党的建设与「活的灵魂」区分
革命道路：农村包围城市 · 武装夺取政权不是先城市后农村
同型 毛中特选择题

新民主主义革命的三大法宝是（ ）。

要点 统一战线、武装斗争、党的建设。三者相互联系，统一战线和武装斗争是战胜敌人的两个基本武器，党的建设是中心环节。
完整解答
  1. 三大法宝是统一战线、武装斗争、党的建设。
  2. 统一战线和武装斗争是战胜敌人的两个基本武器。
  3. 党的建设是中心环节。
  4. 结论：三者相互联系、不可分割。
易错
  • 把三大法宝与活的灵魂、三大作风混淆。
  • 认为新民主主义革命的领导权属于资产阶级。
  • 把革命道路记成「城市中心论」。
讲法
腿姐keywords：法宝=统一战线/武装斗争/党建；灵魂=实事求是/群众路线/独立自主，两组绝不混。

03

社会主义改造理论

核心高频

过渡时期总路线是「一化三改」：逐步实现社会主义工业化，逐步实现对农业、手工业和资本主义工商业的社会主义改造。1956 年底三大改造基本完成，标志着社会主义基本制度在我国确立。

一化三改 = 工业化 + 三大改造一体两翼，工业化是主体
农业、手工业：互助组 → 初级社 → 高级社逐步过渡
资本主义工商业：和平赎买中国独创，区别于剥夺
同型 毛中特选择题

我国对资本主义工商业进行社会主义改造采取的政策是（ ）。

要点 和平赎买。通过国家资本主义形式，逐步把资本主义私有制改造为社会主义公有制。
完整解答
  1. 政策是和平赎买。
  2. 形式是国家资本主义，由低级到高级逐步过渡。
  3. 把资本主义私有制改造为社会主义公有制。
  4. 结论：和平赎买。
易错
  • 把「一化三改」中的「一化」记成农业合作化。
  • 认为三大改造完成标志着进入社会主义初级阶段（进入的是社会主义社会；初级阶段是后来才明确的判断）。
  • 混淆互助组、初级社、高级社的次序。
讲法
徐涛用「一体两翼」讲总路线：工业化是主体，三大改造是两翼。

社会主义建设道路的初步探索

基础中频

《论十大关系》（1956）提出以苏为鉴，探索适合中国国情的社会主义建设道路。《关于正确处理人民内部矛盾的问题》（1957）提出两类不同性质的社会矛盾，人民内部矛盾要用民主的、说服教育的方法解决。

《论十大关系》1956 → 以苏为鉴、走自己的路探索开端
两类矛盾：敌我矛盾（专政）+ 人民内部矛盾（民主）处理方法不能互换
「百花齐放、百家争鸣」→ 文化领域常与两类矛盾一起考
同型 毛中特选择题

毛泽东提出「以苏为鉴，走自己的路」的著作是（ ）。

要点 《论十大关系》。它标志着党探索适合中国国情的社会主义建设道路的开始。
完整解答
  1. 著作是《论十大关系》。
  2. 它标志着党探索适合中国国情的社会主义建设道路的开始。
  3. 排除《实践论》《矛盾论》等哲学著作。
  4. 结论：《论十大关系》。
易错
  • 把《论十大关系》与《关于正确处理人民内部矛盾的问题》的主题混淆。
  • 认为人民内部矛盾也用专政方法解决。
  • 忽略这两篇著作在「初步探索」中的地位。
讲法
腿姐著作—主题一一对应：《十大关系》= 走自己的路；《正确处理》= 两类矛盾。

05

邓小平理论

核心必考

邓小平理论围绕「什么是社会主义、怎样建设社会主义」展开。社会主义本质是解放生产力、发展生产力，消灭剥削、消除两极分化，最终达到共同富裕。社会主义初级阶段理论、社会主义市场经济理论、改革开放理论、「一国两制」构成其核心内容。

社会主义本质：解放/发展生产力 + 消灭剥削/消除两极分化 + 共同富裕三句话不能漏
社会主义初级阶段：十三大系统阐述最大国情、最长时期
基本路线：一个中心、两个基本点经济建设为中心；四项基本原则 + 改革开放
同型 毛中特分析题

为什么说社会主义的本质是解放和发展生产力？

要点 生产力是社会发展最终决定力量；社会主义要体现优越性，必须创造出比资本主义更高的劳动生产率。解放和发展生产力是社会主义本质的首要内容，也是实现共同富裕的物质基础。
完整解答
  1. 生产力是社会发展的最终决定力量。
  2. 社会主义优越性最终要体现在更高的劳动生产率上。
  3. 解放和发展生产力是社会主义本质的首要内容，是实现共同富裕的物质基础。
  4. 结论：所以社会主义本质包含解放和发展生产力。
易错
  • 漏掉「最终达到共同富裕」，只写解放和发展生产力。
  • 把「一个中心」记成改革开放。
  • 认为社会主义初级阶段是泛指任何国家的社会主义起始阶段。
讲法
徐涛用「本质三句、路线一句、阶段一个」收口邓论，先框架后细节。腿姐keywords：本质题必须出现「共同富裕」，否则不完整。

06

「三个代表」重要思想

基础中频

中国共产党必须始终代表中国先进生产力的发展要求，代表中国先进文化的前进方向，代表中国最广大人民的根本利益。「三个代表」进一步回答了「建设什么样的党、怎样建设党」的问题。

三代表：先进生产力 + 先进文化 + 最广大人民根本利益三个「代表」缺一不可
回答的问题：建设什么样的党、怎样建设党与邓论的「什么是社会主义」区分
十六大写入党章（2002）时间点常考
同型 毛中特选择题

「三个代表」重要思想创造性回答的核心问题是（ ）。

要点 建设什么样的党、怎样建设党。它深化了对中国特色社会主义的认识，是加强和改进党的建设的强大理论武器。
完整解答
  1. “三个代表”创造性回答的核心问题是建设什么样的党、怎样建设党。
  2. 排除“什么是社会主义、怎样建设社会主义”，那是邓小平理论的核心问题。
  3. 它深化了对中国特色社会主义的认识，是党建理论。
  4. 结论：建设什么样的党、怎样建设党。
易错
  • 把「三个代表」回答的问题与邓小平理论回答的问题混淆。
  • 记错写入党章的时间。
  • 把三个「代表」的主体写成「人民」而非「党」。
讲法
腿姐对应关系：邓论—什么是社会主义；三个代表—建设什么样的党；科学发展观—实现什么样的发展。

科学发展观

基础中频

科学发展观的第一要义是发展，核心立场是以人为本，基本要求是全面协调可持续，根本方法是统筹兼顾。它回答了「实现什么样的发展、怎样发展」的问题。

第一要义：发展不是「以人为本」
核心：以人为本常与第一要义对调设错
基本要求：全面协调可持续；根本方法：统筹兼顾四个定位各就各位
同型 毛中特选择题

科学发展观的核心立场是（ ）。

要点 以人为本。第一要义是发展，基本要求是全面协调可持续，根本方法是统筹兼顾。
完整解答
  1. 科学发展观的核心立场是以人为本。
  2. 第一要义是发展，基本要求是全面协调可持续，根本方法是统筹兼顾。
  3. 注意题干问的是“核心立场”，不要与“第一要义”混淆。
  4. 结论：以人为本。
易错
  • 把「第一要义」与「核心」互换。
  • 把「根本方法」记成「基本要求」。
  • 认为科学发展观只讲经济，忽略全面协调可持续。
讲法
腿姐四句口诀：发展是第一要义、以人为本是核心、全面协调可持续是基本要求、统筹兼顾是根本方法。

08

中国特色社会主义理论体系与初级阶段

核心高频

中国特色社会主义理论体系包括邓小平理论、「三个代表」重要思想、科学发展观、习近平新时代中国特色社会主义思想。毛泽东思想不属于这个体系。社会主义初级阶段是我国最大的国情，基本路线是「一个中心、两个基本点」。

体系四成员：邓论 + 三个代表 + 科学发展观 + 新思想不含毛泽东思想
最大国情：社会主义初级阶段不是「初级阶段」泛指
基本路线：一个中心（经济建设）+ 两个基本点（四项基本原则、改革开放）二者统一于实践
同型 毛中特选择题

中国特色社会主义理论体系包括毛泽东思想吗？

要点 不包括。毛泽东思想是马克思列宁主义在中国的运用和发展，为中国特色社会主义理论体系提供了理论基础，但不属于该体系。
完整解答
  1. 中国特色社会主义理论体系不包括毛泽东思想。
  2. 它包括邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想。
  3. 毛泽东思想是理论基础，但不属于该体系。
  4. 结论：不包括。
易错
  • 把毛泽东思想纳入中国特色社会主义理论体系。
  • 把「一个中心」理解为以改革开放为中心。
  • 认为初级阶段很快会结束，忽视其长期性。
讲法
徐涛画体系图：马列—毛泽东思想—中特理论体系（邓、三、科、新），箭头关系一眼看清。

专题 01

毛中特时间轴：会议、著作与理论成果

毛中特的失分大多是「张冠李戴」：把十九大的判断安到十八大，把《论十大关系》安到《正确处理人民内部矛盾》。一条时间轴能解决大部分记忆型选择题。

  1. 先立四个锚点：1945 七大（毛泽东思想写入党章）、1956 八大/三大改造完成、1978 十一届三中全会、2012 十八大。
  2. 每个锚点只挂三件事：会议名称、核心判断、对应理论成果。
  3. 著作单独一列：《论十大关系》1956、《关于正确处理人民内部矛盾的问题》1957。
  4. 理论成果一列：毛泽东思想—邓小平理论—三个代表—科学发展观—新思想，按写入党章时间排序。
  5. 考前用空白纸默写时间轴，只补写不出的节点。
例

把「社会主义初级阶段理论系统阐述」与「社会主义市场经济体制改革目标确立」分别归到哪次大会？

解 前者是 1987 年十三大；后者是 1992 年十四大。二者常被互换设错。

踩坑点 不要只背年份，要背「会议—判断—成果」三件套。只背年份，题干一换表述就认不出来。
[[T-topic-02]]
专题 02

毛中特选择题关键词对应表

毛中特选择题大量考「根本、核心、本质、首要、标志、前提」这类定位词。它们无法靠理解推出，只能靠成组记忆；整理成表后，复习成本最低。

  1. 按「根本/核心/本质/首要/标志/前提/基础」七类分组，每组只收高频项。
  2. 每个关键词配一个最短判别句，不写完整定义。
  3. 把易混项放在同一行对比，如「第一要义 vs 核心」「三大法宝 vs 活的灵魂」。
  4. 每天用 10 分钟遮住右列自测，错的做标记。
  5. 考前三天只看错题标记项。
例

「科学发展观的第一要义」与「核心立场」分别是什么？

解 第一要义是发展，核心立场是以人为本。二者最容易被互换，必须成对记。

踩坑点 不要用「理解」代替「记忆」：这类题考的是教材固定表述，理解得再透，词写错也不给分。
