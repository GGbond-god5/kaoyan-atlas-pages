总体、样本与统计量

基础中频

总体是研究对象的全体，样本是独立同分布且与总体同分布的观测值。统计量是不含未知参数的样本函数；一旦表达式里出现未知参数，就不是统计量。这是选填第一道辨析。

\(X_1,\dots,X_n\) iid，与总体同分布简单随机样本
统计量 \(T=T(X_1,\dots,X_n)\) 不含未知参数判定标准
同型 数一

设总体 \(X\sim N(\mu,\sigma^2)\)，\(\mu\) 未知、\(\sigma^2\) 已知，判断 \(\bar X-\mu\) 与 \(\bar X\) 哪个是统计量。

要点 \(\bar X\) 是；\(\bar X-\mu\) 含未知参数 \(\mu\)，不是统计量。
完整解答
  1. 统计量是样本的函数，且不能含未知参数。
  2. \(\bar X\) 只由样本决定，是统计量。
  3. \(\bar X-\mu\) 含未知的 \(\mu\)，不是统计量；若 \(\mu\) 已知则可作统计量。
  4. 检验：统计量的分布应不依赖未知参数，或只依赖被估参数。
易错
  • 把含未知参数的样本函数当统计量；
  • 忽略样本的独立性要求。
讲法
武忠祥统计量的唯一标准：表达式里能不能出现未知参数，出现就不是。

02

样本均值与样本方差

核心必考

样本均值 \(\bar X\) 是总体均值的无偏估计；样本方差 \(S^2\) 分母是 \(n-1\) 而不是 \(n\)，这正是为了无偏。正态总体下 \(\bar X\) 与 \(S^2\) 相互独立，这条独立性与抽样分布定理绑定，必须记牢。

\(\bar X=\dfrac1n\sum X_i,\quad E(\bar X)=\mu,\ D(\bar X)=\dfrac{\sigma^2}{n}\)均值
\(S^2=\dfrac1{n-1}\sum(X_i-\bar X)^2,\quad E(S^2)=\sigma^2\)分母 n-1 保证无偏
\(D(S^2)=\dfrac{2\sigma^4}{n-1}\)正态总体
同型 数一

总体 \(N(\mu,\sigma^2)\)，容量为 n 的样本，求 \(E(S^2)\) 与 \(D(S^2)\)。

要点 \(E(S^2)=\sigma^2\)，\(D(S^2)=2\sigma^4/(n-1)\)。若分母误用 n，期望会变成 \(\frac{n-1}{n}\sigma^2\) 而有偏。
完整解答
  1. 正态总体下 \(\frac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)\)。
  2. 卡方期望为自由度 \(n-1\)，故 \(E(S^2)=\sigma^2\)。
  3. 卡方方差为 \(2(n-1)\)，故 \(D(S^2)=\frac{\sigma^4}{(n-1)^2}\cdot2(n-1)=\frac{2\sigma^4}{n-1}\)。
  4. 若分母用 \(n\)，期望变为 \(\frac{n-1}{n}\sigma^2\)，有偏；这正是 \(S^2\) 分母取 \(n-1\) 的原因。
易错
  • 样本方差分母写 n；
  • 认为 \(\bar X\) 与 \(S^2\) 总独立（仅正态总体）。
讲法
张宇记“分母 n-1 换无偏，正态下均值方差独立”，两句话覆盖本节。

χ² 分布

核心必考

n 个独立标准正态的平方和服从 \(\chi^2(n)\)，自由度就是平方项的个数。可加性要求各 \(\chi^2\) 相互独立。期望等于自由度、方差等于二倍自由度，是选填速算的关键。

\(Z_1^2+\cdots+Z_n^2\sim\chi^2(n)\)构造
\(E(\chi^2(n))=n,\quad D(\chi^2(n))=2n\)矩
\(\chi^2(n_1)+\chi^2(n_2)=\chi^2(n_1+n_2)\)独立时才可加
同型 数一

设 \(X_1,\dots,X_6\) 独立同分布于 \(N(0,1)\)，判断 \(X_1^2+\cdots+X_6^2\) 的分布并求其期望。

要点 \(\chi^2(6)\)，期望 6、方差 12。自由度等于独立标准正态平方项的个数。
完整解答
  1. \(X_i\sim N(0,1)\)，则 \(X_i^2\sim\chi^2(1)\)。
  2. 相互独立的卡方变量可加：\(\sum_{i=1}^6 X_i^2\sim\chi^2(6)\)。
  3. 卡方期望等于自由度 6，方差等于 \(2\times6=12\)。
  4. 检验：变量非负，且 \(E<D\)，符合卡方右偏的特征。
易错
  • 非标准正态平方和直接当 \(\chi^2\)；
  • 自由度数错；
  • 不独立仍用可加性。
讲法
武忠祥\(\chi^2\) 只看两件事：标准正态、平方和；自由度就是项数。

t 分布

核心必考

\(t(n)=Z/\sqrt{Y/n}\)，其中 \(Z\sim N(0,1)\)、\(Y\sim\chi^2(n)\) 且相互独立。t 分布关于 0 对称，n 大时接近标准正态。它出现的典型场景是总体方差未知、用样本方差替代。

\(T=\dfrac{Z}{\sqrt{Y/n}}\sim t(n)\)构造
\(E(T)=0\ (n>1),\quad D(T)=\dfrac{n}{n-2}\ (n>2)\)矩
\(t_{1-\alpha}(n)=-t_{\alpha}(n)\)对称性
同型 数一

总体 \(N(\mu,\sigma^2)\)，\(\sigma^2\) 未知，样本容量 n，写出 \((\bar X-\mu)/(S/\sqrt n)\) 的分布。

要点 服从 \(t(n-1)\)。因为分子是标准正态、分母是 \(\sqrt{\chi^2(n-1)/(n-1)}\)，且二者独立。自由度是 n-1。
完整解答
  1. 分子 \(Z=\frac{\bar X-\mu}{\sigma/\sqrt n}\sim N(0,1)\)。
  2. 分母中的 \(U=\frac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)\)。
  3. 正态抽样定理给出 \(Z\) 与 \(U\) 独立，构造 \(t=\frac{Z}{\sqrt{U/(n-1)}}\)。
  4. 化简得 \(\frac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)\)；自由度来自 \(U\) 的 \(n-1\)。
易错
  • 自由度写成 n；
  • 方差已知仍用 t；
  • 忽略分子分母的独立性。
讲法
张宇t 分布口诀：方差未知用 t，自由度 n-1；方差已知用 u。

05

F 分布

核心高频

两个独立 \(\chi^2\) 各自除以自由度后的比值服从 F 分布。它主要用于比较两个正态总体的方差。记住倒数关系：若 \(F\sim F(n_1,n_2)\)，则 \(1/F\sim F(n_2,n_1)\)。

\(F=\dfrac{\chi^2(n_1)/n_1}{\chi^2(n_2)/n_2}\sim F(n_1,n_2)\)构造，独立
\(F\sim F(n_1,n_2)\Rightarrow 1/F\sim F(n_2,n_1)\)倒数关系
\(F_{1-\alpha}(n_1,n_2)=\dfrac1{F_{\alpha}(n_2,n_1)}\)分位数换算
同型 数一

两个独立正态总体，样本容量分别为 \(n_1,n_2\)，样本方差为 \(S_1^2,S_2^2\)，写出 \(S_1^2/S_2^2\) 在 \(\sigma_1^2=\sigma_2^2\) 下的分布。

要点 \(S_1^2/S_2^2\sim F(n_1-1,n_2-1)\)。因为每个 \((n_i-1)S_i^2/\sigma_i^2\sim\chi^2(n_i-1)\) 且相互独立。
完整解答
  1. 对每个正态总体，\(\frac{(n_i-1)S_i^2}{\sigma_i^2}\sim\chi^2(n_i-1)\)。
  2. 两样本独立，故两个卡方变量独立。
  3. 在 \(\sigma_1^2=\sigma_2^2\) 下，\(\frac{S_1^2}{S_2^2}=\frac{\chi_1^2/(n_1-1)}{\chi_2^2/(n_2-1)}\)。
  4. 按 \(F\) 分布定义，\(\frac{S_1^2}{S_2^2}\sim F(n_1-1,n_2-1)\)。
易错
  • 自由度写反；
  • 忘记方差相等的前提；
  • 分位数换算时倒数方向错。
讲法
武忠祥F 分布只用于方差比；先写两个 \(\chi^2\)，再各自除自由度。

正态总体的抽样分布定理

核心必考

四条定理是一组：\(\bar X\) 正态；\((n-1)S^2/\sigma^2\sim\chi^2(n-1)\)；\(\bar X\) 与 \(S^2\) 独立；由此派生出 t 与 F。做题时先判断“方差已知还是未知”，再选 u、t、\(\chi^2\) 或 F。

\(\bar X\sim N(\mu,\sigma^2/n)\)均值分布
\(\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)\)方差分布
\(\dfrac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)\)方差未知
\(\dfrac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2}\sim F(n_1-1,n_2-1)\)两方差比
同型 数一

总体 \(N(\mu,\sigma^2)\)，\(\mu,\sigma^2\) 均未知，样本容量 16，样本方差 \(S^2\)，求 \(P(S^2/\sigma^2>c)\) 的表达式。

要点 由 \(15S^2/\sigma^2\sim\chi^2(15)\)，事件等价于 \(\chi^2(15)>15c\)，概率为上侧面积。
完整解答
  1. 正态总体下 \(\frac{15S^2}{\sigma^2}\sim\chi^2(15)\)（\(n=16\)）。
  2. 事件 \(\frac{S^2}{\sigma^2}>c\) 等价于 \(\frac{15S^2}{\sigma^2}>15c\)。
  3. 故概率为 \(P(\chi^2(15)>15c)\)，即卡方分布的上侧面积。
  4. 检验：\(c\) 越大，上侧面积越小；\(c=1\) 时约为 0.5 附近。
易错
  • 方差已知却用 t；
  • 把 \(S^2\) 的分布写成 \(\chi^2(n)\)；
  • 漏用 \(\bar X\) 与 \(S^2\) 独立。
讲法
张宇四条定理画依赖图：正态→均值→标准化；方差→\(\chi^2\)；独立→t；两方差→F。

分位数

基础高频

分位数是查表的入口：\(z_{\alpha}\) 满足 \(P(Z>z_{\alpha})=\alpha\)，即上侧面积为 \(\alpha\)。标准正态与 t 分布对称，可用负号；\(\chi^2\) 与 F 不对称，只能换算。

\(P(Z>z_{\alpha})=\alpha\)上侧分位数
\(z_{1-\alpha}=-z_{\alpha}\)标准正态对称
\(F_{1-\alpha}(n_1,n_2)=1/F_{\alpha}(n_2,n_1)\)F 分布换算
同型 数一

已知 \(z_{0.025}=1.96\)，求 \(z_{0.975}\) 与 \(P(|Z|<1.96)\)。

要点 \(z_{0.975}=-1.96\)；\(P(|Z|<1.96)=1-2\times0.025=0.95\)。
完整解答
  1. 标准正态分布关于 0 对称，分位数满足 \(z_{1-\alpha}=-z_\alpha\)。
  2. \(z_{0.975}=z_{1-0.025}=-z_{0.025}=-1.96\)。
  3. \(P(|Z|<1.96)=P(-1.96<Z<1.96)\)。
  4. \(=1-2\times0.025=0.95\)；两侧尾部各占 0.025。
易错
  • 分位数方向与累积概率混淆；
  • 对 \(\chi^2\) 使用负数对称；
  • 查表时自由度用错。
讲法
没咋了分位数只记上侧面积，其余由对称性或换算公式推。

专题 01

三大分布的构造与自由度

数一选填常直接问服从什么分布、自由度是多少。构造不清就会把 n 与 n-1 用错，后面估计与检验全盘皆输。

  1. \(\chi^2\)：数独立标准正态的平方项个数，约束掉一个参数就少一个自由度。
  2. t：分子标准正态，分母是 \(\sqrt{\chi^2/df}\)，二者必须独立。
  3. F：两个独立 \(\chi^2\) 各除自由度再相除，分子自由度在前。
  4. 看条件：方差已知用 u，未知用 t；比较方差用 F；方差本身用 \(\chi^2\)。
  5. 写结论：分布名与自由度都要写全。
例

总体正态，n=10，\(\sigma^2\) 未知，判断 \((\bar X-\mu)/(S/\sqrt{10})\) 的分布。

解 \(t(9)\)。分子 \((\bar X-\mu)/(\sigma/\sqrt{10})\sim N(0,1)\)，分母 \(S/\sigma=\sqrt{\chi^2(9)/9}\)，独立，故为 t(9)。

踩坑点 自由度来自 \(S^2\) 的 \(n-1\)，不是样本容量 n；这是最高频失分点。
[[T-topic-02]]
专题 02

抽样分布题的判断流程

这一章的题几乎不靠计算，靠选对统计量。流程固定，练熟后每题 30 秒定型。

  1. 第一步看问什么：均值、方差、方差比，还是单个观测。
  2. 第二步看已知：\(\sigma^2\) 已知用 u，未知用 t；两总体方差比用 F。
  3. 第三步看独立性：正态总体才有 \(\bar X\) 与 \(S^2\) 独立。
  4. 第四步写标准化：分子减均值、分母除标准误。
  5. 第五步定自由度并查表，注意单双侧。
例

两正态总体方差未知但相等，比较均值，应使用什么统计量？

解 合并方差 \(S_p^2\) 的 t 统计量，自由度 \(n_1+n_2-2\)。若方差不相等则不能用合并方差。

踩坑点 题目未说明正态总体时，t 与 F 的结论都不成立。
