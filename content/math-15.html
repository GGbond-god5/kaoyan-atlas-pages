分布函数及其性质

核心必考

分布函数 \(F(x)=P(X\le x)\) 是描述随机变量的统一工具，离散型、连续型都适用。四条性质必须能默写：单调不减、右连续、\(F(-\infty)=0\)、\(F(+\infty)=1\)。求区间概率时注意端点：\(P(a<X\le b)=F(b)-F(a)\)。

\(F(x)=P(X\le x)\)定义域为全体实数
\(P(a<X\le b)=F(b)-F(a)\)左开右闭，端点归属要与 F 一致
\(P(X=a)=F(a)-F(a-0)\)跳跃度即该点概率
同型 数一

已知 \(F(x)\) 分段给出，求 \(P(1<X\le 3)\) 与 \(P(X=2)\)。

要点 \(P(1<X\le3)=F(3)-F(1)\)；\(P(X=2)=F(2)-F(2-0)\)。连续型在单点概率恒为 0，离散型才看跳跃。
完整解答
  1. 由分布函数定义 \(P(a<X\le b)=F(b)-F(a)\)，取 \(a=1,b=3\)。
  2. \(P(1<X\le3)=F(3)-F(1)\)，把分段表达式代入即可。
  3. \(P(X=2)=F(2)-F(2-0)\)，即 \(F\) 在 \(x=2\) 处的跳跃高度。
  4. 检验：连续型在单点概率为 0；离散型才等于跳跃值。
易错
  • 把 \(P(a<X<b)\) 写成 \(F(b)-F(a)\)，漏掉端点概率；
  • 认为分布函数一定连续（离散型是阶梯）。
讲法
武忠祥分布函数先看右连续与两端极限，选择题常用这两条排除错误选项。

离散型随机变量与常见分布

核心必考

离散型由分布律 \(p_k=P(X=x_k)\) 完全确定，\(\sum p_k=1\)。四个必背分布：0-1 分布、二项分布、泊松分布、几何分布。泊松是二项的极限情形（n 大 p 小，\(\lambda=np\)），题干出现“稀有事件”“单位时间次数”优先想泊松。

\(X\sim B(n,p):\ P(X=k)=C_n^k p^k(1-p)^{n-k}\)n 重伯努利成功次数
\(X\sim P(\lambda):\ P(X=k)=\dfrac{\lambda^k}{k!}e^{-\lambda}\)\(E=D=\lambda\)
\(X\sim G(p):\ P(X=k)=(1-p)^{k-1}p\)首次成功所需次数，\(k=1,2,\dots\)
同型 数一

某放射性物质单位时间内放出粒子数服从参数为 \(\lambda\) 的泊松分布，求单位时间内至少放出 1 个粒子的概率。

要点 \(1-P(X=0)=1-e^{-\lambda}\)。凡“至少一个”先取对立事件，是离散分布的基本功。
完整解答
  1. \(X\sim P(\lambda)\)，\(P(X=k)=e^{-\lambda}\lambda^k/k!\)。
  2. “至少放出一个”取对立事件：\(P(X\ge1)=1-P(X=0)\)。
  3. \(P(X=0)=e^{-\lambda}\)，故 \(P(X\ge1)=1-e^{-\lambda}\)。
  4. 检验：\(\lambda\to0\) 时概率趋于 0；\(\lambda=1\) 时为 \(0.632\)，合理。
易错
  • 几何分布从 0 还是从 1 开始记错；
  • 二项与泊松的适用条件混淆；
  • 泊松分布归一化记成 \(\lambda^k/k!\) 漏掉 \(e^{-\lambda}\)。
讲法
张宇四个分布画一张表：参数、分布律、期望、方差，背表不背推导。

连续型随机变量与概率密度

核心必考

连续型由概率密度 \(f(x)\) 描述，\(f(x)\ge0\) 且 \(\int_{-\infty}^{+\infty}f=1\)。密度不是概率，可以大于 1；连续型随机变量取任一点的概率为 0。\(F(x)=\int_{-\infty}^{x}f(t)dt\)，在 \(f\) 的连续点处 \(F'(x)=f(x)\)。

\(P(a<X<b)=\int_a^b f(x)\,dx\)端点开闭无关
\(F(x)=\int_{-\infty}^{x}f(t)\,dt,\quad F'(x)=f(x)\)连续点处
\(\int_{-\infty}^{+\infty}f(x)\,dx=1\)归一化，求未知常数必用
同型 数一

已知 \(f(x)=Ae^{-|x|}\) 为某随机变量的密度，求 \(A\) 与 \(P(|X|<1)\)。

要点 \(\int_{-\infty}^{\infty}Ae^{-|x|}dx=2A=1\)，故 \(A=1/2\)；\(P(|X|<1)=2\int_0^1 \frac12 e^{-x}dx=1-e^{-1}\)。
完整解答
  1. 密度归一化：\(\int_{-\infty}^{\infty}Ae^{-|x|}dx=2A\int_0^\infty e^{-x}dx=2A=1\)，故 \(A=1/2\)。
  2. \(P(|X|<1)=\int_{-1}^{1}\frac12 e^{-|x|}dx=2\cdot\frac12\int_0^1 e^{-x}dx\)。
  3. 积分得 \(1-e^{-1}\approx0.632\)。
  4. 检验：结果小于 1；密度关于 0 对称，对称区间可直接用 2 倍半区间。
易错
  • 把 \(f(x)\) 当作 \(P(X=x)\)；
  • 求归一化常数时漏掉分段积分的另一半；
  • 认为密度必须小于 1。
讲法
武忠祥密度只保证“积分是概率”，先画密度图再定积分限，比套公式稳。

均匀分布

基础高频

\(X\sim U(a,b)\) 在区间内等可能，密度为常数 \(1/(b-a)\)。它的分布函数是一条斜线，常作为“取一个随机点”的模型，也是二维均匀分布与几何概型的桥梁。

\(f(x)=\dfrac{1}{b-a},\ a<x<b\)区间外为 0
\(F(x)=\dfrac{x-a}{b-a},\ a\le x<b\)线性增长
\(E(X)=\dfrac{a+b}{2},\ D(X)=\dfrac{(b-a)^2}{12}\)必背
同型 数一

\(X\sim U(0,2)\)，求 \(P(X^2<1)\)。

要点 \(X^2<1\iff -1<X<1\)，在 \((0,2)\) 内为 \((0,1)\)，概率 \(=1/2\)。先解不等式再与支撑集取交。
完整解答
  1. \(X\sim U(0,2)\)，密度在 \((0,2)\) 上为 \(1/2\)。
  2. 解不等式 \(X^2<1\)，得 \(-1<X<1\)。
  3. 与支撑集 \((0,2)\) 取交，得 \((0,1)\)，区间长度 1。
  4. 故概率 \(=1/2\)；区间完全落在支撑集内，可直接用长度比。
易错
  • 忘记与支撑集取交集，直接用区间长度；
  • 把均匀分布的密度区间端点写反。
讲法
张宇均匀分布题一律先画数轴，标出支撑集，再把事件翻译成区间。

指数分布与无记忆性

核心高频

\(X\sim E(\lambda)\) 描述等待时间，密度 \(\lambda e^{-\lambda x}\)。最重要的性质是无记忆性：\(P(X>s+t\mid X>s)=P(X>t)\)。题干出现“已使用/已等待了多久，再等多久”优先想无记忆性。

\(f(x)=\lambda e^{-\lambda x},\ x>0\)\(\lambda>0\)
\(F(x)=1-e^{-\lambda x},\ x>0\)求“至多”直接用
\(E(X)=\dfrac{1}{\lambda},\ D(X)=\dfrac{1}{\lambda^2}\)参数是率，不是均值
同型 数一

某元件寿命服从参数为 \(\lambda\) 的指数分布，已知已使用 \(s\) 小时，求再使用 \(t\) 小时仍正常的概率。

要点 由无记忆性，概率为 \(e^{-\lambda t}\)，与 \(s\) 无关。若用条件概率定义算，会得到同一个指数尾。
完整解答
  1. \(X\sim E(\lambda)\)，尾概率 \(P(X>t)=e^{-\lambda t}\)。
  2. 条件概率 \(P(X>s+t\mid X>s)=\frac{P(X>s+t)}{P(X>s)}\)。
  3. 代入 \(=\frac{e^{-\lambda(s+t)}}{e^{-\lambda s}}=e^{-\lambda t}\)。
  4. 结果与 \(s\) 无关，即无记忆性；检验：\(t=0\) 时为 1。
易错
  • 把 \(\lambda\) 当成平均寿命；
  • 无记忆性只对指数分布成立，不能套到其他分布。
讲法
武忠祥指数分布记“率参数”，均值是 \(1/\lambda\)；看到“已经用了多久”直接写无记忆性。

正态分布与标准化

核心必考

\(X\sim N(\mu,\sigma^2)\) 的密度关于 \(\mu\) 对称，标准化 \(Z=(X-\mu)/\sigma\sim N(0,1)\) 后查表。核心技巧：所有正态概率都化为 \(\Phi\) 值，利用 \(\Phi(-z)=1-\Phi(z)\)。线性变换保持正态：\(aX+b\sim N(a\mu+b,a^2\sigma^2)\)。

\(Z=\dfrac{X-\mu}{\sigma}\sim N(0,1)\)标准化
\(P(X\le x)=\Phi\!\left(\dfrac{x-\mu}{\sigma}\right)\)查表
\(\Phi(-z)=1-\Phi(z)\)对称性，负值转正
同型 数一

\(X\sim N(2,9)\)，求 \(P(1<X<5)\)（用 \(\Phi\) 表示）。

要点 标准化：\(P=\Phi\!\left(\frac{5-2}{3}\right)-\Phi\!\left(\frac{1-2}{3}\right)=\Phi(1)-\Phi(-1/3)=\Phi(1)+\Phi(1/3)-1\)。
完整解答
  1. \(X\sim N(2,9)\)，\(\sigma=3\)，标准化 \(Z=(X-2)/3\sim N(0,1)\)。
  2. \(P(1<X<5)=P\!\left(\frac{1-2}{3}<Z<\frac{5-2}{3}\right)=P(-1/3<Z<1)\)。
  3. \(=\Phi(1)-\Phi(-1/3)=\Phi(1)+\Phi(1/3)-1\)。
  4. 数值 \(\approx0.8413+0.6306-1=0.4719\)；区间关于均值不对称，略小于 0.5 合理。
易错
  • 方差 \(\sigma^2\) 与标准差 \(\sigma\) 混用；
  • 负分位数不转化，直接查表；
  • 认为正态分布密度最大值是 \(1/\sigma\)（漏 \(\sqrt{2\pi}\)）。
讲法
张宇正态题三步：标准化、化正、查表；草稿上先写 \(Z=\cdot\) 再代数字。

一维随机变量函数的分布

核心必考

求 \(Y=g(X)\) 的分布，通用方法是分布函数法：先写 \(F_Y(y)=P(g(X)\le y)\)，把事件翻译成 X 的区间，再用 X 的分布求概率，最后求导得密度。只有当 \(g\) 严格单调且可导时，才能直接用反函数公式。

\(F_Y(y)=P(g(X)\le y)\)通用起点，不要跳步
\(f_Y(y)=f_X(h(y))\,|h'(y)|\)\(h=g^{-1}\)，仅单调时可用
\(Y=aX+b\Rightarrow f_Y(y)=\dfrac{1}{|a|}f_X\!\left(\dfrac{y-b}{a}\right)\)线性变换
同型 数一

\(X\sim U(0,1)\)，令 \(Y=-2\ln X\)，求 \(Y\) 的密度。

要点 \(F_Y(y)=P(-2\ln X\le y)=P(X\ge e^{-y/2})=1-e^{-y/2}\)（\(y>0\)），求导得 \(f_Y(y)=\frac12 e^{-y/2}\)，即 \(Y\sim E(1/2)\)。
完整解答
  1. \(X\in(0,1)\)，故 \(Y=-2\ln X>0\)；先求分布函数。
  2. \(F_Y(y)=P(-2\ln X\le y)=P(X\ge e^{-y/2})=1-e^{-y/2}\)，\(y>0\)。
  3. 求导得 \(f_Y(y)=\frac12 e^{-y/2}\)，\(y>0\)。
  4. 即 \(Y\sim E(1/2)\)；检验 \(\int_0^\infty\frac12e^{-y/2}dy=1\)。
易错
  • 不讨论 \(y\) 的取值范围，密度写成全轴；
  • 单调公式漏绝对值；
  • 分段函数忘记逐段求再合并。
讲法
武忠祥函数分布题只用分布函数法，先事件、再区间、再求导，三步不跳。
[[T-topic-01]]
专题 01

分布函数法求 \(Y=g(X)\) 的五步

这是本章最稳定的解答题来源，也是二维“和的分布”的基础。失分点几乎都在取值范围与分段，而不是积分本身。

  1. 写定义：\(F_Y(y)=P(g(X)\le y)\)，先不要动 X 的密度。
  2. 解不等式：把 \(g(X)\le y\) 解成 X 的区间，注意 \(g\) 不单调时要分段。
  3. 定范围：由 X 的支撑集确定 \(y\) 的有效范围，范围外 \(F_Y=0\) 或 1。
  4. 算概率：用 X 的分布函数或密度积分，得到 \(F_Y(y)\)。
  5. 求导：在可导点对 \(y\) 求导得 \(f_Y(y)\)，并写成分段形式。
例

\(X\sim N(0,1)\)，\(Y=X^2\)，求 \(f_Y(y)\)。

解 \(y\le0\) 时 \(F_Y=0\)；\(y>0\) 时 \(F_Y=P(-\sqrt y\le X\le\sqrt y)=2\Phi(\sqrt y)-1\)，求导得 \(f_Y(y)=\frac{1}{\sqrt{2\pi y}}e^{-y/2}\)，即 \(\chi^2(1)\)。

踩坑点 \(g\) 不单调时，一个 \(y\) 对应两段 X 区间，概率必须相加；只写一段是本章最常见的错误。
