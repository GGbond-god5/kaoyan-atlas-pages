01

挠曲线近似微分方程

核心高频

在弹性、小变形条件下，挠曲线近似微分方程为 \(EIw''=-M(x)\)（w 向上为正，M 下凸为正）。二次积分得转角与挠度，积分常数由边界条件和连续条件确定。符号约定必须在题首写明，否则整题符号会翻。

\(EIw''=-M(x)\)w 向上为正，M 下凸为正
\(EI\theta=-\int M(x)\,dx+C\)θ ≈ w′，小变形
\(EIw=-\int\!\int M(x)\,dx\,dx+Cx+D\)二次积分
同型 807 高频题型

简支梁受均布载荷，用积分法求最大挠度。

要点 写出 \(M(x)=qx(l-x)/2\)，代入方程二次积分；由 \(w(0)=w(l)=0\) 定常数，得 \(w_{\max}=5ql^4/(384EI)\)，在跨中。
完整解答
  1. 简支梁均布载荷，弯矩 \(M(x)=qx(l-x)/2\)。
  2. 挠曲线近似微分方程 \(EIw''=-M(x)\)，积分一次得转角、两次得挠度。
  3. 边界条件 \(w(0)=0,\ w(l)=0\) 定两个积分常数。
  4. 最大挠度在跨中，\(w_{\max}=5ql^4/(384EI)\)。
  5. 校核：量纲为长度，均布载荷增大或刚度减小则挠度增大。
易错
  • 符号约定不统一，导致 w 与 M 反号。
  • 把 \(w''\) 直接当成曲率而不作小变形近似。
讲法
瞌睡哥先写清“w 向上为正、M 下凸为正”，再动笔；符号错是弯曲变形题的第一大失分点。

02

积分法与边界条件

核心必考

积分法的关键是分段与定常数。集中力、集中力偶处弯矩表达式改变，必须分段积分；每段两个积分常数，由支座边界条件（简支端 w=0，固定端 w=0 且 θ=0）和分段点连续条件（w、θ 连续）确定。

\(w(0)=0,\quad w(l)=0\)简支梁边界
\(w(0)=0,\quad \theta(0)=0\)固定端边界
\(w_i(x_0)=w_{i+1}(x_0),\quad \theta_i(x_0)=\theta_{i+1}(x_0)\)分段点连续
同型 807 高频题型

简支梁跨中受集中力，用积分法求跨中挠度与支座转角。

要点 分两段写弯矩，积分后由边界与跨中连续条件定四个常数；得 \(w_{\max}=Fl^3/(48EI)\)，支座转角 \(\theta=Fl^2/(16EI)\)。
完整解答
  1. 以集中力为界分两段写弯矩方程。
  2. 每段积分两次，共四个积分常数。
  3. 用两端挠度为零、跨中挠度与转角连续定常数。
  4. 得跨中挠度 \(w_{\max}=Fl^3/(48EI)\)。
  5. 支座转角 \(\theta=Fl^2/(16EI)\)，方向由载荷指向确定。
易错
  • 分段后漏写连续条件，常数定不出来。
  • 把固定端转角条件漏掉（只写 w=0）。
讲法
瞌睡哥积分法只适合简单载荷；复杂载荷用叠加法，考场上不要硬积。

叠加法求挠度与转角

核心必考

在线弹性、小变形下，多个载荷产生的挠度与转角可代数叠加。把复杂梁拆成几个标准梁（简支均布、简支跨中集中力、悬臂端集中力、悬臂均布），查标准公式后在同一截面相加。叠加法比积分法快得多，是 807 的首选。

\(w_{\max}=\dfrac{5ql^4}{384EI}\)简支梁均布，跨中
\(w_{\max}=\dfrac{Fl^3}{48EI}\)简支梁跨中集中力
\(w_{\max}=\dfrac{Fl^3}{3EI}\)悬臂梁自由端集中力
\(w_{\max}=\dfrac{ql^4}{8EI}\)悬臂梁均布
同型 807 高频题型

悬臂梁受均布载荷 q 与自由端集中力 F，求自由端挠度。

要点 分别叠加：\(ql^4/(8EI)+Fl^3/(3EI)\)；注意两个标准梁的固定端位置与坐标一致。
完整解答
  1. 把载荷拆成均布 \(q\) 与自由端集中力 \(F\) 两个标准工况。
  2. 均布悬臂自由端挠度 \(ql^4/(8EI)\)。
  3. 端部集中力挠度 \(Fl^3/(3EI)\)。
  4. 两者同向，直接相加 \(w=ql^4/(8EI)+Fl^3/(3EI)\)。
  5. 校核：固定端转角不为零，自由端剪力为零。
易错
  • 叠加时坐标原点不一致，力臂或符号出错。
  • 把不同截面的挠度直接相加。
讲法
瞌睡哥背四个标准公式，叠加法就够用；考场上不推导。

梁的刚度条件

核心高频

刚度条件：最大挠度 \(w_{\max}\le[w]\)，最大转角 \(\theta_{\max}\le[\theta]\)。许用挠度常按跨度的分数给出（如 \(l/250\)、\(l/400\)）。刚度不足会影响正常使用，但不一定意味着强度不足；807 可能要求同时满足强度与刚度。

\(w_{\max}\le[w]=\dfrac{l}{n}\)n 常取 250、400 等
\(\theta_{\max}\le[\theta]\)转角限值，rad
\(I_z\ge\dfrac{5ql^3\cdot n}{384E}\)均布简支梁由刚度反解惯性矩
同型 807 题

简支梁受均布载荷，要求跨中挠度不超过 l/250，求所需截面高度。

要点 由 \(5ql^4/(384EI)\le l/250\) 解出 \(I\) 下限，再由矩形 \(I=bh^3/12\) 反解 h；同时用强度条件校核，取较大高度。
完整解答
  1. 刚度条件 \(w_{\max}=5ql^4/(384EI)\le l/250\)。
  2. 解出所需惯性矩 \(I\ge5ql^3\cdot250/(384E)\)。
  3. 矩形 \(I=bh^3/12\)，给定 \(b\) 反解 \(h\)。
  4. 再用强度条件 \(W=bh^2/6\ge M/[\sigma]\) 校核。
  5. 取强度与刚度要求的较大截面尺寸。
易错
  • 刚度条件与强度条件混为一谈。
  • 许用挠度单位与计算挠度单位不一致。
讲法
瞌睡哥刚度题统一“反解 I，再反解尺寸”，最后与强度结果取大值。

简单超静定梁

核心必考

超静定梁的多余约束常用变形比较法解除：去掉多余支座，代以反力，使该处挠度等于实际约束位移（通常为零）。方程仍为三件套：平衡、变形协调、物理关系。807 的超静定梁常与刚性梁、吊杆组合出现。

\(w_{0}+w_{R}=0\)解除约束处的实际位移 + 反力产生的位移 = 0
\(R_B=\dfrac{3ql}{8}\)一端固定一端简支、均布载荷时的简支端反力
同型 807 题

一端固定、一端简支的梁受均布载荷，求支座反力。

要点 解除简支端代以 \(R_B\)；悬臂梁在 q 与 \(R_B\) 共同作用下 B 端挠度为零，\(ql^4/(8EI)-R_B l^3/(3EI)=0\)，得 \(R_B=3ql/8\)。
完整解答
  1. 一次超静定，解除简支端 B，代以反力 \(R_B\)。
  2. 变形协调：B 端挠度为零。
  3. 均布载荷产生向下挠度 \(ql^4/(8EI)\)，\(R_B\) 产生向上挠度 \(R_Bl^3/(3EI)\)。
  4. 令两者相等：\(R_B=3ql/8\)。
  5. 由平衡得 \(R_A=5ql/8\)，固定端弯矩 \(M_A=ql^2/8\)，并校核。
易错
  • 协调方程符号错：把“挠度为零”写成“两挠度相等”。
  • 忘记多余约束处的实际位移可能不为零（支座沉降）。
讲法
瞌睡哥超静定梁与拉压超静定同一套三步法，只是物理关系换成挠度公式。

提高弯曲刚度的措施

基础中频

挠度与 \(EI\) 成反比、与跨度的高次方成正比。有效措施：增大截面惯性矩（材料外移、工字形）、缩短跨度或增加中间支承、改善载荷布置、采用变截面梁。注意提高刚度主要靠 \(I_z\)，而提高强度主要靠 \(W_z\)，二者不完全一致。

\(w\propto\dfrac{1}{EI}\)刚度与 EI 成正比
\(w\propto l^4\)均布载荷下对跨度极敏感
同型 807 概念题

为什么增加中间支座比增大截面更有效地减小挠度？

要点 增加中间支座把跨度分段，挠度随跨度四次方下降，效果远大于单纯增大 \(I\)；但会增加超静定次数与支座反力。
完整解答
  1. 挠度与跨度四次方成正比，\(w\propto l^4\)。
  2. 增加中间支座把跨度减半，挠度约降为原来的 \(1/16\)。
  3. 增大截面只按 \(I\) 线性或三次方改善，效果弱。
  4. 但增加支座提高超静定次数，支座反力与温度/沉降敏感。
  5. 结论：控制挠度优先“减跨”，再考虑“加刚度”。
易错
  • 认为提高强度的方法必然提高刚度。
  • 忽略跨度对挠度的四次方影响。
讲法
瞌睡哥记“缩短跨度最有效，材料外移次之，增大面积最笨”。

叠加法：跨中集中力 + 半跨均布

进阶高频

叠加法的关键不是套两个公式，而是先确认每个标准工况的支承、坐标与挠度方向一致。半跨均布可利用对称性：整跨均布在跨中的挠度，由左右半跨各贡献一半。

\(w_P=\dfrac{Pl^3}{48EI}\)简支梁跨中集中力
\(w_q=\dfrac{5ql^4}{768EI}\)半跨均布在跨中的挠度（整跨的一半）
\(w_{\text{mid}}=\dfrac{Pl^3}{48EI}+\dfrac{5ql^4}{768EI}\)同向相加
同型 807 题

简支梁长 \(l\)，跨中作用集中力 \(P\)，左半跨作用均布载荷 \(q\)，求跨中挠度。

要点 \(w_{\text{mid}}=\dfrac{Pl^3}{48EI}+\dfrac{5ql^4}{768EI}\)。
完整解答
  1. 拆成两个标准工况：①跨中集中力 \(P\)；②左半跨均布 \(q\)。
  2. 工况①直接查表：\(w_1=Pl^3/(48EI)\)，方向向下。
  3. 工况②利用对称性：整跨均布跨中挠度为 \(5ql^4/(384EI)\)，左右半跨各贡献一半，故 \(w_2=5ql^4/(768EI)\)。
  4. 两工况同向，跨中挠度 \(w=w_1+w_2\)。
  5. 校核：若 \(q=0\) 退化为 \(Pl^3/(48EI)\)；若 \(P=0\) 退化为半跨均布结果。
易错
  • 把半跨均布误按整跨 \(5ql^4/(384EI)\) 计算，结果翻倍。
  • 两个工况的挠度方向不一致时仍直接相加，未定符号。
讲法
瞌睡哥叠加法先拆标准工况，再统一坐标与正方向，最后代数和。

08

一次超静定梁：多余约束与变形协调

核心必考

一端固定、一端简支的梁是一次超静定。解除简支端代以反力 \(R_B\)，用“B 端挠度为零”作协调条件，把 \(q\) 与 \(R_B\) 两个悬臂梁工况叠加。

\(R_B=\dfrac{3ql}{8}\)均布载荷下
\(R_A=\dfrac{5ql}{8},\quad M_A=\dfrac{ql^2}{8}\)固定端反力与弯矩
同型 807 题

一端固定、一端简支的梁受均布载荷 \(q\)，求两端反力与固定端弯矩。

要点 \(R_B=3ql/8,\ R_A=5ql/8,\ M_A=ql^2/8\)。
完整解答
  1. 解除 B 端简支约束，代以竖向反力 \(R_B\)，结构化为悬臂梁。
  2. 变形协调：B 端实际挠度为零，\(w_B=0\)。
  3. 均布 \(q\) 使 B 端下挠 \(ql^4/(8EI)\)；\(R_B\) 使 B 端上挠 \(R_Bl^3/(3EI)\)。
  4. 令两者相等：\(R_Bl^3/(3EI)=ql^4/(8EI)\)，得 \(R_B=3ql/8\)。
  5. 由竖向平衡 \(R_A=ql-R_B=5ql/8\)；对 A 取矩得 \(M_A=ql^2/8\)，并校核 B 端弯矩为零。
易错
  • 协调方程符号写反，把上挠与下挠同号相加。
  • 求出 \(R_B\) 后不再回代平衡，导致 \(R_A\)、\(M_A\) 错。
讲法
瞌睡哥超静定先解除多余约束，再把“实际位移=0”写成方程。

专题 01

叠加法求挠度：四步不出错

807 的变形题时间有限，积分法容易算错常数；叠加法只要标准公式背熟，5 分钟就能出结果。

  1. 把载荷拆成标准形式：均布、跨中集中、端部集中、集中力偶。
  2. 统一坐标原点与正方向，画出示意图。
  3. 查标准公式，注意每个公式对应的梁型与位置。
  4. 在同一截面代数相加，拉压/上下符号统一。
  5. 检查边界：支座处挠度应为零，固定端转角应为零。
例

简支梁跨中受集中力 F，同时全长受均布 q，求跨中挠度。

解 \(w=Fl^3/(48EI)+5ql^4/(384EI)\)，两项均向下，直接相加。

踩坑点 悬臂梁公式与简支梁公式不能混用；先确认梁型，再查公式。

专题 02

超静定梁：变形比较法三方程

超静定是 807 的年度必考，梁的超静定比拉压更常与刚性梁、吊杆组合，变形协调的几何关系更隐蔽。

  1. 判断超静定次数，选择多余约束并解除。
  2. 代以多余反力，写出解除后结构在载荷与反力共同作用下的位移。
  3. 写协调条件：多余约束处的实际位移（常为零）。
  4. 用标准挠度公式代入，解出多余反力。
  5. 回代平衡方程求其余反力，画内力图校核。
例

一端固定、一端简支梁受均布 q，求固定端反力偶。

解 解除简支端代以 \(R_B=3ql/8\)；固定端反力偶由平衡求得 \(M_A=ql^2/8\)，方向与载荷产生的弯矩相反。

踩坑点 协调方程写“挠度相等”还是“挠度为零”，取决于解除的是哪种约束；先画解除后的结构图。
[[T-topic-03]]
专题 03

叠加法与超静定梁：拆载荷、补约束

807 的弯曲变形题很少只考一个标准梁：要么多载荷叠加，要么多一个支座。核心动作只有两个——拆载荷、补约束。

  1. 拆：把复杂载荷拆成集中力、均布、力偶等标准工况。
  2. 统：统一坐标、正方向与截面位置，避免公式混用。
  3. 补：超静定先解除多余约束，代以多余反力。
  4. 协：写被解除处的位移（或转角）协调条件。
  5. 叠：物理关系代入后与平衡方程联立，回代校核。
例

为什么半跨均布在跨中的挠度是整跨的一半？

解 把整跨均布看成左半跨与右半跨两个对称工况；跨中位于对称轴上，两者贡献相等，故各占整跨结果的一半。

踩坑点 叠加法不是“看到两个载荷就把两个最大挠度相加”；最大挠度位置不同时要先写挠曲线函数，再在同一截面相加。

专题 04

推导：q、Q、M、θ、v 的微分关系

剪力图、弯矩图、挠度之间的符号关系是 807 作图题与超静定题的底层规则。记住“q→Q→M→θ→v 逐次积分”，比背结论稳。

  1. 取微段 \(dx\)，设分布载荷 \(q(x)\) 向下为正；左端剪力 \(Q\)、弯矩 \(M\)，右端为 \(Q+dQ\)、\(M+dM\)。
  2. 竖向平衡：\(Q+q\,dx-(Q+dQ)=0\)，得 \(dQ/dx=q\)。即剪力图的斜率等于分布载荷集度。
  3. 对微段右端取矩，略去高阶小量 \(q\,dx\cdot dx/2\)，得 \(dM/dx=Q\)。即弯矩图的斜率等于剪力。
  4. 由平面假设与线弹性，曲率 \(\kappa=M/(EI)\)；小变形下 \(\kappa\approx v''\)，所以 \(EIv''=M\)。
  5. 逐次求导：\(\theta=v'\)，\(M=EIv''\)，\(Q=EIv'''\)，\(q=EIv''''\)。反过来就是逐次积分，每积一次多一个常数，由边界条件确定。
  6. 边界与连续条件：铰支 \(v=0\)、固定端 \(v=\theta=0\)、自由端 \(M=Q=0\)；集中力处 \(Q\) 突变、集中力偶处 \(M\) 突变，但 \(v,\theta\) 连续。
  7. 用途：控制面法快速作图、超静定梁变形协调、能量法结果校核。
例

简支梁长 \(l\)、均布载荷 \(q\)、抗弯刚度 \(EI\)，用微分关系求跨中最大挠度。

解 反力各 \(ql/2\)，\(M(x)=qx(l-x)/2\)；由 \(EIv''=M\) 积分两次，代入 \(v(0)=v(l)=0\)，得 \(v(x)=\dfrac{qx}{24EI}(l^3-2lx^2+x^3)\)，跨中 \(v_{\max}=\dfrac{5ql^4}{384EI}\)。

踩坑点 符号约定要统一：q 向下为正时 \(dQ/dx=q\)、\(dM/dx=Q\)；若把 \(EIv''=M\) 写成 \(-M\)，挠度方向会整体反号。
