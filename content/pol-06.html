人生观与人生价值

核心必考

人生观主要包括人生目的、人生态度和人生价值。人生目的是人生观的核心，回答「为什么活着」。人生价值包括自我价值与社会价值，社会价值是主要方面。评价人生价值的根本尺度是看一个人的实践活动是否符合社会发展客观规律、是否促进了社会进步。

人生观三要素：目的（核心）· 态度 · 价值「核心」是高频填空
人生价值：自我价值 + 社会价值社会价值是主要方面
评价尺度：是否符合社会发展规律 + 是否促进社会进步两条并用
同型 思修选择题

人生观的核心是（ ）。

要点 人生目的。它决定人生道路、人生态度和人生价值标准。
完整解答
  1. 人生观包括人生目的、人生态度和人生价值。
  2. 人生目的是人生观的核心。
  3. 它决定人生道路、人生态度和人生价值标准。
  4. 结论：人生目的。
同型 思修分析题

结合某青年扎根基层的事迹，说明如何评价人生价值。

要点 看其社会价值：是否促进社会进步、是否符合人民需要；同时承认自我价值。评价的根本尺度是社会实践及其效果，不是职位高低或收入多少。
完整解答
  1. 评价人生价值的根本尺度是社会实践及其效果。
  2. 看社会价值：是否促进社会进步、是否符合人民需要。
  3. 同时承认自我价值，二者是统一的。
  4. 不以职位高低、收入多少作为根本标准。
易错
  • 把「人生态度」当作人生观核心。
  • 只讲自我价值，忽略社会价值的主要地位。
  • 用财富、地位作为评价人生价值的主要标准。
讲法
腿姐keywords：人生目的=核心；社会价值=主要方面；评价尺度=社会发展+人民需要。

理想信念与马克思主义信仰

核心必考

理想是人们在实践中形成的、有实现可能性的对未来的向往和追求；信念是人们在一定的认识基础上确立的对某种思想或事物坚信不疑并身体力行的心理态度和精神状态。马克思主义是科学信仰，中国特色社会主义是共同理想，共产主义是远大理想。

理想 = 有实现可能性的向往区别于空想
信仰三层次：马克思主义 · 中国特色社会主义 · 共产主义科学信仰—共同理想—远大理想
理想与现实：对立统一，在一定条件下转化分析题常用
同型 思修分析题

如何理解「理想信念是精神之钙」？

要点 理想信念提供方向、动力和定力；缺钙就会精神懈怠、方向迷失。马克思主义信仰和中国特色社会主义共同理想是共产党人安身立命的根本。
完整解答
  1. 理想信念提供方向、动力和定力。
  2. 缺钙就会精神懈怠、方向迷失。
  3. 马克思主义信仰和中国特色社会主义共同理想是共产党人安身立命的根本。
  4. 结论：理想信念是精神之钙。
易错
  • 把理想等同于空想，忽略「有实现可能性」。
  • 把中国特色社会主义共同理想与共产主义远大理想割裂。
  • 认为理想与现实不可调和。
讲法
徐涛用「方向—动力—定力」三力解释理想信念的作用，答分析题不空。

中国精神与爱国主义

核心必考

中国精神以爱国主义为核心的民族精神和以改革创新为核心的时代精神为两翼。民族精神包括伟大创造精神、伟大奋斗精神、伟大团结精神、伟大梦想精神。爱国主义是中华民族精神的核心，其本质是爱国、爱党、爱社会主义的高度统一。

民族精神核心：爱国主义；时代精神核心：改革创新两个核心不能对调
四个伟大精神：创造 · 奋斗 · 团结 · 梦想民族精神内容
爱国主义本质：爱国 + 爱党 + 爱社会主义相统一三统一
同型 思修分析题

新时代为什么必须弘扬以爱国主义为核心的民族精神？

要点 爱国主义是凝聚民族力量的精神纽带，是中华民族团结奋斗、自强不息的精神动力；弘扬爱国主义有助于增强民族认同、维护国家统一、推动民族复兴。
完整解答
  1. 爱国主义是民族精神的核心。
  2. 它是凝聚民族力量的精神纽带。
  3. 弘扬爱国主义有助于增强民族认同、维护国家统一、推动民族复兴。
  4. 结论：新时代必须弘扬爱国主义。
易错
  • 把民族精神核心写成「改革创新」。
  • 把爱国主义理解为狭隘排外。
  • 忽略爱国、爱党、爱社会主义的统一。
讲法
腿姐keywords：民族精神「爱国」、时代精神「改革创新」，两句话成对记。

社会主义核心价值观

核心必考

社会主义核心价值观共 24 字，分三个层面：国家层面富强、民主、文明、和谐；社会层面自由、平等、公正、法治；个人层面爱国、敬业、诚信、友善。它是当代中国精神的集中体现，凝结着全体人民共同的价值追求。

国家：富强 · 民主 · 文明 · 和谐四个词
社会：自由 · 平等 · 公正 · 法治四个词
个人：爱国 · 敬业 · 诚信 · 友善四个词
同型 思修选择题

社会主义核心价值观中，属于个人层面的是（ ）。

要点 爱国、敬业、诚信、友善。国家层面是富强、民主、文明、和谐；社会层面是自由、平等、公正、法治。
完整解答
  1. 国家层面：富强、民主、文明、和谐。
  2. 社会层面：自由、平等、公正、法治。
  3. 个人层面：爱国、敬业、诚信、友善。
  4. 结论：个人层面是爱国、敬业、诚信、友善。
易错
  • 把「公正」写成「公平」，或把「法治」放到个人层面。
  • 漏写某一层，或把三层的词混排。
  • 认为核心价值观只是口号，忽略其规范功能。
讲法
腿姐keywords：24 字按「国家—社会—个人」三层四词，默写时先画三层框。

道德的本质、功能与传统美德

核心高频

道德是反映社会经济关系的特殊意识形态，是社会实践的产物，具有认识、规范、调节、激励、导向等功能。中华传统美德的基本精神包括注重整体利益、推崇仁爱、讲求谦敬礼让、倡导言行一致、追求精神境界、重视道德践履。

道德本质：反映社会经济关系的特殊意识形态不是主观自生
道德功能：认识 · 规范 · 调节 · 激励 · 导向五个功能
传统美德六精神：整体利益 · 仁爱 · 礼让 · 诚信 · 境界 · 践履常考列举
同型 思修选择题

道德的本质是什么？

要点 道德是反映社会经济关系的特殊意识形态，是由经济基础决定的上层建筑，同时具有相对独立性。
完整解答
  1. 道德是反映社会经济关系的特殊意识形态。
  2. 它由经济基础决定，是上层建筑。
  3. 同时具有相对独立性。
  4. 结论：道德的本质是反映社会经济关系的特殊意识形态。
易错
  • 把道德说成超历史的、永恒不变的。
  • 把道德的功能只理解为「约束」。
  • 把传统美德等同于全部传统文化。
讲法
徐涛用「经济关系决定道德，道德反作用于经济」一句打穿本质与功能。

社会公德、职业道德、家庭美德、个人品德

核心高频

社会公德：文明礼貌、助人为乐、爱护公物、保护环境、遵纪守法。职业道德：爱岗敬业、诚实守信、办事公道、服务群众、奉献社会。家庭美德：尊老爱幼、男女平等、夫妻和睦、勤俭持家、邻里团结。个人品德是道德建设的基础。

公德五条：文明礼貌 · 助人为乐 · 爱护公物 · 保护环境 · 遵纪守法五条常考
职业道德五条：爱岗敬业 · 诚实守信 · 办事公道 · 服务群众 · 奉献社会「奉献社会」是最高层次
家庭美德五条：尊老爱幼 · 男女平等 · 夫妻和睦 · 勤俭持家 · 邻里团结五条
同型 思修选择题

职业道德的最高层次要求是（ ）。

要点 奉献社会。爱岗敬业、诚实守信、办事公道、服务群众、奉献社会构成职业道德的基本要求。
完整解答
  1. 职业道德的基本要求：爱岗敬业、诚实守信、办事公道、服务群众、奉献社会。
  2. 最高层次是奉献社会。
  3. 结论：奉献社会。
易错
  • 把「保护环境」归入职业道德。
  • 漏掉「邻里团结」或把家庭美德与个人品德混淆。
  • 认为个人品德不重要，忽略其基础地位。
讲法
腿姐keywords：四德各五条，用「公—职—家—个」四框分别默写，避免串场。

法治思维与法律权威

核心高频

法治思维是以法治价值和法治精神为导向，运用法律原则、规则和方法思考处理问题的思维模式，基本内容包括法律至上、权力制约、公平正义、权利保障、正当程序。法律权威源于法律的内在说服力和外在强制力。

法治思维五内容：法律至上 · 权力制约 · 公平正义 · 权利保障 · 正当程序五条成组
法律权威 = 内在说服力 + 外在强制力两面
法律至上：宪法法律高于任何个人意志不是「法律万能」
同型 思修分析题

结合「按程序办事」的案例，说明正当程序为什么是法治思维的重要内容。

要点 正当程序保证决定过程的公开、公平、参与和可救济，能约束权力任性、保障当事人权利，是实体正义的实现条件。
完整解答
  1. 正当程序保证决定过程的公开、公平、参与和可救济。
  2. 它能约束权力任性，保障当事人权利。
  3. 正当程序是实体正义的实现条件。
  4. 结论：正当程序是法治思维的重要内容。
易错
  • 把「法律至上」理解为「法律解决一切问题」。
  • 把法治思维与道德思维混同。
  • 忽略「正当程序」的独立价值。
讲法
徐涛用「权限—程序—权利—责任」四问检查案例，法治题就不会跑偏。

宪法与中国特色社会主义法律体系

基础高频

宪法是国家的根本法，具有最高法律效力，是治国安邦的总章程。中国特色社会主义法律体系以宪法为核心，由法律、行政法规、地方性法规等构成。坚持依法治国首先要坚持依宪治国，坚持依法执政首先要坚持依宪执政。

宪法 = 根本法 + 最高法律效力两个定位
依宪治国 · 依宪执政「首先」二字常考
法律体系以宪法为核心不是以民法典为核心
同型 思修选择题

为什么说宪法是国家的根本法？

要点 宪法规定国家根本制度和根本任务、公民基本权利和义务，具有最高法律效力，是制定其他法律的依据。
完整解答
  1. 宪法规定国家根本制度和根本任务、公民基本权利和义务。
  2. 宪法具有最高法律效力。
  3. 宪法是制定其他法律的依据。
  4. 结论：宪法是国家的根本法。
易错
  • 把宪法与普通法律并列。
  • 把「依宪治国」写成「以德治国」。
  • 认为宪法只约束国家机关，不约束公民。
讲法
腿姐keywords：宪法「根本法、最高效力、总章程」三连；依宪治国「首先」不能丢。

权利与义务、依法治国与以德治国

核心高频

权利与义务相互依存、相互促进，没有无义务的权利，也没有无权利的义务。坚持依法治国和以德治国相结合，是中国特色社会主义法治道路的鲜明特点。

权利与义务：相互依存 · 相互促进不是先有权利后有义务
依法治国 + 以德治国 = 相结合二者不可偏废
法治与德治：他律 + 自律分析题常用
同型 思修分析题

为什么必须坚持依法治国和以德治国相结合？

要点 法律是成文的道德，道德是内心的法律。法治提供刚性约束，德治提供价值基础；二者相互补充、相互促进，才能实现国家治理现代化。
完整解答
  1. 法律是成文的道德，道德是内心的法律。
  2. 法治提供刚性约束，德治提供价值基础。
  3. 二者相互补充、相互促进。
  4. 结论：必须坚持依法治国和以德治国相结合。
易错
  • 把权利与义务割裂，认为可以先享受权利。
  • 把德治理解为「人治」。
  • 认为法治可以替代德治，或反之。
讲法
徐涛用「法律是底线、道德是高地」比喻法治与德治的分工，收尾自然。

专题 01

思修分析题：三类材料、三套骨架

思修分析题通常落在「人生价值」「道德践行」「法治意识」三类材料上。每类都有固定骨架，提前准备可以在考场上直接套。

  1. 先判类型：材料讲个人选择→人生价值观；讲社会风尚→道德；讲规则程序→法治。
  2. 人生价值类：人生目的—社会价值—评价尺度—结合材料。
  3. 道德类：道德本质/功能—具体德目—传统美德或核心价值观—材料对应。
  4. 法治类：法治思维五内容—权利义务—依法治国与以德治国—材料对应。
  5. 结尾统一落到「新时代青年/社会主义核心价值观」，不新开概念。
例

材料：一名大学生毕业后回乡创业，带动村民致富。设问：运用人生价值理论分析其选择。

解 人生目的决定人生道路；他把个人理想融入社会需要，体现了社会价值的主导地位；评价人生价值看是否促进社会进步和人民福祉。其选择符合社会主义核心价值观，值得肯定。

踩坑点 不要把所有原理都写上去。思修分析题按「材料类型」选一套骨架，写深一套比浅写三套得分高。
[[T-topic-02]]
专题 02

思修易混概念对照表

思修选择题大量考「核心、基础、最高、根本」这类定位词，概念之间只差一两个字。集中对照记忆，比反复看书有效。

  1. 人生观：目的（核心）—态度—价值（社会价值为主）。
  2. 中国精神：民族精神核心=爱国主义；时代精神核心=改革创新。
  3. 核心价值观：国家/社会/个人三层，每层四词。
  4. 道德：本质=特殊意识形态；基础=个人品德。
  5. 法治：宪法=根本法；法治思维五内容；依法治国与以德治国相结合。
  6. 每天遮住右列自测，错项标红，考前只看红项。
例

「人生观的核心」与「道德建设的基础」分别是什么？

解 人生观的核心是人生目的；道德建设的基础是个人品德。二者常被互换设错。

踩坑点 不要把「核心」「基础」「根本」「最高」当成同义词。每个词的搭配对象是固定的，错一个字就丢分。
