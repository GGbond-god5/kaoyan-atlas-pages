基本概念与可分离变量方程

基础必考

一阶方程先看能否写成 \(y'=f(x)g(y)\)，能则分离变量、两边积分。注意除以 \(g(y)\) 时可能丢掉 \(g(y)=0\) 的常数解；有初始条件时先定 \(C\) 再化简。

\(\dfrac{dy}{g(y)}=\int f(x)dx\)分离变量
\(y'=f(ax+by+c)\)：令 \(u=ax+by+c\)可化为可分离
同型 数一

求 \(y'=2xy,\ y(0)=1\) 的特解。

要点 分离得 \(dy/y=2x\,dx\)，积分 \(\ln|y|=x^2+C\)，由 \(y(0)=1\) 得 \(C=0\)，故 \(y=e^{x^2}\)。
完整解答
  1. 方程 \(y'=2xy\) 可分离：\(\frac{dy}{y}=2x\,dx\)（\(y\ne0\)）。
  2. 两边积分：\(\ln|y|=x^2+C\)，故 \(y=Ce^{x^2}\)（\(C\) 可正可负）。
  3. 代入初值 \(y(0)=1\)：\(1=Ce^0=C\)，故 \(C=1\)。
  4. 特解为 \(y=e^{x^2}\)。
  5. 检查：\(y'=2xe^{x^2}=2xy\)，且 \(y(0)=1\)，满足方程与初值。
易错
  • 分离时除以 \(y\) 丢掉 \(y=0\) 解。
  • 积分后不加常数，导致特解求错。
讲法
武忠祥一阶方程先问“能不能分离”，能分离就是送分题；分离后先写通解再代初值。

齐次微分方程

基础高频

形如 \(y'=\varphi(y/x)\) 的方程令 \(u=y/x\)，则 \(y=ux,\ y'=u+xu'\)，化为可分离方程。识别标志是右端只含 \(y/x\) 的组合，或分子分母同次齐次。

\(u=\dfrac yx,\quad y'=u+xu'\)代换
\(x\dfrac{du}{dx}=\varphi(u)-u\)化为可分离
同型 数一

求 \(y'=\dfrac{y}{x}+\dfrac{x}{y}\) 的通解。

要点 令 \(u=y/x\)，得 \(xu'=1/u\)，分离积分 \(u^2/2=\ln|x|+C\)，回代得 \(y^2=2x^2(\ln|x|+C)\)。
完整解答
  1. 方程为齐次型 \(y'=f(y/x)\)，令 \(u=\frac yx\)，则 \(y=ux,\ y'=u+xu'\)。
  2. 代入：\(u+xu'=u+\frac1u\)，消去 \(u\) 得 \(xu'=\frac1u\)。
  3. 分离变量：\(u\,du=\frac{dx}{x}\)，积分得 \(\frac{u^2}{2}=\ln|x|+C\)。
  4. 回代 \(u=y/x\)：\(\frac{y^2}{2x^2}=\ln|x|+C\)，即 \(y^2=2x^2(\ln|x|+C)\)。
  5. 检查：求导可还原；注意 \(x\ne0\)，且解在 \(x>0\) 或 \(x<0\) 的区间上分别成立。
易错
  • 代换后忘记 \(y'=u+xu'\) 中的 \(xu'\)。
  • 回代时把 \(u\) 留在答案里。
讲法
张宇看到 \(y/x\) 就令 \(u=y/x\)；代换后一定先把 \(u'\) 单独解出来。

一阶线性方程与伯努利方程

核心必考

标准形 \(y'+P(x)y=Q(x)\)，直接套通解公式，或用积分因子 \(e^{\int P dx}\) 乘两边。伯努利方程 \(y'+Py=Qy^n\) 令 \(z=y^{1-n}\) 化为一阶线性。

\(y=e^{-\int Pdx}\left(\int Qe^{\int Pdx}dx+C\right)\)通解公式
\(z=y^{1-n}\Rightarrow z'+(1-n)Pz=(1-n)Q\)伯努利化线性
同型 数一

求 \(y'+\dfrac{y}{x}=x\) 的通解。

要点 \(P=1/x,\ Q=x\)，积分因子 \(x\)，得 \((xy)'=x^2\)，积分 \(xy=x^3/3+C\)，故 \(y=x^2/3+C/x\)。
完整解答
  1. 一阶线性方程 \(y'+P(x)y=Q(x)\)，这里 \(P=\frac1x,\ Q=x\)。
  2. 积分因子 \(\mu=e^{\int P dx}=e^{\ln|x|}=|x|\)，在 \(x>0\) 上取 \(\mu=x\)。
  3. 方程两边乘 \(x\)：\(xy'+y=x^2\)，即 \((xy)'=x^2\)。
  4. 积分得 \(xy=\frac{x^3}{3}+C\)，故 \(y=\frac{x^2}{3}+\frac Cx\)。
  5. 检查：代回 \(y'+\frac yx=x\)，成立；\(x=0\) 不在定义域内。
易错
  • 公式中 \(\int Pdx\) 忘记取指数。
  • 伯努利方程 \(n=0\) 或 \(n=1\) 时仍做代换（此时本就是线性）。
讲法
没咋了一阶线性优先“乘积分因子”而不是背公式，步骤分更稳，也不易记错符号。

全微分方程

进阶中频

方程 \(Pdx+Qdy=0\) 满足 \(P_y=Q_x\) 时为全微分方程，存在 \(u\) 使 \(du=Pdx+Qdy\)，通解为 \(u=C\)。求 \(u\) 用折线积分或凑微分。

\(P_y=Q_x\iff\) 全微分方程判定
\(u=\int_{x_0}^xP(t,y_0)dt+\int_{y_0}^yQ(x,t)dt\)折线法
同型 数一

求 \((2x+y)dx+(x+2y)dy=0\) 的通解。

要点 \(P_y=1=Q_x\)，凑微分得 \(d(x^2+xy+y^2)=0\)，通解 \(x^2+xy+y^2=C\)。
完整解答
  1. 记 \(P=2x+y,\ Q=x+2y\)，验证 \(P_y=1,\ Q_x=1\)，故为全微分方程。
  2. 存在 \(u(x,y)\) 使 \(du=Pdx+Qdy\)；由 \(u_x=2x+y\) 积分得 \(u=x^2+xy+g(y)\)。
  3. 对 \(y\) 求导：\(u_y=x+g'(y)=Q=x+2y\)，故 \(g'(y)=2y\)，\(g=y^2\)。
  4. 通解为 \(u=C\)，即 \(x^2+xy+y^2=C\)。
  5. 检查：对 \(x^2+xy+y^2=C\) 求全微分，正好得到原方程。
易错
  • 不验证 \(P_y=Q_x\) 就凑全微分。
  • 折线法积分路径选得穿过奇点。
讲法
武忠祥全微分方程与路径无关是同一件事，先验条件再凑 \(d(xy)\)、\(d(x^2+y^2)\)。

可降阶的高阶方程

进阶高频

三类可降阶：\(y''=f(x)\) 直接积分两次；\(y''=f(x,y')\) 缺 \(y\)，令 \(p=y'\)；\(y''=f(y,y')\) 缺 \(x\)，令 \(p=y'\) 且 \(y''=p\,dp/dy\)。识别“缺谁”是关键。

\(y''=f(x)\Rightarrow y'=\int f dx+C_1\)两次积分
\(y''=f(x,y'):\ p=y'\)缺 y
\(y''=f(y,y'):\ y''=p\dfrac{dp}{dy}\)缺 x
同型 数一

求 \(yy''=(y')^2\) 的通解。

要点 缺 \(x\)，令 \(p=y'\)，则 \(yp\,dp/dy=p^2\)，得 \(dp/p=dy/y\)，\(p=C_1y\)，即 \(y'=C_1y\)，故 \(y=C_2e^{C_1x}\)。
完整解答
  1. 方程缺自变量 \(x\)，令 \(p=y'\)，则 \(y''=p\frac{dp}{dy}\)。
  2. 代入 \(yy''=(y')^2\)：\(y p\frac{dp}{dy}=p^2\)。
  3. 若 \(p\ne0\)，约去 \(p\) 得 \(\frac{dp}{p}=\frac{dy}{y}\)，积分 \(\ln|p|=\ln|y|+C_1\)，即 \(p=C_1y\)。
  4. 回代 \(p=y'\)：\(\frac{dy}{dx}=C_1y\)，解得 \(y=C_2e^{C_1x}\)。
  5. 另外 \(p=0\) 给出常数解 \(y=C\)，已包含在 \(C_1=0\) 的情形中。
易错
  • 缺 \(x\) 时仍令 \(p=y'\) 且 \(y''=dp/dx\)，无法分离。
  • 积分两次忘记两个常数。
讲法
张宇可降阶只看“缺谁”：缺 \(y\) 用 \(p(x)\)，缺 \(x\) 用 \(p(y)\)。

线性方程解的结构

基础中频

齐次方程通解是两个线性无关特解的线性组合；非齐次方程通解 = 对应齐次通解 + 一个特解。叠加原理：右端为 \(f_1+f_2\) 时，特解可分别求再相加。

\(y=C_1y_1+C_2y_2\)齐次通解
\(y=Y+y^*\)非齐次通解
\(W(y_1,y_2)\ne0\)线性无关判据
同型 数一

已知 \(y_1=e^x,\ y_2=e^{2x}\) 是某二阶齐次方程的解，写出其通解。

要点 \(y_1,y_2\) 线性无关（朗斯基行列式不为零），通解为 \(y=C_1e^x+C_2e^{2x}\)。
完整解答
  1. 二阶齐次线性方程的通解由其两个线性无关解线性组合而成。
  2. 检验线性无关：朗斯基行列式 \(W(y_1,y_2)=e^x\cdot2e^{2x}-e^{2x}\cdot e^x=e^{3x}\ne0\)。
  3. 故 \(y_1=e^x,\ y_2=e^{2x}\) 构成基本解组。
  4. 通解为 \(y=C_1e^x+C_2e^{2x}\)。
  5. 检查：代回任一以 \(e^x,e^{2x}\) 为解的方程（如 \(y''-3y'+2y=0\)）都成立。
易错
  • 把非齐次特解直接乘常数当通解。
  • 两个特解线性相关仍写 \(C_1y_1+C_2y_2\) 作为通解。
讲法
武忠祥解的结构题只记一句话：非齐次通解 = 齐次通解 + 特解。

二阶常系数齐次线性方程

核心必考

写特征方程 \(r^2+pr+q=0\)，按判别式分三种情形：两不等实根、重根、共轭复根，分别写出通解。重根时第二个解乘 \(x\)，复根时用 \(e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)\)。

\(r_{1,2}=\dfrac{-p\pm\sqrt{p^2-4q}}{2}\)特征根
\(r_1\ne r_2:\ y=C_1e^{r_1x}+C_2e^{r_2x}\)相异实根
\(r_1=r_2=r:\ y=(C_1+C_2x)e^{rx}\)重根
\(\alpha\pm\beta i:\ y=e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)\)复根
同型 数一

求 \(y''-3y'+2y=0\) 的通解。

要点 特征方程 \(r^2-3r+2=0\)，根 \(1,2\)，通解 \(y=C_1e^x+C_2e^{2x}\)。
完整解答
  1. 写特征方程：\(r^2-3r+2=0\)。
  2. 因式分解 \((r-1)(r-2)=0\)，特征根 \(r_1=1,\ r_2=2\)，为两个不同实根。
  3. 对应两个线性无关解 \(e^x,\ e^{2x}\)。
  4. 通解为 \(y=C_1e^x+C_2e^{2x}\)。
  5. 检查：代入方程，每一项分别满足，线性组合也满足。
易错
  • 重根情形漏乘 \(x\)。
  • 复根情形把 \(\beta\) 写成 \(\beta x\) 放进指数。
讲法
没咋了特征根三种情形做成一张表，考前默写一遍，考场直接查表。

二阶常系数非齐次方程

核心必考

先求齐次通解，再设特解。右端 \(e^{\lambda x}P_m(x)\)：特解设 \(x^k e^{\lambda x}Q_m(x)\)，\(k\) 为 \(\lambda\) 作为特征根的重数。右端含 \(\cos\beta x,\sin\beta x\) 时用 \(e^{\alpha x}(R\cos\beta x+S\sin\beta x)\)。

\(y^*=x^ke^{\lambda x}Q_m(x)\)\(k=0,1,2\)
\(y^*=x^ke^{\alpha x}(R\cos\beta x+S\sin\beta x)\)三角型
同型 数一

求 \(y''-2y'+y=e^x\) 的一个特解。

要点 特征根 \(r=1\) 为二重根，故设 \(y^*=Ax^2e^x\)；代入得 \(2Ae^x=e^x\)，\(A=1/2\)，特解 \(y^*=\frac12x^2e^x\)。
完整解答
  1. 先解齐次方程 \(y''-2y'+y=0\)，特征方程 \((r-1)^2=0\)，\(r=1\) 为二重根。
  2. 右端 \(e^x\) 对应特征根 \(r=1\)，发生二重共振，故设特解 \(y^*=Ax^2e^x\)。
  3. 求导：\(y^{*'}=A(2x+x^2)e^x,\ y^{*''}=A(2+4x+x^2)e^x\)。
  4. 代入原方程：\(y^{*''}-2y^{*'}+y^*=2Ae^x\)，令其等于 \(e^x\)，得 \(A=\frac12\)。
  5. 特解 \(y^*=\frac12x^2e^x\)；通解再叠加齐次通解 \((C_1+C_2x)e^x\)。
易错
  • \(\lambda\) 是特征根却仍设 \(k=0\)。
  • 三角型漏掉 \(\sin\) 项，只设 \(\cos\)。
讲法
张宇特解设法只看“\(\lambda\) 是不是特征根、是几重”，其余照抄右端形式。

欧拉方程与微分方程应用

进阶中频

欧拉方程 \(x^2y''+pxy'+qy=f(x)\) 令 \(x=e^t\)（或 \(t=\ln x\)），化为常系数线性方程；记 \(x^2y''=D(D-1)y\)。应用题先建微分方程，再用初始条件定常数。

\(x=e^t,\quad x^2y''=D(D-1)y\)\(D=d/dt\)
\(x^2y''-xy'+y=0\Rightarrow y=C_1x+C_2x\ln x\)典型解
同型 数一

求 \(x^2y''-xy'+y=0\ (x>0)\) 的通解。

要点 令 \(x=e^t\)，方程化为 \(D(D-1)y-Dy+y=0\)，即 \((D-1)^2y=0\)，得 \(y=(C_1+C_2t)e^t=C_1x+C_2x\ln x\)。
完整解答
  1. 这是欧拉方程，令 \(x=e^t\)（\(x>0\)），记 \(D=\frac{d}{dt}\)。
  2. 有 \(xy'=Dy,\ x^2y''=D(D-1)y\)，代入原方程得 \(D(D-1)y-Dy+y=0\)。
  3. 化简：\((D^2-2D+1)y=0\)，即 \((D-1)^2y=0\)。
  4. 特征根 \(1\) 为二重根，故 \(y=(C_1+C_2t)e^t\)。
  5. 回代 \(t=\ln x,\ e^t=x\)，得 \(y=C_1x+C_2x\ln x\)。
易错
  • 欧拉方程不换元直接套常系数公式。
  • 应用题忘记用初始条件定常数。
讲法
武忠祥欧拉方程只记“\(x=e^t\)，\(x^2y''=D(D-1)y\)”，换元后按常系数做。

专题 01

二阶非齐次特解设法：一张表解决

数一微分方程大题的第二问几乎都考非齐次特解。设错形式，后面计算全废；设对形式，只是待定系数。

  1. 先解特征方程，写出齐次通解，并标出特征根。
  2. 看右端类型：多项式、指数、三角，或它们的乘积。
  3. 判断右端指数 \(\lambda\) 是否为特征根：不是取 \(k=0\)，单根取 \(k=1\)，重根取 \(k=2\)。
  4. 按右端同类型设特解，多项式次数与右端一致。
  5. 代入原方程比较系数，解出待定系数，最后写通解。
例

求 \(y''-3y'+2y=e^{3x}\) 的通解。

解 齐次通解 \(Y=C_1e^x+C_2e^{2x}\)；\(\lambda=3\) 不是特征根，设 \(y^*=Ae^{3x}\)，代入得 \((9-9+2)Ae^{3x}=e^{3x}\)，\(A=1/2\)。通解 \(y=C_1e^x+C_2e^{2x}+\frac12e^{3x}\)。

踩坑点 右端是 \(e^x\) 且 \(r=1\) 是单根时，特解必须设 \(Axe^x\) 而不是 \(Ae^x\)，否则代入后恒为零，解不出 \(A\)。
