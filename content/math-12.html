特征值与特征向量的定义与求法

核心必考

满足 \(Av=\lambda v\)（\(v\ne0\)）的 \(\lambda\) 为特征值，\(v\) 为特征向量。求法两步：解特征方程 \(|A-\lambda E|=0\) 得特征值；对每个 \(\lambda\) 解齐次方程组 \((A-\lambda E)x=0\) 得特征向量。特征向量必须非零，这是最容易忽略的一句话。

\(|A-\lambda E|=0\)特征方程
\((A-\lambda E)x=0\)特征向量满足的方程组
\(\dim N(A-\lambda E)=n-r(A-\lambda E)\)几何重数
同型 数一

已知三阶矩阵 \(A\)，求全部特征值与对应的线性无关特征向量。

要点 展开 \(|A-\lambda E|\) 求根；对每个根写 \((A-\lambda E)x=0\)，化行最简形求基础解系，基础解系即该特征值的全部线性无关特征向量。
完整解答
  1. 目标：求全部特征值与线性无关特征向量。
  2. 解特征方程 \(|A-\lambda E|=0\)，得特征值及重数。
  3. 对每个 \(\lambda_i\)，解 \((A-\lambda_iE)x=0\)。
  4. 行变换化行最简形，取基础解系作为对应的线性无关特征向量。
  5. 用 \(A\xi_i=\lambda_i\xi_i\) 抽查。
易错
  • 把零向量当作特征向量。
  • 求特征向量时解的是 \((\lambda E-A)x=0\) 却把符号算错。
讲法
武忠祥求特征值先看行和是否为常数，是则 \(\lambda=\) 行和必为一个特征值，能省一次展开。

02

特征值的性质

核心必考

两个必背恒等式：\(\sum\lambda_{i}=\operatorname{tr}(A)\)，\(\prod\lambda_{i}=|A|\)。它们既能快速验算，也能在只知道部分特征值时反推其余。不同特征值对应的特征向量线性无关；\(k\) 重特征值最多有 \(k\) 个线性无关特征向量。

\(\sum_{i=1}^{n}\lambda_{i}=\operatorname{tr}(A)\)迹
\(\prod_{i=1}^{n}\lambda_{i}=|A|\)行列式
\(f(A)\) 的特征值为 \(f(\lambda_{i})\)多项式映射
同型 数一

三阶矩阵 \(A\) 的特征值为 \(1,2,3\)，求 \(|A^{2}-2A+E|\)。

要点 令 \(f(x)=x^{2}-2x+1=(x-1)^{2}\)，则 \(f(A)\) 的特征值为 \(0,1,4\)，行列式为 0。
完整解答
  1. 目标：用特征值性质求 \(f(A)\) 的行列式。
  2. \(f(x)=x^2-2x+1=(x-1)^2\)。
  3. \(f(A)\) 的特征值为 \(f(1)=0,\ f(2)=1,\ f(3)=4\)。
  4. 行列式等于特征值之积：\(0\cdot1\cdot4=0\)。
易错
  • 把 \(\operatorname{tr}(A)\) 当成特征值之和的平方。
  • 认为 \(f(A)\) 的特征向量与原矩阵不同。
讲法
张宇特征值题先写“和、积”两行，很多参数题一步就能定出来。

相似矩阵与相似对角化

核心必考

\(A\sim B\) 指存在可逆 \(P\) 使 \(B=P^{-1}AP\)。相似矩阵有相同的特征多项式、特征值、行列式、迹、秩。\(A\) 可对角化 \(\Leftrightarrow\) 有 \(n\) 个线性无关的特征向量 \(\Leftrightarrow\) 每个特征值的几何重数等于代数重数。

\(P^{-1}AP=\Lambda\)\(P\) 的列是特征向量
\(A\ \text{可对角化}\Leftrightarrow\sum\dim N(A-\lambda_{i}E)=n\)几何重数之和
n 个不同特征值 \(\Rightarrow\) 可对角化充分不必要
同型 数一

判断三阶矩阵能否相似对角化；若能，求可逆矩阵 \(P\) 与对角阵 \(\Lambda\)。

要点 求特征值并统计重数；对每个重特征值求 \((A-\lambda E)x=0\) 的基础解系，若线性无关特征向量总数为 3 则可对角化；把特征向量按列拼成 \(P\)，对应特征值放对角。
完整解答
  1. 目标：判断是否可对角化并求 \(P,\Lambda\)。
  2. 求特征值与代数重数。
  3. 对每个重特征值，求 \(n-r(A-\lambda E)\)，即几何重数。
  4. 若每个特征值的几何重数等于代数重数，则可对角化；否则不可。
  5. 可对角化时，以特征向量为列拼 \(P\)，\(\Lambda=\mathrm{diag}(\lambda_i)\)，验证 \(P^{-1}AP=\Lambda\)。
易错
  • 只凭“有重特征值”就判定不可对角化。
  • \(P\) 的列顺序与 \(\Lambda\) 的特征值顺序不对应。
讲法
没咋了可对角化只看“能不能凑够 n 个无关特征向量”，与特征值是否重复无关。

实对称矩阵的正交对角化

核心必考

实对称矩阵必可正交对角化，且不同特征值的特征向量自动正交。重特征值对应的特征向量需要先用施密特正交化，再单位化。最后 \(Q^{T}AQ=\Lambda\)，\(Q\) 为正交矩阵。这是二次型一章的直接工具。

\(Q^{T}AQ=\Lambda,\quad Q^{T}Q=E\)\(Q\) 的列为标准正交特征向量
\(\beta_{2}=\alpha_{2}-\dfrac{(\alpha_{2},\beta_{1})}{(\beta_{1},\beta_{1})}\beta_{1}\)施密特正交化
\(q_{i}=\dfrac{\beta_{i}}{\|\beta_{i}\|}\)单位化
同型 数一

已知三阶实对称矩阵 \(A\) 的特征值与特征向量，求正交矩阵 \(Q\) 使 \(Q^{T}AQ\) 为对角阵。

要点 不同特征值的特征向量先单位化；重特征值的一组特征向量先施密特正交化再单位化；按列拼成 \(Q\)，对角元按对应顺序排列。
完整解答
  1. 目标：求正交矩阵 \(Q\)。
  2. 求特征值与特征向量；不同特征值的特征向量已正交。
  3. 重特征值的一组特征向量用施密特正交化。
  4. 全部单位化，按列拼成 \(Q\)。
  5. 则 \(Q^TAQ=\mathrm{diag}(\lambda_i)\)；验证 \(Q^TQ=E\)。
易错
  • 重特征值的特征向量忘记正交化，导致 \(Q\) 不正交。
  • 只正交化不单位化，\(Q^{T}Q\ne E\)。
讲法
武忠祥实对称题固定四步：求特征值—求特征向量—施密特—单位化；顺序不能跳。

05

特征值的应用：矩阵幂与函数

进阶高频

若 \(A=P\Lambda P^{-1}\)，则 \(A^{k}=P\Lambda^{k}P^{-1}\)，\(f(A)=Pf(\Lambda)P^{-1}\)。这是求高阶矩阵幂的标准方法；秩一矩阵另有捷径：\(A=\alpha\beta^{T}\) 时 \(A^{k}=(\beta^{T}\alpha)^{k-1}A\)。

\(A^{k}=P\Lambda^{k}P^{-1}\)可对角化时
\(f(A)=Pf(\Lambda)P^{-1}\)多项式与解析函数
\((\alpha\beta^{T})^{k}=(\beta^{T}\alpha)^{k-1}\alpha\beta^{T}\)秩一矩阵
同型 数一

已知 \(A\) 可对角化且特征值为 \(1,2\)，求 \(A^{10}\)。

要点 求特征向量拼成 \(P\)，\(A^{10}=P\begin{pmatrix}1&0\\0&2^{10}\end{pmatrix}P^{-1}\)；先算 \(P^{-1}\) 再乘，避免十次矩阵乘法。
完整解答
  1. 目标：用对角化计算 \(A^{10}\)。
  2. 求特征值与特征向量，拼 \(P,\Lambda\)，使 \(A=P\Lambda P^{-1}\)。
  3. \(A^{10}=P\Lambda^{10}P^{-1}\)。
  4. \(\Lambda^{10}=\mathrm{diag}(1^{10},2^{10})\)。
  5. 乘出结果，并用迹与行列式抽查。
易错
  • 把 \(A^{k}\) 算成对角元各自 k 次方而忽略 \(P,P^{-1}\)。
  • 秩一矩阵忘记先算 \(\beta^{T}\alpha\)（一个数）。
讲法
张宇求高阶幂先问“能不能对角化”；能则走 \(P\Lambda^{k}P^{-1}\)，不能则找规律。

由特征值反推行列式与秩

核心高频

选择题常给特征值或特征向量，反推行列式、秩、参数。核心关系：\(|A|=\prod\lambda_{i}\)；\(r(A)=\) 非零特征值个数（可对角化时）；\(A\) 不可逆 \(\Leftrightarrow0\) 是特征值；\(A^{*}\) 的特征值为 \(|A|/\lambda_{i}\)。

\(|A|=\prod\lambda_{i}\)行列式
\(r(A)=\#\{\lambda_{i}\ne0\}\)可对角化时
\(A^{*}\) 的特征值 \(=\dfrac{|A|}{\lambda_{i}}\)\(\lambda_{i}\ne0\)
同型 数一

已知三阶矩阵 \(A\) 的特征值为 \(1,1,0\)，问 \(r(A)\) 与 \(r(A^{*})\)。

要点 若 \(A\) 可对角化，\(r(A)=2\)；\(|A|=0\)，故 \(r(A^{*})=1\)（因为 \(r(A)=n-1\)）。注意：\(r(A)=2\) 还需要可对角化这一前提，题目若未给需另行判断。
完整解答
  1. 目标：由特征值 \(1,1,0\) 判断 \(r(A)\) 与 \(r(A^*)\)。
  2. \(\lambda=0\) 为单特征值，故 \(r(A)=n-1=2\)。
  3. \(|A|=0\)，所以 \(AA^*=O\)，\(r(A)+r(A^*)\le3\)。
  4. \(r(A)=2\) 说明存在非零二阶子式，\(A^*\ne O\)。
  5. 故 \(r(A^*)=1\)。
易错
  • 把“非零特征值个数”直接当秩，忽略不可对角化的情形。
  • \(A^{*}\) 特征值公式在 \(\lambda=0\) 时失效。
讲法
没咋了特征值与秩的换算只在可对角化时最干净；题目没给就先验证。

相似与合同的辨析

进阶中频

相似是 \(B=P^{-1}AP\)，合同是 \(B=C^{T}AC\)。实对称矩阵：相似看特征值是否相同，合同看正负惯性指数是否相同。正交相似既是相似又是合同。选择题常拿“相似是否合同”“合同是否相似”设陷阱。

\(A\sim B\Rightarrow\lambda(A)=\lambda(B)\)必要条件
\(A\simeq B\Leftrightarrow\) 正负惯性指数相同实对称
正交相似 \(\Rightarrow\) 既相似又合同\(Q^{T}=Q^{-1}\)
同型 数一

判断两个实对称矩阵是否相似、是否合同，并说明理由。

要点 分别求特征值：特征值相同才可能相似；再数正、负特征值个数：正负惯性指数相同即合同。相似要求特征值完全相同，合同只要求符号个数相同。
完整解答
  1. 目标：分别判断相似与合同。
  2. 相似的必要条件是特征值相同（含重数）；求两边特征值比较。
  3. 实对称矩阵相似 \(\Leftrightarrow\) 特征值完全相同。
  4. 合同看惯性指数：正、负特征值个数相同即合同（Sylvester 惯性定理）。
  5. 分别给出结论：实对称矩阵相似必合同，合同不一定相似。
易错
  • 认为实对称矩阵只要行列式相同就合同。
  • 把“合同”当成“相似”的弱化版，忽略变换矩阵类型不同。
讲法
武忠祥相似看数值，合同看符号；八个字区分两个概念。

专题 01

相似对角化：判定与操作一条龙

数一解答题常要求“求可逆矩阵 \(P\) 使 \(P^{-1}AP\) 为对角阵”。判定与构造分开练，考场才不会在重特征值上卡住。

  1. 求特征值：解 \(|A-\lambda E|=0\)，统计每个根的重数。
  2. 对每个特征值求 \((A-\lambda E)x=0\) 的基础解系，记录线性无关特征向量个数。
  3. 判定：所有特征值的几何重数之和等于 \(n\) 才可对角化；若某个重特征值凑不够，直接不可对角化。
  4. 构造：把全部特征向量按列拼成 \(P\)，对应特征值按同序放 \(\Lambda\)。
  5. 验算：\(AP=P\Lambda\) 只需抽查一列，比求 \(P^{-1}\) 快。
例

\(A=\begin{pmatrix}2&1\\0&2\end{pmatrix}\) 能否对角化？

解 特征值 \(\lambda=2\)（二重），\(r(A-2E)=r\begin{pmatrix}0&1\\0&0\end{pmatrix}=1\)，几何重数 \(2-1=1<2\)，故不可对角化。

踩坑点 “特征值有重根”不等于“不可对角化”；判定的唯一标准是几何重数够不够。
[[T-topic-02]]
专题 02

实对称矩阵：正交对角化标准流程

实对称矩阵是数一必考，且直接服务于二次型。流程固定，但施密特正交化最容易漏。

  1. 求特征值，注意重数；实对称矩阵的特征值必为实数。
  2. 对每个特征值求基础解系，得到特征向量。
  3. 不同特征值的特征向量已经正交，只需单位化。
  4. 同一重特征值的多个特征向量，先施密特正交化，再单位化。
  5. 按列拼成 \(Q\)，验证 \(Q^{T}Q=E\) 与 \(Q^{T}AQ=\Lambda\)。
例

二重特征值 \(\lambda=1\) 对应特征向量 \(\alpha_{1}=(1,1,0)^{T},\ \alpha_{2}=(1,0,1)^{T}\)，求标准正交组。

解 \(\beta_{1}=\alpha_{1}\)；\(\beta_{2}=\alpha_{2}-\frac{(\alpha_{2},\beta_{1})}{(\beta_{1},\beta_{1})}\beta_{1}=(1,0,1)^{T}-\frac12(1,1,0)^{T}=(\frac12,-\frac12,1)^{T}\)；再分别单位化。

踩坑点 重特征值内部的特征向量不一定正交，必须做施密特；不同特征值之间才自动正交。
